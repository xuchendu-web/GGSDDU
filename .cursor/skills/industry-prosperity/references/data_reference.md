# 行业景气度追踪 — 数据参考

## 申万一级行业（31个）与 cjpy 因子映射

cjpy 中的行业因子名为 `一级行业` 或 `申万一级行业名称`（返回值如"电子"、"食品饮料"等）。

## 关键 cjpy 数据表

### 财务基础表

| 表名 | 关键字段 | 单位 | 说明 |
|------|---------|------|------|
| 主要财务指标 | 净资产收益率(%), 每股收益, 每股净资产 | % / 元 | 按报告期，含 报告类型（年报/中报/季报） |
| 合并利润表 | 营业总收入, 归母净利润 | 元 | 季度+累计 |
| 合并资产负债表 | 资产总计, 存货, 应收帐款 | 元 | 时点数 |

### 行业细分表

| 表名 | 关键字段 | 说明 |
|------|---------|------|
| 主营收入及成本_分行业 | 主营毛利率(%), 主营收入增长率(%) | 公司分业务线 |
| 存货 | 存货合计, 原材料, 产成品 | 库存明细 |
| 应收帐款帐龄分析 | 帐龄结构 | 回款效率 |
| 业绩预告 | 预告净利润变动幅度(%) | 前瞻指标 |

### 宏观表

| 表名 | 用途 |
|------|------|

## 五维度指标计算公式

### 盈利质量
- **ROE**：各成分股 净资产收益率(%) 的中位数
- **毛利率**：各成分股 主营毛利率(%) 的中位数
- **净利率**：净利润/营业收入 × 100%，取中位数

### 增长动能
- **营收增速**：最���季度营收 / 去年同期营收 - 1，取中位数
- **净利润增速**：最新季度归母净利润 / 去年同期 - 1，取中位数

### 库存效率
- **存货周转率变化**：(最新存货周转率 / 去年同期存货周转率 - 1) × 100
- **库存/总资产变��**：最新(存货/总资产) - 去年同期(存货/总资产)

### 市场定价
- **PE分位数**：当前 PE 在近5年历史中的分位（<30% = 低估，>70% = 高估）
- **1月动量**：近20个交易日行业指数涨跌幅
- **3月动量**：近60个交易日行业指数涨跌幅

### 资金关注
- **换手率变化**：(最新20日均换手 / 前20日均换手 - 1) × 100
- **成交额变化**：(最新20日均成交额 / 前20日均成交额 - 1) × 100
