# Research notes knowledge base (local FTS5)

Markdown and PDF notes under `research/research-kb/` are indexed locally with SQLite FTS5 (document + chunk indexes). No cloud upload; content comes only from files on disk.

## Prerequisites

- Python 3.10+ (stdlib: `sqlite3`, no required pip packages)
- Optional PDF text: `pip install pypdf` **or** system `pdftotext` (poppler). PDFs that are encrypted, oversized, or unreadable are skipped with a stderr message.

## CLI

From the repository root:

```bash
python3 research/research-kb/cli.py ingest
python3 research/research-kb/cli.py rebuild-fts
```

`ingest.py` remains a thin wrapper with the same flags.

### Ingest options

| Flag | Meaning |
|------|---------|
| `--root PATH` | Directory to scan recursively for `*.md` and `*.pdf` (default: `research/research-kb/`) |
| `--db PATH` | SQLite file (default: `<root>/kb_index.sqlite`) |
| `--force` | Re-read every file even if unchanged |
| `--rebuild-fts` | Run FTS5 `rebuild` on `documents_fts` and `chunks_fts` after ingest |
| `--chunk-chars N` | Chunk size (default 2400) |
| `--chunk-overlap N` | Chunk overlap (default 200) |

Skipped paths: `fixtures/`, `_corpus_stub/`, `kb_pipeline/`, and dotfiles.

## Search (CLI)

```bash
python3 research/research-kb/search.py volatility managed --limit 5
python3 research/research-kb/search.py "time series momentum"
python3 research/research-kb/search.py HYPOTHESES --json
python3 research/research-kb/search.py volatility --mode documents
```

- Default `--mode chunks` searches `chunks_fts` (finer snippets). Use `--mode documents` for whole-note BM25.
- Terms are combined with **AND** unless you use quoted phrases.
- Each hit includes **path**, **title**, optional **chunk**, BM25 **score**, **snippet**, and absolute **cite** path.
- Exit code `2` when there are no matches.

## Optional embeddings (stub)

`embed_stub.py` defines a `NoOpEmbedder` and `get_embedder("noop")` for a future vector sidecar. Ingest/search do not call it today.

## Smoke test

```bash
bash research/research-kb/smoke_test.sh
```

Runs ingest with FTS rebuild, checks chunk counts, sample queries, optional `fixtures/minimal.pdf` extraction, and a **500-file** stub corpus under `_corpus_stub/` (generated by `fixtures/gen_corpus_stub.py`, not committed).

## Sample corpus

The bundled sample is the extracted `kb-sample` tarball: volatility-managed / TSMOM literature notes, week-42 prep, hypotheses, and judging logs (~23 Markdown files). Re-run ingest after adding or editing notes.

## Why FTS5 instead of ripgrep alone

- Ranked hits (BM25) instead of flat line matches
- Snippets with context around the match (chunk-level by default)
- Stable **relative path citations** for Q&A-style lookup
- Single `kb_index.sqlite` you can copy or back up with the notes

For raw regex or cross-repo search, keep using `rg`; use this index when you want ranked note retrieval with paths.
