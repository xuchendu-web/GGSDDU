# 上线与验证手册

## 1. 上线前业务确认

以下事项必须由小程序主体负责人确认，当前仓库不能代替平台与法律审核：

- 正式小程序名称、主体类型、服务类目与经营范围；无相应资质时，名称和介绍不使用“证券、投顾、投资咨询”等受限表述。
- 客服邮箱、投诉渠道、处理时限、主体名称和联系信息。
- 144 条内容的版权来源、编辑与合规双审台账。
- 隐私保护指引、用户协议（如适用）、数据保留期限和删除流程。
- 云数据库权限、运营人员权限、日志脱敏和应急责任人。

## 2. 微信云开发配置

1. 用正式 AppID 替换 `project.config.json` 的 `touristappid`。
2. 在微信开发者工具中导入仓库根目录，开通云开发环境。
3. 创建集合 `draws`、`events`、`content_config`。
4. 创建文档 `content_config/active`，初始内容为 `{ "offlineCardIds": [] }`。
5. 对 `draws` 和 `events` 设为仅云函数可写、运营后台按最小权限读取；客户端不得直连。
6. 右键 `cloudfunctions/draw`，选择“上传并部署：云端安装依赖”。
7. 在测试环境确认抽取、分享还原、下线与事件写入后，再部署生产环境。

## 3. 开发版验收

在微信开发者工具及至少一台 iOS、一台 Android 真机逐项核对：

- 新用户：首页无需登录或授权；点按封面和按钮均能完成首翻。
- 三主题：“开盘前、收盘后、周末复盘”仅返回对应分类。
- 重复翻页：每次生成新 `drawId`，旧链接仍稳定还原原 `cardId`。
- 收藏与最近：收藏可切换，最近最多 20 条，退出重进后仍在本机。
- 分享落地：好友打开看到同一页；链接只含 `drawId` 与固定 `from=share`。
- 二代路径：好友点击“翻自己的第一页”得到新 `drawId`。
- 远程下线：下线 ID 不再被抽中，旧分享不展示正文。
- 弱网：云函数不可用时可从本地审核库抽页，页面明确本地来源。
- 布局：常见屏宽、系统字体放大、深浅色系统设置下无截断。
- 隐私：网络面板中不出现问题文本、证券代码、持仓、通讯录或好友关系。

## 4. 自动验证

```bash
npm ci
npm run verify
```

验证覆盖 TypeScript 静态检查、内容数量/schema/禁用表达/重复度、有效随机池、稳定实验分组、`drawId` 还原、下线降级、事件字段白名单和分享参数隐私。

## 5. 提审材料

- 功能说明：随机投资者教育摘句与决策反思，不提供投资咨询服务。
- 核心路径截图：首页、结果页、风险提示、收藏、分享落地。
- 隐私说明：无需输入问题；本地收藏；云端最小必要匿名数据字段。
- 内容审核说明：人工白名单、编辑/合规双审、版本留痕、单条下线与熔断。
- 测试账号：首版免登录，无需提供。
- 风险声明：内容仅用于投资者教育与自我反思，不构成投资建议。

## 6. 灰度与监控

- 先发布体验版，由内部审核人员走完整清单。
- 灰度期间每日核对抽取失败、分享还原失败、投诉和下线内容曝光。
- 实验以投诉率和审核风险为硬护栏；任何合规异常立即停实验。
- 上线后第一周抽样检查事件字段，确认无自由文本或新增隐私字段。

## 7. 回滚

- 内容风险：执行 `docs/content-review.md` 的单条下线或紧急熔断。
- 云函数异常：回滚到上一稳定云函数版本；客户端自动使用本地审核库。
- 客户端异常：暂停新版本，恢复上一审核通过版本；保留历史 `drawId` 数据，不迁移或重写。
