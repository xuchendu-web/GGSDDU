# 投资反思卡产品规格

## 1. 产品定义

一句话定位：面向个人投资者的“随机投资者教育摘句与决策反思工具”，用一张经人工审核的卡片，让用户在行动前后检查证据、纪律、风险、情绪与复盘过程。

首版免登录、免授权、无需输入问题。产品不采集用户心中所想，不读取行情、证券代码、持仓或好友关系，不接入下单。

### 成功标准

- 用户读完一页后更冷静、更愿意核对依据，而不是更想立即交易。
- 北极星指标：每周“由分享进入并完成首次翻页”的新增用户数。
- 护栏：内容投诉率、分享落地失败率、下线内容曝光量和审核驳回原因。

## 2. 八个首发场景

| 场景 | 用户状态 | 产品入口 | 期望行为 |
| --- | --- | --- | --- |
| 开盘前冷静 | 信息密集、急于行动 | “开盘前”主题 | 核对计划、前提与承受范围 |
| 大幅波动后暂停 | 焦虑或后悔 | 泛用翻页 | 识别情绪，推迟冲动反应 |
| 连续上涨后防追随 | 害怕错过 | 泛用翻页 | 区分证据与群体热度 |
| 财务披露前检查假设 | 确信感过强 | 证据类卡片 | 写出反证与数据口径 |
| 收盘复盘 | 受单日结果影响 | “收盘后”主题 | 分开评价结果和过程 |
| 周末组合体检 | 需要全局视角 | “周末复盘”主题 | 检查目标、期限与风险来源 |
| 群聊争论降温 | 被观点音量牵引 | 分享同一页 | 回到一手来源与独立判断 |
| 新手开启话题 | 不知如何讨论风险 | 朋友分享落地 | 从反思问题开始交流 |

## 3. 核心流程

1. 首页说明“想好一个投资问题”，同时明确“无需输入，也不会采集”。
2. 用户点按封面、主按钮或三个主题入口。
3. 本地或云端从有效人工白名单随机返回一页；页面展示短答、反思问题和适用边界。
4. 用户可收藏到本机，或通过微信原生分享“送给朋友”。
5. 分享链接仅携带不可变 `drawId` 和固定来源标记；朋友看到同一页。
6. 分享落地用户可“翻自己的第一页”，形成自然二代传播。
7. 最近 20 条和收藏默认仅在本机保存，弱网仍可使用本地审核内容。

### 异常与降级

- 云函数失败：从打包的审核白名单本地抽取，显式标记“本地审核内容”。
- 分享记录不存在：展示无法打开状态并提供返回首页。
- 内容远程下线：分享还原不再展示正文，返回不可用状态；禁止自动映射成另一条内容。
- 全主题内容被下线：云函数返回 `NO_APPROVED_CONTENT`，客户端回退到本地白名单；紧急熔断时应同步发布禁用本地内容的新版本。

## 4. 增长闭环

闭环：完成首翻 → 收藏或送给朋友 → 好友查看同一页 → 好友翻自己的第一页 → 再次分享。

- 分享卡展示完整结论语境，文案为“这页让我想到你”或“送你一张投资反思卡”。
- 不以分享换次数、积分、内容或权益；不做好友助力、排行榜或诱导分享。
- `parentDrawId` 只用于匿名入口归因，不建立或推断好友关系。
- 首轮实验：点按/长按提示、500/1000ms 动效、两种分享文案、泛用/主题入口。
- 分组由匿名标识稳定散列；实验结果不能改变内容合规边界。

## 5. 指标与事件口径

| 事件 | 触发点 | 必要字段 |
| --- | --- | --- |
| `home_view` | 首页展示 | `attribution` |
| `draw_start` | 发起抽页 | `theme` |
| `draw_complete` | 页面展示成功 | `drawId`, `cardId` |
| `favorite_add/remove` | 本地收藏变更 | `cardId` |
| `share_initiated` | 生成分享消息 | `drawId` |
| `share_landing_view` | 分享页还原成功 | `drawId`, `cardId` |
| `shared_user_draw_start` | 分享用户翻自己的页 | `parentDrawId` |
| `restore_failed` | 分享还原失败 | `drawId` |

派生指标：

- 首翻完成率 = `draw_complete` 去重用户 / `draw_start` 去重用户。
- 分享率 = `share_initiated` 去重用户 / `draw_complete` 去重用户。
- 分享打开到首翻转化 = 带 `parentDrawId` 的 `draw_complete` 去重用户 / `share_landing_view` 去重用户。
- 二代分享率 = 分享落地用户后续 `share_initiated` 去重用户 / `share_landing_view` 去重用户。
- D1/D7 仅使用匿名访问标识做留存统计，不拼接外部身份。

事件接口执行名称白名单与字段白名单。不得上传问题文本、证券代码、持仓、通讯录、好友关系、自由文本或设备指纹。

## 6. 内容与文案规范

- 结论只涉及证据质量、风险意识、决策纪律、情绪觉察和复盘。
- 每页必须同时展示短答、反思问题、适用边界、版本和审核状态对应的数据记录。
- 使用“翻开一页”“随机一页”“投资反思卡”等中性表达。
- 对外禁用：神秘化、求签式或确定性行情表达；个股和具体产品；买卖指令；目标价；收益或胜率承诺；模拟官方或持牌投顾口吻。
- 不因免责声明而放宽正文审核。免责声明不能替代产品实质合规。

## 7. 数据与隐私

云端集合：

- `draws`：`drawId`, `cardId`, `createdAt`, `attribution`, `experiment`。
- `events`：事件名、时间、匿名标识和白名单字段。
- `content_config/active`：远程下线的 `offlineCardIds`。

保留策略上线前由主体根据最小必要原则确定并写入隐私政策。日志禁止记录完整请求体。客服排查仅凭 `drawId` 定位，不反查社交关系。

## 8. 明确不做

首阶段不做 AI 问答、UGC、行情、个股分析、模拟交易、付费抽页、订阅营销、排行榜、好友助力或交易接口。
