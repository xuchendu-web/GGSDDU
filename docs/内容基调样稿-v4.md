# 内容基调样稿 v4

只供确认。本轮**不改** 220 条、HTML、DOCX。

**废弃 v3：** 随机翻书不可能知道读者当时上涨、下跌、盈利、亏损、踏空或犹豫。答案不能预设任何状态。按涨/跌/踏空/套牢/横盘分类的方案作废。成书仍然一页一句、不标分类、不按心情分章。

读者带着未知心情来。翻到的那句必须：**红着读得通，绿着读得通，手指悬着也读得通**——三种对法不同，不是同一条纪律套三次。

## 内容公式

**一句 = 不带方向的股市物件或场景 + 情绪出口 + 意外滑一下。**

- **股市语境：** 明确或隐约。账户、软件、刷新、群、这一笔、盯盘、开盘收盘、行情、盘面、下单键、屏幕、佣金、成本、自选、委托、A 股夜里……读者听得出在交易桌前。
- **不带方向：** 正文不写涨了/跌了/红了/绿了/涨停/跌停/踏空/套牢/浮盈/浮亏/回撤/解套。那是读者自己的天气，书不知道。
- **情绪出口：** 被看见、被轻轻拆穿、被允许不表演。不是被指导。
- **三向适配（硬门槛）：** 写下后必须能答「上涨时如何成立 / 下跌时如何成立 / 犹豫时如何成立」。任一牵强，整条淘汰。三种成立方式必须是三种心情，不能都是「所以别下单」。
- **人生解答书：** 短、轻、一本正经地胡说。看似答非所问，对号入座是读者的事。

## 淘汰标准

- 预设状态：离开红绿涨跌踏空套牢，句子塌掉
- 三向同一：三条检验都在说「别交易 / 去洗脸」
- 说教：纪律、规则、计划、复盘、仓位、止损不是认输、因为所以
- 指令与预测：买、卖、加、减、会涨、会跌、到底了
- 点名与数字：个股、基金、点位、收益率
- 术语梗：只靠 K 线、涨停、均线抖机灵，没有情绪
- 泛人生鸡汤：先吃饭、出门右转、月亮不管——没有股市家具，谁的人生书都能用
- 同质：条条问句、条条「先别发」、条条「它不回微信」
