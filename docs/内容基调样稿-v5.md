## 六类机制

### 1. 自我原谅

不是「亏损没关系」的鸡汤，是把**这一笔/这一分钟**从永久判决降成手滑、过期验证码、不记考勤。人还在原价。

出口：被允许不当天才，也不当犯人。

### 2. 允许错过

不是喊你空仓，是承认**站名、请柬、叫号、窗口**本来就不是为你开的。错过是一种到站，不是旷课。

出口：FOMO 被看见，又被降级成误车，不必补票。

### 3. 庆祝小确幸

庆祝的不是盈亏，是**验证码一次对、行情没卡、客服没来电、分红够一瓶汽水、利息很小但是真的**。小，而且可核对。

出口：今天仍有一笔完成的小事，不靠盘面盖章。

### 4. 嘲讽确定性

嘲的是词：**稳了、一定、百分之百、目标价、闭环、均线宣誓、明天**。公章、句号、手印全是假的。

出口：把「我算准了」轻轻拆穿，不换成另一套预测。

### 5. 接受荒诞

同一则消息两种天气；开盘像抽签；原因今晚不补写。市场在即兴，人不必当编剧。

出口：笑一下荒诞，就不用立刻解释。

### 6. 朋友式陪伴

书坐旁边，不坐庄。看见盘面，也看见你。不懂这一笔，不抢着下单，不索要账户截图。

出口：有人在，且不把陪伴变成合谋。

## 三向抽检

每类 3 条。上涨 / 下跌 / 犹豫必须是三种心情。

### 自我原谅

**1 这一笔可以当手滑。**

- 上涨：追那一下，允许当成手滑，不必封神。
- 下跌：逃或补那一下，允许当成手滑，不必请罪。
- 犹豫：差一点按下去，允许当成手滑，不必立人设。

**6 漏看一条公告。世界没塌。**

- 上涨：漏了别人正在庆祝的那条，人还在。
- 下跌：漏了别人正在恐慌的那条，人还在。
- 犹豫：没读完就不敢动，允许没读完。

**10 错价了。人还在原价。**

- 上涨：买贵了，人没有因此升值成天才。
- 下跌：卖便宜了，人没有因此贬值。
- 犹豫：怕错价所以悬着，人仍是原价。

### 允许错过

**11 板块轮动没写你的站名。**

- 上涨：这班热闹没停你这站，允许误。
- 下跌：这班砸下来也没点你的名，允许不追着跳。
- 犹豫：轮到谁都像在叫你，站牌上没有你。

**12 别人的自选，不是请柬。**

- 上涨：别人的名单在发光，不是请你入席。
- 下跌：别人的名单在哭，不是请你陪葬。
- 犹豫：借来的名单，仍不是请柬。

**20 错过也算一种到站。**

- 上涨：没坐上那班，也算到了「没坐上」。
- 下跌：没及时走，也算到了「没走成」——先被看见，不判刑。
- 犹豫：一直没点，也是一种抵达。

### 庆祝小确幸

**21 验证码一次对了。**

- 上涨：激动里仍有一件小事做成了。
- 下跌：难受里仍有一件小事做成了。
- 犹豫：纠结里仍有一件小事做成了。

**24 分红到账。够一瓶汽水。**

- 上涨：大数字旁边，有一笔能摸到的小真钱。
- 下跌：大伤口旁边，有一瓶汽水级的真钱。
- 犹豫：不必等方向，汽水已经进账。

**30 利息到了。很小，是真的。**

- 上涨：真的小钱，对比幻觉里的大赚。
- 下跌：真的小钱，对比幻觉里的大亏。
- 犹豫：真的小钱，对比还没发生的决定。

### 嘲讽确定性

**31 稳了这两个字，没公章。**

- 上涨：群里喊稳了，想加盖喜悦。
- 下跌：群里喊到底了稳了，想加盖止疼。
- 犹豫：自己心里喊稳了，想结束悬着。

**37 明天两个字，尚未上市。**

- 上涨：明天会更高——那两个字还没上市。
- 下跌：明天会回来——那两个字还没上市。
- 犹豫：明天再决定——那两个字还没上市。

**38 均线不会宣誓。**

- 上涨：均线不是来给你作证的。
- 下跌：均线不是来给你宣判的。
- 犹豫：均线不宣誓「可以点了」。

### 接受荒诞

**41 同一则消息，两种天气。**

- 上涨：同一条被读成晴。
- 下跌：同一条被读成暴雨。
- 犹豫：两种天气叠在一条上，所以动不了。

**42 开盘像抽签。筒还在摇。**

- 上涨：抽到喜，筒还在摇，不是天命。
- 下跌：抽到疼，筒还在摇，不是针对。
- 犹豫：筒还在摇，答案不会先掉出来。

**48 原因会补写。今晚没有。**

- 上涨：胜利叙事还没写好。
- 下跌：失败叙事还没写好。
- 犹豫：行动理由还没写好。今晚可以没有。

### 朋友式陪伴

**51 嗯。盘面我看见了。**

- 上涨：看见你想被看见的那面。
- 下跌：看见你不想被看见的那面。
- 犹豫：看见你悬着的那面。都不追问。

**53 并排坐。不并排下单。**

- 上涨：陪着，不跟着追。
- 下跌：陪着，不跟着砍或补。
- 犹豫：陪着，不把陪伴变成合谋。

**54 我也不懂这一笔。**

- 上涨：这喜，我也不装懂。
- 下跌：这疼，我也不装懂。
- 犹豫：这悬，我也不装懂。人还在。

## 淘汰清单

### 三向同一（都在说别交易 / 去休息）

今日操作次数可以是零；条件单没触发你也没触发；今天佣金是零人还在；直播间上车可以错过（指令口吻）。

### 与 v3/v4/研究候选过近

龙虎榜有座位不是你的；盘面在即兴剧本是空白；这出戏道具先到；截图不用发我；钥匙我帮你拿着；椅子没响你也没响；配号去旅行了（近「成本价去旅行」）；别人的红未读变体。

### 核心禁区 / 身体出口过密

锁屏前窗外有云；银证转出成功晚饭有着落；网络满格先喝一口；周末休市章已盖（近睡觉）；如果要走门没上锁（离席）；风从自选吹过窗可以关；这杯水给你；分时图在哭你去炒菜的近亲。

### 预设涨跌或术语当笑点

主升浪没留联系方式；铁底是铝合金的；底部这个词很会搬家；支撑位很害羞；政策底市场底你的底；涨跌停是围栏。

### 说教 / 课堂词

复盘笔记可以撕；风险揭示书今晚可以不背；适当性匹配不匹配心情；T+1你也给自己+1；复盘结论有效期一天；我们不复盘我们坐着；话术很满仓位是别人的。

### 同骨架超限或连续模板

废单不记仇 / 委托编号会作废（近撤单）；密码输错了人也行（近验证码）；点错板块人还在地球（近手滑）；机会没有挂号条 / 号已经叫到别处（近不叫号）；那班车可以误 / 这班飞机可以误机（近错过到站）；水杯满的、热水壶、绿植、地铁有座、伞在包里（生活对比连发）；必然发生在嘴上（近一定）；同一个按钮两种命运（近同一则消息）。

### 股市家具不够 / 泛人生

肩还在靠一下；窗开一条缝；雨还在下人还在屋；茶凉了也算陪；充电线还在原处；快递取了；指南针在转路还没修；一只蝴蝶好几个按钮。

### 攻击、迷信、荐股近亲（池内试写即弃）

未采用天台、开光、跟着买、会涨会跌、个股名。
