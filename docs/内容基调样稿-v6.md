# 内容基调样稿 v6

路线 **A** 已确认。本轮**不改** 220 条、HTML、DOCX、小程序。

**不在此编问题、不做三向配对。** 抽页测试由协调器「先锁问题再抽页」完成。

不得复用 v3 / v4 / v5 / 语料研究六十条正文。内部先写 **80** 条，筛到 **30**。
