# 网络减压语料研究

本轮**不改** 220 条、HTML、DOCX。只扩公开中文语料，提炼表达机制、词汇场与节奏，供后续基调确认。成书仍按 v4：状态无关、随机翻页、一句一页。

访问日期（除非另注）：**2026-09-17**。只采可打开的公开页；付费墙、登录墙内不可核验正文不引用。**严禁把他人句子搬进候选句**；来源里的金句只作机制标本，正文一律改写。

## 方法

1. **搜什么：** A 股股民调侃、股吧/雪球情绪、职场与生活减压段子、反高潮、自嘲、拟人、装傻、把大事说小。
2. **抽什么：** 机制（预期怎么铺、包袱怎么滑、情绪怎么泄）、词汇场（物件、动词、口吻）、节奏（短句、两截、冷收）。不抽可复述的成句。
3. **不抽什么：** 荐股话术、天台/轻生梗、迷信开光、点名个股/基金、攻击他人的脏话段子、付费墙正文。
4. **迁到股市解答书：** 保留「被看见、被拆穿、被允许不表演」；物件换成交易桌家具；正文不带涨跌红绿方向词。

对照口径：`docs/内容基调样稿-v4.md`。本文件 60 条是**新写候选**，不与 v4 三十条撞正文。

## 2. 十类幽默与舒缓机制

机制从语料归纳，**不是**把源句改几个字。迁移时只借结构。

### 2.1 把大事说小（轻描淡写 / understatement）

标本：「关灯吃面」不写连续跌停，只写灯与面。大事缩成生活琐事，痛还在，但不表演痛。

节奏：物件很小 + 动作日常 + 不解释。

股市迁移：灯、面、午休、倒水、钥匙、口袋。禁止把「关灯吃面」当答案正文。

### 2.2 自嘲换同盟（打工人 / 小丑 / 韭菜的自用义）

标本：自称打工人、小丑竟是我自己——先把自己放低，换共鸣，不是骂对面是韭菜。

节奏：身份词轻轻戴上，立刻滑开，不控诉体制。

股市迁移：你把心跳交给刷新；自尊放进自选。禁止对读者说「你就是韭菜」。

### 2.3 拟人：物有脾气，人可以下班

标本：修辞学拟人；职场把工位、闹钟当对手。期货圈把零件拟人，机制同，不搬具体梗。

节奏：主语是键、佣金、委托、分时；谓语是人的动作（加班、喘气、握手、道歉）。

股市迁移：佣金不站队；下单键没有心跳。物越冷，人越被允许热过就走。

### 2.4 反高潮 / 预期违背（铺陈 + 包袱）

标本：相声三翻四抖；冷笑话后半脱轨；纽约时报文中的书单从教材滑到《活着》（只借「清单越来越不像投资」的滑法，不抄书单）。

节奏：前半像要给结论，后半落到生活或拒绝服务。两截即可，神谕太短，翻一次就够，不必三番。

股市迁移：开盘是上班。不是开庭。 / 你在等答案。软件在等电。

### 2.5 装傻 + 旁边有人拆穿

标本：漫才装傻役 / 吐槽役；相声捧逗。神谕里「装傻」是盘面、软件、群；「吐槽」是后半句冷冷点破。

节奏：一本正经的错认（开盘=开庭、红点=作业）+ 一句拆穿。

股市迁移：软件的红点，不是作业。读者自己当吐槽役。

### 2.6 补刀：已够窘，再轻轻一刀

标本：北大 CCL「补刀」= 对方已不利再挖苦；过了是没教养。神谕的补刀必须轻、对事不对人、给台阶。

节奏：前句已经看见你，后句把表演道具拿走（颁奖台、旁白、印章）。

股市迁移：这一笔没有颁奖台。禁止补到羞辱、天台、家暴式比喻。

### 2.7 职场错位：交易桌 = 工位

标本：打工人语录把KPI、早会、工牌、下班铃错位到生活。股民盯盘本就像上班。

节奏：上班家具（工牌、评优、作业、开会、主持）焊到盘面上，人被允许摸鱼。

股市迁移：行情没有工牌；盯盘像开会。没人主持。

### 2.8 食物等级与身体出口

标本：吃肉 / 喝汤 / 吃面；关灯吃面；问胃。身体比盘面诚实。

节奏：胃、口、灯、午休出场，行情没有义务管饭。

股市迁移：你饿了。刷新不能煮面。禁止复述吃面金句，禁止把亏损写成「创业」。

### 2.9 群与专家的热闹，椅子只有一把

标本：雪球「涨有人解释、跌有人解释」；股吧情绪传染论文；NYT 网络股神；财联社忽悠式荐股。

节奏：群很满、很热、很专家；键、椅子、署名是空的。

股市迁移：群里的结论，没有署名。专家在直播。你在生活。

### 2.10 冷收与拒绝服务（冷幽默）

标本：冷幽默「笑不笑由你」；人生解答书式答非所问；打工人假鸡血。

节奏：短、句号硬、不解释因为所以。允许敷衍得庄严。

股市迁移：夜里没有集合竞价。钥匙在口袋。不在软件里。

## 3. 股市可迁移词汇 / 句式骨架

### 3.1 词汇场（家具，不带方向）

| 类 | 可用 | 慎用（易滑向术语梗或红线） |
| --- | --- | --- |
| 物件 | 账户、软件、屏幕、刷新、键、委托、队列、自选、佣金、成本、通知、红点、椅子、耳机、群、截图、分时、集合竞价、开盘铃、工牌、口袋、钥匙、胃、灯 | K线、均线、龙虎榜（点到为止）、北向（点到为止） |
| 人 / 拟人对象 | 行情、盘面、委托单、下单键、分时图、持仓、专家、群 | 庄家、主力（易阴阳怪气攻击） |
| 动作 | 亮、跳、喘、加班、排队、握手、鼓掌、评分、写信、点赞、撤、关、摘、倒水 | 梭哈、抄底、护盘（易变指令或预测） |
| 生活错位 | 上班、开庭、宣判、作业、评优、颁奖台、旁白、印章、快递、开会、主持、午休、煮面 | 天台、上坟、坐牢（过狠） |

### 3.2 句式骨架（填家具，不填涨跌）

1. **物 + 人的拒绝：** `X不会Y。` / `X没有Z。`（握手、旁白、工牌、心跳）
2. **两截拆穿：** `A是B。不是C。`（开盘是上班。不是开庭。）
3. **你把心情放错地方：** `你把P交给了Q。`
4. **物很勤快，人不必：** `刷新键很勤快。你不必。`
5. **群很满，座位是你的：** `群里今晚很满。椅子只有一把。`
6. **身体出口：** `你饿了。X不能煮面。`
7. **时间空白合法：** `开盘前的空白，也是空白。` / `夜里没有集合竞价。`
8. **轻补刀：** `这一笔没有颁奖台。` / `截图会发黄。`
9. **装傻错认：** `软件的红点，不是作业。`
10. **许可撤退：** `委托可以撤。心情也可以。` / `观众可以离席。`

节奏偏好：六至十二字；两句只为转折；句号硬；少问句；不写因为所以。

## 4. 不适合使用的表达

### 4.1 陈词滥调（听过就滑走，没有情绪出口）

- 「时间的朋友」「做价值投资」「心态很重要」「投资有风险」当神谕
- 「利好茅台」及一切点名个股的万能归因
- 「吃肉喝汤吃面」等级表直接当答案（词汇场可借鉴，口号不可）
- 「关灯吃面」「天台见」「梭哈」「抄底抄到十八层」原文或近义拼接
- v1 课堂句：止损不是认输、仓位先降下来、满仓是情绪
- 条条「先别下单 / 去洗脸 / 先吃饭」而没有股市家具

### 4.2 攻击性

- 骂读者或他人韭菜、接盘侠、傻X、庄家不得好死
- 性别、地域、学历、职业贬损
- 补刀过线：家暴、侮辱身体、拿亲人开涮

### 4.4 荐股与预测（监管红线）

### 4.5 高敏感（看起来像段子，实际伤人）

- 天台、跳楼、绳子、安眠药、上坟、自杀物业告示
- 把亏损写成「创业了至少没累着」式冷血鸡汤
