# 课题交付明细：宽基 ETF 数据判断标定清单（v1.0）

> 用途：本清单是课题的核心交付物明细。以「沪深300 决策卡」的六个输出区块为骨架，逐条罗列系统需要研究所标定的**每一个数据判断项**。每项须明确三件事：**计算口径、判断标准（分档阈值）、数据来源**。
>
> 填写铁律（沿用《ETF模板补充要求》验收标准）：
> 1. 每个字段填**具体数值/公式/规则**，禁止"视情况而定""一般参考""结合市场情况"等模糊表述；
> 2. 数据来源明确到**具体机构或终端字段**（如 Wind: pe_ttm / 中证指数公司月报 / 美联储 H.15）；
> 3. 每项判断附**一句输出表述示例**（系统照此句式生成）；
> 4. 表中「沪深300 示例」列为示意值，研究所须复核修正后签字生效。
>
> 覆盖范围：以下全部标定项须对 8 只 P0 宽基逐一填写（沪深300、上证50、中证500、中证1000、中证A500、科创50、创业板指、深证100）。指数间通用的规则填一次，指数特有的（可比清单、估值中枢、风险库）逐只填。
