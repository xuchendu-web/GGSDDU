# 课题交付明细：宽基 ETF 数据判断标定清单（v2.0 全维度版）

> 用途：本清单是课题的核心交付物明细，覆盖宽基 ETF 分析所需的**全部数据判断项**。v2.0 在 v1.0（对齐沪深300 决策卡六区块，约 75 项）基础上新增七类维度，重组为 **10 个维度（D1-D10）**，共约 120 项。
>
> 每项须由研究所明确三件事：**计算口径、判断标准（分档阈值）、数据来源**。
>
> 填写铁律：
> 1. 每个字段填**具体数值/公式/规则**，禁止"视情况而定""一般参考"等模糊表述；
> 2. 数据来源明确到**具体机构或终端字段**（如 Wind: pe_ttm / 中证指数公司月报 / 中金所结算数据）；
> 3. 每项判断附**一句输出表述示例**（系统照此句式生成）；
> 4. 标注「新增-须论证」的项不接受纯经验值，须附历史数据论证或回测支持。
>
> 覆盖范围：全部标定项对 8 只 P0 宽基逐一适用（沪深300、上证50、中证500、中证1000、中证A500、科创50、创业板指、深证100）。通用规则填一次；标注【逐只】的项按指数逐一填写。
>
> 优先级：P0 = 决策卡首版必需；P1 = 首版后第一轮增强；P2 = 机构定制项。
