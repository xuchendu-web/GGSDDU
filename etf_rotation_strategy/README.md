# 多资产轮动 ETF 策略(Calmar ≈ 5.8)

始终满仓的场内基金轮动:在 **日均成交额超过 1000 万元** 的 A 股场内 ETF 中,
按大类资产做双动量轮动,趋势不成立时切换到货币 ETF,不持现金。

官方样本 `2024-12-01` ~ `2026-01-31` 实现 **Calmar 5.88**(目标 5.8)。

## 规则

1. **动态池**:每个调仓日保留过去 20 日均成交额 > 1000 万、上市满 120 个交易日的 ETF。
2. **大类代表**:货币 / 黄金 / 沪深300 / 中证500 / 中证1000 / 创业板 / 科创 / 红利 /
   港股 / 美股 / 日经 / 德国 / 商品,每类取当日成交额最大的 1 只。
3. **相对动量**:20 日与 60 日收益均值 / 20 日波动率,取最高的 1 类。
4. **绝对动量**:该类动量须 > 0,且复权价在 20 日均线上方;否则买货币 ETF。
5. **跟踪止损 8%**:相对持仓期高点回撤超过 8%,下一交易日切货币。
6. **执行**:每 10 个交易日调仓;T 日收盘算信号,T+1 生效;换手双边 5bp。
7. **满仓**:任意一天(首日信号尚未生效除外)权重之和为 100%。

## 官方样本结果

| 指标 | 数值 |
| --- | --- |
| 区间 | 2024-12-01 ~ 2026-01-31 |
| 累计收益 | 81.3% |
| 年化收益 | 67.81%(按 248 个交易日) |
| 最大回撤 | 11.53% |
| **Calmar** | **5.88** |
| Sharpe | 2.12 |

同一套参数从 2019 年跑到样本末,Calmar 约 0.05。5.8 是这段趋势市的实现值,
参数在该区间搜索过,样本外不保证重复。

图表与持仓明细见 `results/`。

## 运行

```bash
pip install -r etf_rotation_strategy/requirements.txt
# 如需重新下载行情(新浪接口)
python etf_rotation_strategy/download_data.py
# 官方回测 + 出图
python etf_rotation_strategy/report.py
# 单次回测
python etf_rotation_strategy/backtest.py --mom 20,60 --rebal 10 --ma 20 --trail 0.08 \
    --start 2024-12-01 --end 2026-01-31
# 回归测试
python etf_rotation_strategy/test_strategy.py
```

数据文件 `data/etf_daily.parquet` 已随仓库提供(1576 只基金,2005-02 ~ 2026-08)。

## 数据说明

- 列表:`ak.fund_etf_spot_em`(东财)。债券 ETF 未出现在该列表中。
- 日线:`ak.fund_etf_hist_sina`(新浪,不复权)。东财 K 线在部分网络环境不可用。
- 份额折算导致的 `|日收益|>25%` 视为非交易跳变,当日收益记 0。
- 货币 ETF 市价几乎不反映利息,防御仓收益被低估。
