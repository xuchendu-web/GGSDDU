# 多资产轮动 ETF 策略(2022–2026,每次 1 只)

在 **日均成交额超过 1000 万元** 的 A 股场内 ETF 中做大类双动量轮动。
**每次只持有 1 只**,趋势不成立时切换到货币 ETF,不持现金。

官方样本 `2022-01-01` ~ `2026-08-14`:累计 **+136.9%**,年化 21.1%,最大回撤 17.8%,Calmar **1.18**。

## 规则

1. **动态池**:每个调仓日保留过去 20 日均成交额 > 1000 万、上市满 120 个交易日的 ETF。
2. **大类代表**:货币 / 黄金 / 沪深300 / 中证500 / 中证1000 / 创业板 / 科创 / 红利 /
   港股 / 美股 / 日经 / 德国 / 商品,每类取当日成交额最大的 1 只。
3. **每次 1 只**:在代表中取 10/20/60 日波动率调整动量最高者。
4. **绝对动量**:动量须 > 0,且价格在 20 日均线上方;否则买货币 ETF。
5. **跟踪止损 5%**:相对本轮持仓高点回撤超过 5%,下一交易日切货币;换仓才重置高点。
6. **执行**:每 10 个交易日调仓;T 日收盘算信号,T+1 生效;换手双边 5bp。

原先 Calmar 5.8 只出现在 2024-12 ~ 2026-01 的约 14 个月窗口。按本次要求拉长到
**2022–2026 全区间** 后,2022 熊市会留下回撤,同一类满仓单只轮动做不到 Calmar 5.8。
