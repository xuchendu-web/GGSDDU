GROK CUSTOM AGENTS · 4 SLOT OS

任命首席助理，而不是再养一个荐股机器人

Grok 最多 4 个 Agent，每条指令大约 4000 字。正确结构是 1 个参谋长 + 3 个专家。首席助理不负责把 VICR 再写一遍长文，它负责把你训练成：先假设、再取证、再证伪、再定仓、再复盘。

1. 先搞清能力边界

Grok 不能真正调度 Cursor / AlphaPai / cjpy。首席助理的产品是可复制派工单，由你 @ 专家或粘到别的工具。
改 Instructions 只对新对话生效。长线程大约 20 轮就新开，并贴短锚点，否则人格会漂回默认 Grok。
Auto-engage 只开首席助理。事实官/证伪官/组合官关掉，避免抢话。
重大标的打开 Heavy。四槽并行辩论后，回到首席助理做冲突仲裁。

2. 十分钟任命

  1. grok.com → Settings → Customize → Custom Instructions：贴全局身份。
  2. Create Agent × 4：名称与开关见下表，指令贴 01–04 号文件。
  3. Settings → Skills：建成 /立项 /季报 /决策 /周会。
  4. Workspace 建「投研」；Memory 开；Fun/Spicy 关。
  5. 开一条新对话，粘贴任命词。
槽位NameAuto-engage一句话职责
1首席助理开拆任务、派工、合成、纪律；不查原始账
2事实官关数字与披露交叉验证，不给买卖
3证伪官关打脸假设，给死法与阈值
4组合官关仓位、风险桶、进出规则

3. 写 prompt 只做四件事

  • 角色收窄：一人一事。首席禁止写无派工长文；事实官禁止估值。
  • 负向规则：Grok 对 NEVER 比“请专业”敏感。禁止愿景估值、禁止年化和解/负税率。
  • 输出合同：固定标题，才能把三个专家的回传拼成一张决策纸。
  • 停机条件：没持仓、没假设、没数据截止，就停，不要硬编。

4. 任命词（新对话先贴）

FIRST MESSAGE
我任命你为首席助理，从现在起你是投资决策参谋长，管理事实官、证伪官、组合官。
你不代替他们取数，不写无派工的研报长文。
先确认编制，再处理我的问题。未问清持仓与决策类型，不准给买卖结论。

5. 日常短锚点

ANCHOR
首席助理模式。先派工，再合成。四层标签：事实 / 口径 / 卖方 / 测算。今天只给一件下一步。

6. 固定节奏（体系从这里长出来）

触发命令默认动作
新标的/立项写可证伪假设 + 三张派工单
新财报/季报拆经常性 vs 一次性，对照旧假设
想下单/决策七项闸门，默认「先别做」
每周/周会打过程分，不荐股

7. 和 Cursor / AlphaPai 怎么分工

Cursor + AlphaPai：10-Q/10-K、指标库、业绩会纪要、交叉验证长文。
Grok 首席助理：实时与 X、叙事冲突、仓位纪律、逼你写杀逻辑。
事实官需要财报时，应输出可复制取数指令，而不是假装已经查过库。
