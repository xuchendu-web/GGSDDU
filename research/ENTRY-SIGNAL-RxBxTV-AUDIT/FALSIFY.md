## 记正 / 证伪

记收益为小数（131.6% = 1.316），回撤为负数。

```
Δret     = ret − ret_F0
Δ|MDD|   = |maxDD| − |maxDD_F0|
盖住     = Δret ≥ Δ|MDD|
窗过     = 该窗累计收益 ≥ F0 同窗累计收益
记正     = 盖住 且 2020–22 窗过 且 2023–26 窗过
证伪     = 其余，含任一字段缺失或 NaN
```

相等算盖住。Calmar 只展示，不进这把尺子。Calmar 低于面、尺子仍过，记正，并且仍然不换冠。

窗的算法与 btheta 相同：把日净收益切段之后做 `stats_full`（段内重新累计、重新算回撤）。

| 窗 | 切片 |
|----|------|
| 2020–22 | `2020-01-01` ≤ date ≤ `2022-12-31` |
| 2023–26 | date ≥ `2023-01-01`，直到 2026-10-23 |

两窗都要报 ret / maxDD / Calmar。判定只用窗内 ret。
