## 主口径冻结（只选一种）

候选有四种写法，本卡**只冻结第一种**。后三种不进四件套、不作并列主簿。

| 候选 | 公式（窗止于信号日前一交易日） | 本卡 |
|------|-------------------------------|------|
| **相邻窗 OLS Δβ（主）** | 取连续 2N 根日 qfq 收盘。旧窗 = 前 N 根，新窗 = 后 N 根（不重叠）。各窗 `ln(P_i) = α + β·t_i`，`t_i = 0…N−1`（交易日下标）。`accel = β_new − β_old`。硬闸：新开要求 `accel` 有限且 `accel > 0`。N=40，`min_bars=80` | **冻结**。离散二阶导：斜率本身在加快。符号与 `Δslope_ann` 相同（`slope_ann = e^{β·252}−1` 对 β 严格递增），闸用 raw Δβ，不年化、不乘 R² |
| 套叠窗 `β_N − β_{2N}` | 短窗嵌在长窗里 | **不跑**。重叠高通，和相邻窗可以换号；夹具锁住实现必须走出相邻窗 |
| ROC-of-ROC | `(P_t/P_{t−N}−1) − (P_{t−N}/P_{t−2N}−1)` | **不跑**。这是原始收益二阶差，靠近已闭合的 RET\*，不是斜率族的 OLS |
| ΔS20 / ΔClenow | Sharpe 或 #1 score 的时差 | **不跑**。ΔS20 是 S12/S40 的近亲；ΔClenow 是 #1 再来一次 |

选相邻 40+40、不选 60/90 的理由（设计选择，不是回测结论）：

1. 80 根回看 ≠ #1 的 N=90 / 邻档 N=60。本刀不插值 #1 的窗。
2. 40 个交易日 ≈ 8 周，两段合成 ≈ 16 周。短于 Clenow 主窗，长于 S20 的 20 根收益，避免「又扫一遍 Sharpe 窗」。
3. 硬闸挂在 S20 填席之后：问的是过滤，不是换键。

禁止在看到结果之后改成套叠窗、ROC-of-ROC、ΔS20、年化差当另一本、或把主簿改成「叠在 SR90 上」。

### 回看价格与加速度

价格与 `sharpe_n_on` 同一条日 qfq 收盘。截止：**信号周五的前一交易日**。`(signal − last_bar).days > 5` → 缺失。

```
ols_beta(px[0…n−1]):
    若根数 < n 或任一收盘 ≤0 或非有限 → None
    y_i = ln(P_i)                         # 最老→最新
    t_i = i                               # 交易日下标，不是日历日
    Sxx = Σ (t_i − t̄)²
    Sxy = Σ (t_i − t̄)(y_i − ȳ)
    若 Sxx ≤ 0 或非有限 → None
    β = Sxy / Sxx
    若 β 非有限 → None
    返回 β
    # 价格全平 → β = 0（有定义）。不因 Syy=0 判缺失——那是 #1 的 R² 无定义，本卡不算 R²

accel_on(closes, d, n):
    sub = closes[: d − 1 日]
    若 (d − sub.index[-1]).days > 5 → None
    window = sub 的最后 2n 根
    若根数 < 2n → None
    β_old = ols_beta(window[0 : n])
    β_new = ols_beta(window[n : 2n])
    若任一为 None → None
    返回 β_new − β_old
```

| 键 | `n` | `min_bars` | 闸 |
|----|-----|------------|-----|
| AG40（主） | 40 | 80 | 硬闸 `accel > 0` |
| AG20（窗邻档） | 20 | 40 | 硬闸 `accel > 0` |
| AG40S（机制邻档） | 40 | 80 | 无硬闸；S20 短名单内按 accel 取席 |

`min_bars = 2n`：两段都必须抽满 n 根，不允许 80% 凑合。这与 `sharpe_n_on`「必须满 n 根收益」对齐。

禁止：用信号日当天收盘、日历日当 t、跳过中间缺失日却仍宣称满 2n、用 510300 残差或 β、用指数 σ 年化、乘 R²、R² 地板、`β_new > 0` 另闸（「只要在涨」是 #3 / #1 已禁的斜率硬闸）、ER、与 S20 加权、套叠窗。

`accel ≤ 0`（含正好 0）**不能**过硬闸。两段斜率相同 = 匀速，不是加速。负斜率但 `Δβ > 0`（跌得更慢 / 开始抬头）**可以**过闸——这正是斜率的斜率，不是「只要上涨」。

## 证伪尺子

比较对象只有本次运行的 **F0**。不与 TV 网格 158.3% 比，不与 nob_ref 134.0% 比，不与 KB 旧对照 135.0% 比，不与 PR#67 的 131.9% 比，不与压缩突破 68.1% 比，不与 RET8 的 149.6% / MOM121 的 145.9% 横比，**不与 #1 的 SR90 72.8% 横比**（不同问）。

记收益为小数（131.6% = 1.316），回撤为负数。不等式与 ENTRY-SIGNAL 八格已锁的 `ruler.py` / residual-mom / Clenow 卡相同，不另造 0.9× 或 −2pp：

Δ|MDD|   = |maxDD| − |maxDD_F0|
盖住     = Δret ≥ Δ|MDD|
窗过     = 该窗累计收益 ≥ F0 同窗累计收益
惰性     = (id ≠ F0) 且 (
             持仓周集合 {(周五, frozenset(codes))} 与 F0 相同
