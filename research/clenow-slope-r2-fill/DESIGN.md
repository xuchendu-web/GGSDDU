## 主口径冻结（只选一种）

候选有三种写法，本卡**只冻结第一种**。后两种不进四件套、不作并列主簿。

| 候选 | 公式（窗止于信号日前一交易日） | 本卡 |
|------|-------------------------------|------|
| **年化指数斜率 × R²（主）** | `ln(P_i) = α + β·t_i + ε`，`t_i = 0…N−1`（交易日下标，不是日历日）；`slope_ann = e^{β·252} − 1`；`score = slope_ann × R²`；N=90，`min_bars=90` | **冻结**。Clenow 自述 / Following the Trend 幻灯：`annualized_slope = exp(slope)^252 − 1`，再乘 R²。[Clenow Tampa 2025](https://cmtassociation.org/wp-content/uploads/2025/01/Clenow-Using-Momentum.pdf) 代码里的 `×100` 只是百分数展示，**本卡用小数**（0.25 = 25%），排序不变 |
| raw `β × R²` | 不年化 | **不跑**。单位是「每日对数价格」，表上不可读；且因 `exp` 非线性 × 名字间 R² 不同，周内排序可以和年化式分叉。用户允许二选一，本卡选书上的年化式 |
| `(1+β)^252 × R²` | Teddy Koker 常见误写 | **不跑**。这是毛值年化，不是 `e^{β·252}−1`。[Teddy Koker 2019](https://teddykoker.com/2019/05/momentum-strategy-from-stocks-on-the-move-in-python/) 写 `((1+slope)**252)*(r**2)`（不减 1）。近亲误写 `(1+β)^{252}−1` 也不跑。夹具锁住实现必须走出 `exp(β·252)−1` |

文献边界（只约束本卡，不编造书内表格数字）：

- Clenow *Stocks on the Move* / Following the Trend：过去 **90 个交易日**的指数回归年化斜率 × 决定系数。R² 用来罚跳空和噪声，奖励平滑趋势。
- 年化惯例有 250 / 252 / 260。本卡冻 **252**，与仓库 `sharpe_n_on` 的 `√252` 同一交易日年。禁止 250/260。
- 125/250 双窗平均是筛股产品的另一指标，不是书上的 90 日主口径，**不进本卡**。
- 书上还有 SPX>MA200、ATR 仓位。那是门和 L，不是填席键。本卡不搬。

选「替换 S20」而不是「与 S20 互补」的理由（设计选择，不是回测结论）：

1. 本刀问的是填席键本身。互补 = `w·S20 + (1−w)·score`，是 MOM121 式合成，已证伪族。
2. residual-mom / skip-month 两张填席卡都冻「替换」。斜率族第一把对齐同一问法。
3. 若要事后说「S20 与斜率加权」，那是另一把刀，且必须先过本卡的替换问。

禁止在看到结果之后改成 raw `β×R²`、`(1+β)^252`、250 日年化、或把主簿改成 S20 互补。

## 精确规则

### 合格池与填席集合

每个信号周五 `t`，先看 `risk_on = (b ≥ 0.45)`。`risk_on` 为假：与 FACE 相同，E0 / `breadth_off` 出清，本周不填席。

`D_t`（当周冲击池）= 当周同时满足：

1. `in_play` 且 `in_play_kind == spike_ft`；
2. 不是 `box_pending` / `pending_second_week`；
3. 有有限的该书 `score`（主簿 / 邻档各自的 N 与 k）；
4. 在 AUM≥2 亿研究池内。

`D_t` **包含已持仓**（只要仍是 spike_ft 且 score 有限）。斜率×R² 是名字相对自身价格路径的属性，不因账上已有谁而改，也**不**减截面均值——那是 residual-mom。

`C_t`（填席集合）= `D_t` 减去当前持仓（与 btheta `build_cands(..., skip=set(positions))` 相同）。

斜率排序不要求 `|D_t| ≥ 2`（没有去均值）。`C_t` 为空：已持仓维持到 E0；**空席空着**。禁止回退 SHARPE20，禁止从非 spike 池补，禁止把缺失 score 回退成 RET12 / R12w / S20。

### 回看价格与 Clenow 分数

价格与 `sharpe_n_on` 同一条日 qfq 收盘。截止：**信号周五的前一交易日**。`(signal − last_bar).days > 5` → 缺失。

S20 今天坐在针 `05f0f8a4` 的

|------|--------|--------|

| `build_cands` | 261–284 | spike_ft 且有信号价；`skip=已持仓`；给每名算 sharpe |
| `simulate` 填席 | 339–349 | `require_sharpe=True` 后按 `rank_fn` 取 `slots = max_pos − 已持仓` |

本刀只在这个填席点把 `sharpe_n_on` / `sharpe_key` 换成 `clenow_score_on` / `clenow_key`。F0 仍走 Sharpe。breadth / spike / max5 / E0 / TV / 时钟 / 成本 / 宇宙不动。

```
clenow_score_on(closes, d, n, k):
    sub = closes[: d − 1 日]
    若 (d − sub.index[-1]).days > 5 → None
    window = sub 的最后 n 根
    若根数 < n → None
    若任一收盘 ≤0 或非有限 → None
    y_i = ln(P_i)                         # i = 0…n−1，最老→最新
    t_i = i                               # 交易日下标，不是日历日
    Sxx = Σ (t_i − t̄)²
    Syy = Σ (y_i − ȳ)²
    Sxy = Σ (t_i − t̄)(y_i − ȳ)
    若 Sxx ≤ 0 或 Syy ≤ 0 或非有限 → None   # 价格全相等 → R² 无定义
    β = Sxy / Sxx
    R² = (Sxy²) / (Sxx · Syy)
    若 β 或 R² 非有限 或 R² 落在 [0,1] 外（容差 1e-12）→ None
    slope_ann = exp(β · 252) − 1          # ≡ exp(β)^252 − 1
    若 slope_ann 非有限 → None
    返回 slope_ann · (R²)^k
```

| 键 | `n` | `min_bars` | `k` |
|----|-----|------------|-----|
| SR90（主） | 90 | 90 | 1 |
| SR60（窗邻档） | 60 | 60 | 1 |
| SR90K2（权邻档） | 90 | 90 | 2 |

`min_bars = n`：交易日窗必须抽满 n 根，不允许 80% 凑合。这与 `sharpe_n_on`「必须满 n 根收益」对齐。

禁止：用信号日当天收盘、日历日当 t、跳过中间缺失日却仍宣称满 n、用 510300 残差或 β、用指数 σ 年化、R² 地板、斜率>0 硬闸、加速度、ER、与 S20 加权。

负斜率**可以**进排序（会排在底部）。S20 也允许负 Sharpe。本卡不做「只要上涨」过滤器——那是加速度 / 地板刀的事。
