## 精确算法（主档 ρ*=0.85）

唯一被测旋钮是填席过滤器。B、TV、E0、max5、成本、时钟不离开面。

### 当周输入

信号周五 `t`（FACE 日历，≥14:30 决策）：

1. 宽度门 `b ≥ 0.45`。门关则空仓，不去重。
2. 已持仓走 E0。被踢的席空出来。
3. 存活持仓若仍 `is_spike`（`in_play` 且 `in_play_kind==spike_ft`，排除 `box_pending` / `pending_second_week`）则 **留在账上**。它们 **不因** 彼此相关超过 ρ* 被踢——本刀不加新出场。
4. 候选 `C`：当周不在账上、已过 `is_spike`、有有限 `SHARPE20` 的名字，按 SHARPE20 **降序**（并列 `code` 字符串较小者在前）。缺 Sharpe 的不进排序，与面相同。

### 相关定义（写死）

对任意一对代码 `(i, j)`，在 `t` 上的 `ρ_ij(t)`：

```
周收益 r_{k,w} = P_{k,w} / P_{k,w-1} − 1
P     = 日 qfq 收盘，对齐 FACE 日历周五
        （该周五无交易则取该周五之前最近一根交易日收盘）
窗    = t 之前已完成的 60 根周收益
        最后一根周收益结束于 t 之前的上一个日历周五
        t 当日收盘 / 14:30 价不进窗
ρ     = Pearson( {r_i,w} , {r_j,w} )，只在两名都有限的周上算
n_ov  = 两名都有限的周数
ρ_ij  = ρ   若 n_ov ≥ 40 且 ρ 有限
      = NA  否则
```

- 用 **收益** 相关，不用价格水平相关。
- 用 **Pearson**。不跑 Spearman / Kendall。
- 跳过条件是 `ρ_ij > ρ*`，**不是** `|ρ_ij| > ρ*`。负相关留下（分散）。
- `ρ_ij == ρ*` 留下（超过才跳）。
- `ρ_ij` 为 NA：**不当成超过**，该候选可入选（缺数据 fail-open），并计 `n_corr_na`。
- 价格序列与 `sharpe_n_on` 同一条日 qfq，只是重采样到周五。不要另开 14:30 价做相关（14:30 只服务 FACE 分类与成交）。

仓库扫描（只读，2026-10-26）：**没有任何分支发表过 60 周滚动收益相关矩阵**。`etf-correlation/data/research_pool_v2.csv`（PR#36 分支）只有 `code,name,index,family,l0,aum,…`，是池标签，**不是**相关矩阵。`CORR-R3` 的 60 日 ρ̄ **不能**当本刀输入。实施必须先做库存：有周收益缓存则 **现场算** 60 周 Pearson；两者都没有则 `BLOCKED`，禁止新抓数。见 `COMPOSER.md`。

`family` / `l0` **不是**相关的代理。标签只进事后诊断（最大同族只数、独立 family 数），不进跳过判定。

### 贪心填席

```
S ← 当周存活且仍 is_spike 的已持仓          # 种子；不因相关互踢
for c in C:                                  # 已按 SHARPE20 降序
    if |S| ≥ 5:
        break
    if 存在 s ∈ S，使 ρ_cs 有限且 ρ_cs > ρ*:
        skip c；n_dedup_skip += 1
    else:
        S.append(c)
# |S| < 5 允许。不从非 spike 池补，不降 ρ*，不把已跳过的名字按「次相关」拉回
```

席位权重：选中名字等权，再乘 TV25 的 L。空席变现金，收益 0。一手换手公式与面相同：`mean(Σ|Δ(L·w)| / 2)`。

F0：ρ* 关闭，不计算相关，`n_dedup_skip = 0`，`n_corr_na = 0`。填席退回面上的 `take[:slots]`。

### 算术夹具（不是策略数字）

执行方先过这三则，再碰面。它们只锁公式：

| 名 | 输入 | 应落在 |
|----|------|--------|
| 同列 | 两列完全相同的 60 根有限周收益 | Pearson ∈ [0.999999, 1.000001] → 对任何 ρ*∈{0.75,0.85,0.90} 都跳过 |
| 正交 | 60 根，一列常数交替 +1/−1，另一列与之错开使样本相关为 0 | Pearson ∈ [−1e-12, 1e-12] → 三档都留下 |
| 重叠不足 | 只有 39 根共同有限周 | 返回 NA → 不跳过 |

## 闸（相对 in-run F0 / FACE）

比较对象只有本次运行的 **F0**。不与压缩突破的 68.1% FACE 比，不与 TV 网格 158.3% 比，不与 RP-IV60 的 75.6% 比。

记收益为小数（131.6% = 1.316），回撤为负数。不等式与 ENTRY-SIGNAL 八格已锁的 `ruler.py` / Kaufman ER 卡相同，不另造 0.9× 或 −2pp：

```
Δret     = ret − ret_F0
Δ|MDD|   = |maxDD| − |maxDD_F0|
G1 盖住  = Δret ≥ Δ|MDD|
G2 后段  = 2023–26 累计收益 ≥ F0 同窗累计收益     # 参与闸：不踏空
G3 前段  = 2020–22 累计收益 ≥ F0 同窗累计收益
记正     = G1 且 G2 且 G3
证伪     = 其余，含任一字段缺失或 NaN
```

相等算过闸。Calmar 与 Sharpe 只展示，不进这把尺子。

| 窗 | 切片 |
|----|------|
| 2020–22 | `2020-01-01` ≤ date ≤ `2022-12-31` |
| 2023–26 | date ≥ `2023-01-01`，直到 2026-10-23 |

两窗都要报 ret / maxDD / Calmar。判定只用窗内 ret。G2 是本刀点名的 **2023–26 参与闸**：去重若把后段主线席位让成空仓或弱主题，即使全样本回撤变浅，仍证伪。
