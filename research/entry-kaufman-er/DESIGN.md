## 这刀回答什么

在冻结面上加一道**个券路径效率闸**。只挡新开与换入，已持仓不因 ER 跌破 θ 而平。

问的不是「再扫一遍 R / B / TV」，也不是「再叠 PT × COOL」。那两刀已经闭合，见下「跳过」。问的也不是压缩突破：那是周区间收窄后再向上破高，已经在另一条引擎上出过四件套。

本刀唯一新问题：Kaufman 效率比 `ER(N) ≥ θ` 能不能在**同一条 btheta 针**上改善新进质量，并且过已经写死的严格尺子。

## 公式（不另造）

Perry Kaufman 发表的效率比，原文写法见 [Kaufman Signals · Matching the Markets to the Strategy](https://kaufmansignals.com/matching-the-markets-to-the-strategy/)：

```
ER(t) = |C_t − C_{t−N}| / Σ_{i=t−N+1}^{t} |C_i − C_{i−1}|
```

- 分子：N 根之前收盘到今天收盘的净位移（取绝对值）。
- 分母：这 N 步每一根的绝对变动之和。
- 值域 [0, 1]。一路单边则 ER = 1；净位移为 0 则 ER = 0。
- 噪声不是波动率。横盘时分母可以很大、分子接近 0；单边大波动时 ER 仍可以高。
- ER **没有方向**。方向继续只来自面上已有的 `spike_ft` + SHARPE20。本刀不加 signed ER，不加 KAMA 的 Fast SC / Slow SC / SC²。

N 锁 **10**。来源只有已经写出来的默认，不在本仓里估：

| 出处 | 写下的 N |

| X 线索 | 默认 10（上引 Grok 帖） |
| TradingTact 回看区间 | 「多数市场 10–20」——区间上沿不进本刀 |

## 闸点

管线只加在 btheta `simulate.build_cands` 的出口。该函数已经 `skip=set(positions)`，所以进 pool 的都是**当周不在账上的名字**。新开（空席）和换入（E0 / breadth 让出席位）走同一条 `take[:slots]`。

| 闸点 | 规则 |
|------|------|
| 作用对象 | `build_cands` 里已过 `is_spike`（`in_play` 且 `in_play_kind==spike_ft`，排除 `box_pending` / `pending_second_week`）的新名 |
| 不作用 | 已持仓。不平旧仓、不重算 ER、不加 HYST / PT / COOL |
| 价格 | 与 `sharpe_n_on` 同一条日 qfq 收盘序列 |
| 截止 | 信号周五的**前一交易日**。`(signal − last_bar).days > 5` 视为缺失 |
| 长度 | 需要 N+1 = 11 根收盘。不够 → 闸失败 |
| 判定 | `ER` 有限且 `ER ≥ θ` 才进 pool；否则丢弃该名 |
| 补席 | 剩余 pool 继续按 SHARPE20 排序，取 `slots = max_pos − 已持仓`。过不了门的席位空着，不降 max5 规则、不从非 spike 池补 |
| 分母 0 / 非有限 | 闸失败（不能声称 ER≥θ） |
| F0 | θ 关闭，不计算 ER，`n_er_blocked = 0` |

这与 R 闸同一条管线（挡名、下一名补席），不是压缩突破准则稿里那句「跳过该席、不替换为下一名」。压缩突破的 `face_engine.py` 实际是 `continue` 换下一名，与它自己的准则稿不一致；本刀写死补席，避免再分叉。

R 闸（`ret_nd_on`，N∈{40,60,80}）本刀**不打开**。ER 不是动量符号，不能复用 R 的实现去「顺便」挡负收益。

## 证伪尺子

比较对象只有本次运行的 **F0**。不与压缩突破的 68.1% FACE 比，不与 TV 网格 158.3% 比，不与 R60 的 134.0% 比。

记收益为小数（131.6% = 1.316），回撤为负数。不等式与 ENTRY-SIGNAL 八格已锁的 `ruler.py` 相同，不另造 0.9× 或 −2pp：

```
Δret     = ret − ret_F0
Δ|MDD|   = |maxDD| − |maxDD_F0|
盖住     = Δret ≥ Δ|MDD|
窗过     = 该窗累计收益 ≥ F0 同窗累计收益
记正     = 盖住 且 2020–22 窗过 且 2023–26 窗过
证伪     = 其余，含任一字段缺失或 NaN
```

相等算盖住。Calmar 只展示，不进这把尺子。

| 窗 | 切片 |
|----|------|
| 2020–22 | `2020-01-01` ≤ date ≤ `2022-12-31` |
| 2023–26 | date ≥ `2023-01-01`，直到 2026-10-23 |

两窗都要报 ret / maxDD / Calmar。判定只用窗内 ret。

### 入场质量（只披露，不翻转旗标）

压缩突破主表用过这些列。本刀同样报，用来看「挡的是不是噪声」，不参与记正：

- `n_entries`：`take` 次数（新开+换入）

「邻档 hit-rate 与 win-size 同时优于 F0」只写旁注。不能把严格尺子的证伪改成记正。
