1. 假冲击是短窗现象。ER20 问的是「S20 看的那 20 根直不直」，不是 90 日长路效率。

### 回看价格、R²、ER

价格与 `sharpe_n_on` 同一条日 qfq 收盘。截止：**信号周五的前一交易日**。`(signal − last_bar).days > 5` → 缺失。

```
ols_r2(px[0…n−1]):
    若根数 < n 或任一收盘 ≤0 或非有限 → None
    y_i = ln(P_i)                         # 最老→最新
    t_i = i                               # 交易日下标，不是日历日
    Sxx = Σ (t_i − t̄)²
    Syy = Σ (y_i − ȳ)²
    Sxy = Σ (t_i − t̄)(y_i − ȳ)
    若 Sxx ≤ 0 或 Syy ≤ 0 或非有限 → None   # 价格全平 → R² 无定义 → 闸失败
    R² = (Sxy²) / (Sxx · Syy)
    若 R² 非有限 或落在 [0,1] 外（容差 1e-12）→ None
    返回 clip 到 [0,1] 的 R²
    # 不算 β，不年化，不乘 slope。β 符号不进闸

r2_on(closes, d, n=90):
    sub = closes[: d − 1 日]
    若 (d − sub.index[-1]).days > 5 → None
    window = sub 的最后 n 根
    若根数 < n → None
    返回 ols_r2(window)

kaufman_er(closes, d, n=20):
    sub = closes[: d − 1 日]
    若 (d − sub.index[-1]).days > 5 → None
    window = sub 的最后 n+1 根
    若根数 < n+1 → None
    denom = Σ_{i=1..n} |C_i − C_{i−1}|
    若 denom ≤ 0 或非有限 → None          # 全平 → 无定义 → 闸失败
    num = |C_n − C_0|
    若 num 非有限 → None
    返回 num / denom
```

| 键 | 地板 | 窗 | 闸 |
|----|------|----|-----|
| RF50（主） | R² ≥ 0.50 | N=90，`min_bars=90` | 硬闸；不算 ER |
| ER20（ER 邻档） | ER ≥ 0.40 | N=20，需 21 根收盘 | 硬闸；不算 R² |
| AND50（合取邻档） | R² ≥ 0.50 **且** ER ≥ 0.40 | 两窗各自满样本 | 任一缺失或不过 → 挡 |

`min_bars` 必须抽满，不允许 80% 凑合。这与 `sharpe_n_on`「必须满 n 根收益」对齐。

### 闸质量（只披露，不翻转旗标）

- `n_entries`：新开+换入次数

- `mean_abs_D`：`risk_on` 且 `|D_t| ≥ 1` 的周，对 `|D_t|` 取均值
