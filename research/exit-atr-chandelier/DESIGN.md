## 1. 对照面 FACE（冻结，只作尺子）

FACE 是研究侧账面，不是实盘冠军。规则保持 SPIKE-S20 延窗复核的原文：

- 池：研究池 `universe_replace_only_436.csv`，`aum ≥ 2`（324 只）。与实盘池分开。
- 时钟：信号周五 ≥14:30（周线收盘换成 `qfq_1430` 后做因果 classify）；成交同一周五收盘。
- 门：breadth ≥ 45%（face 列 `b` / `risk_on`）。门关则当周空仓，现金收益为 0。
- 选品：`spike_ft`，剔除 `box_pending` 与 `pending_second_week`；席位最多 5。
- 填席：`SHARPE20`。近 20 个日收益的均值/标准差 × √252，窗口严格止于信号日前一交易日。缺 Sharpe 的名字不参与排序。

## 2. 这刀回答什么

已测出场里，固定阈值与日历布尔都未站住：

| 刀 | PR | 机制 | 已判 |
|---|---|---|---|
| 止盈单腿 PT10/15/25 | #35 | 未实现 ≥ 固定 % vs `entry_px` | 证伪 |
| 亏损冷静 COOL4/6/8 | #37 | 上周组合收益 ≤ 固定 % → 下周空仓 | 证伪 |
| 最大持有 MH4/6/8 | #41 | 连续持有满 W 周强平 | 未系统性优于 FACE |
| PT15 × COOL6 | #52 / #59 | 两布尔交叉 | 证伪（Δret 盖不住 Δ\|MDD\|） |
| MH6 × rank-drop | #53 | 持有上限 × 掉出席位排名 | 证伪 |

这些刀的共同点：判决是**一次性布尔**——对照一个冻结水平（入场价、上周组合收益、持有周数、当周 classify 状态），本周是或否。路径上创过的高点不进入状态。

本族换机制：单票、入场后路径追踪。止损只随最高价上移，不回撤；距离用该票自身 ATR 计价，不共用一个 15%。问的是：在同一周频面上，**波动自适应的追踪出场**能不能在少吃回吐的同时，不踏空 2023–26。

H1（开跑前写死）：

> 主簿 `CH-ATR14×3` 相对 **当次重放的 FACE**，全样本满足 Δret ≥ Δ|MDD|，且 2023–26 累计收益不低于 FACE 的 2023–26、且自身为正。

H1 过 → `记正`（不换冠）。H1 不过 → `证伪`（不换冠）。邻档不能把失败的主簿救成 `记正`。

## 3. 与旧刀布尔差在哪

旧刀布尔（E0 + 已证伪出场）和新机制对照：

| | E0 结构布尔 | PT 固定止盈 | MH 日历布尔 | COOL 组合布尔 | 本族吊灯 |
|---|---|---|---|---|---|
| 输入 | 当周 classify：`falsify_close` / `always_in` / `in_play` | 现价 / `entry_px` | 持有周数 | 上一完整交易周组合收益 | 入场后最高价、Wilder ATR |
| 状态 | 当周快照，无记忆 | 无路径；高点不抬门槛 | 无价格 | 组合层，不看单票 | 路径：HH 只上不下 |
| 尺度 | 结构价（与波动无关） | 固定百分数 | 固定周数 | 固定百分数 | k × ATR（价单位） |
| 右尾 | 结构在就拿 | 到点就砍 | 到期就砍 | 急跌后空一周 | 新高抬止损，回吐才砍 |
| 本族态度 | **保留**，不替换 | 不重开、不交叉 | 不重开、不交叉 | 不重开、不交叉 | **唯一被测叠加** |

不是「把 PT15 的 15% 改成 3×ATR」。PT 的参照是入场价；吊灯的参照是入场后最高价。一个从入场横着砍，一个从高点吊下来。LeBeau 教科书里还有「最近 N 根最高价 − k·ATR」的滚动窗，那是另一刀，本族不做（见第 7 节）。

E0 与吊灯同一周五都触发：记 `exit_reason = chandelier`，E0 原因写入旁标 `e0_also`，两条计数都加。breadth 关闭与末日评估仍优先于吊灯。

## 4. 精确规则（主簿 CH-ATR14×3）

唯一改动：在 FACE 的 `simulate` 退出环里，E0 之前加一层单票吊灯。入场、填席、TV、成本、周五时钟、E0 原文不动。

### 4.1 时钟与价格

与 FACE 同一根针，不另造「14:30 决策 / 收盘触发」双价：

1. 决策日 = FACE 日历周五。
2. 触发价 = `simulate` 里的 `px_on`。延窗路径上，周五 weekly close 已被 `qfq_1430` 覆盖（`price_1430 × (day qfq 收 / sina 收)`）；映射失败则退回 weekly close，与 E0 当周用的是同一格。
3. ATR 与「已完成日」最高价的样本，**不含信号周五**，最后一根是上一交易日。
4. 持仓名单交给 `run_live_tv` 之后，日收益与 0.2% RT 仍按 FACE 原文（`COST_SIDE = 0.001`，`LIVE_COST_RT = 0.002`）。不要在吊灯里重写成交价。
5. `px_on` 不进入 ATR 的 TR；它可以进入当日 HH 代理，见 4.3。

### 4.2 Wilder ATR（日频，价单位）

用研究缓存 `research_cache/day/<code>.json` 的后复权 `o/h/l/c`，与 `qfq_1430` 同一条链。禁止用 sina 未复权高低和 qfq 收盘混算 TR。

```
TR_t = max( H_t − L_t, |H_t − C_{t−1}|, |L_t − C_{t−1}| )
ATR_N 的种子 = 前 N 根 TR 的算术平均
此后 ATR_t = (ATR_{t−1} × (N − 1) + TR_t) / N
```

主簿 N = **14**。这是 Wilder 平滑，不是 TR 的 SMA，也不是 `pandas.ewm`。样本不足 N 根已完成日、或任一根缺 h/l/c：该票该周 `atr_ready = false`，不发吊灯，E0 照旧。不要用收盘波幅、不要用 TV 的 σ20/σ60 冒充 ATR。

ATR 是价格单位。`k` 无量纲。禁止改成 ATR%（`k × ATR / close`）再拿去和 PT 比。

### 4.3 吊灯线（入场后路径，不是滚动窗）

对持仓 `p`，信号周五 `t`：

```
HH_done = max( 入场日（含）到 t 的上一交易日（含）的日高 )
HH_t    = max( HH_done, px_on )        # 当周决策价可抬高，不可压低
stop_t  = HH_t − k × ATR_t             # 主簿 k = 3
trigger = (px_on < stop_t) 且 atr_ready
```

`HH_t` 对一只持仓单调不减。回吐不降低止损。入场当周：若入场日就是 `t`，本周不对新开仓做吊灯（没有「入场后已完成日」）；E0 仍可当周出场。

同一周五吊灯触发：从持仓名单去掉，`exit_reason = chandelier`，后续净值仍走 `run_live_tv`。下一信号周五，该票若仍是 `spike_ft` 且过 SHARPE20 填席，允许重新入场。不加冷静（COOL 已证伪），不禁止再入。

### 4.4 退出优先级（写死）

对每个持仓、每个信号周五，按此顺序只留一个 `exit_reason`：

1. `eod_eval`（末日）
2. `breadth_off`（门关）
3. `chandelier`（本族，且 `atr_ready`）
4. E0：`falsify` / `always_in_flip` / `left_structure`（原文；与吊灯共用当周 `px_on`）

未退出则 `weeks += 1`，与 FACE 相同。不要在日频盘中砍仓，不要把吊灯做成组合层 overlay。

### 4.5 覆盖保险丝

持仓名字-周里 `atr_ready = false` 的比例记 `atr_skip_name_week_pct`。该比例 **> 5%**：整包 `BLOCKED`（数据不够，不是机制失败）。FACE 重放不走吊灯，不受此条约束。

## 6. 证伪尺子（相对 in-run FACE）

百分比差用百分点。`Δret = ret_book − ret_FACE`。`Δ|MDD| = |MDD_book| − |MDD_FACE|`，回撤变深时为正。

| 闸 | 过闸 |
|---|---|
| G1 收益盖住回撤 | `Δret ≥ Δ\|MDD\|` |
| G2 后段不踏空 | 2023–26 累计收益 `≥` FACE 的 2023–26 累计收益，且本身为正 |

两闸都打在**主簿**上。2023–26 的「不踏空」是 ≥ FACE，不是 PT/COOL 刀用过的「≥ 90% FACE」。分段边界与延窗 `metrics_row` 相同：2020-01-01…2022-12-31，以及 ≥2023-01-01。

Calmar、Sharpe、一手换手、吊灯次数是主表必报列，**不是第三闸**。Calmar 劣于 FACE 只旁注，不单独否决。2020–22 必须进主表；前段变弱、后段不踏空、且 G1 仍过时，可以 `记正`（与 HYST-M3 的记账方式相同）。前段不单独否决，后段踏空否决。

## 10. 文献边界（只约束本卡，不另开刀）

Chuck LeBeau 的吊灯出场是「近期极值减去若干 ATR」。长趋势里它是追踪止损，不是固定止盈。本卡把「近期极值」锁成**入场后最高价**，是为了直接对上已证伪的 PT（PT 从入场价横砍）。滚动 N 窗留给下一张卡。Wilder ATR 用他的平滑，避免和 TV25 的样本标准差混成同一种「波动」。Kim–Tse–Wald 的消融（趋势收益里很大一块来自波动缩放）提醒：本卡已经在面上留了 TV25，吊灯只许改出场，不许顺手改 L。
