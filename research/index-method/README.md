# 指数编制方法

本目录只存放已发布的指数编制规则比较，服务 ETF 报告里的「跟踪指数投资价值」一节。

当前文件：

- [`official-methodology-comparison.md`](official-methodology-comparison.md)：中证（CSI）、深交所（SZSE）、恒生（HSI）、标普（S&P）、MSCI、富时（FTSE）的官方方法对照、边界情形表和引用核对清单。

使用约束：

- 笔记比较规则，不记录成份、权重、行情、估值、规模或收益。需要这些数字时另取数，并单独标注日期。
- 单只指数的编制方案优先于本笔记。本笔记里的数字都绑在检索日和文件版本上，版本更新后要重读原文。
- 深证系列与国证系列、FTSE GEIS 与 Russell 美国指数是不同规则书，不能互相引用。
