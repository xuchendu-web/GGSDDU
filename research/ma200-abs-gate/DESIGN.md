## 公式（不另造）

Faber GTAA 的可交易慢趋势：月收 > 10 月 SMA（公开写法见 Faber, *A Quantitative Approach to Tactical Asset Allocation*）。周频等价冻结为 **40 根周五收盘的简单算术平均**（40×5 = 200 个交易日，≈200D；不是另算一根日线 200SMA）。

```
SMA_N(t) = mean(C_{t-N+1}, …, C_t)
abs_on(t) = 1  若 C_t > SMA_N(t)
          = 0  其他（含相等、非有限、长度不够）
```

- `C` 是 **单一市场代理** 的周收盘，不是池内各券自己的均线。
- 含当周。当周 `C_t` 与 FACE 同一套周五 ≥14:30 代理（有 14:30 用 14:30，否则 kit 周线收盘）。不得用信号日之后的官方收盘。
- 严格 `>`。相等视为关。
- **不加斜率**。MA 是否高于 4 周前，是 PR#66 的通道结构，本刀不计算。
- **不加 HYST / 缓冲区**。HYST-M2/M3 是另一刀（PR#50）。
- 日线 200SMA、10 月月线 SMA、指数期货，本刀不跑。

N 锁邻档 **30 / 40 / 50 周**。40 是 Faber 10 月的周频翻译；30 / 50 是 ±10 周邻档，不是本仓净值反推。

## 证伪尺子

比较对象只有本次运行的 **F0**。不与 Dual-MOM 的 131.9% 比，不与 NOBREADTH 跑的 134.0% 比，不与 TV 网格 158.3% 比，不与压缩突破 68.1% 比，不与通道 overlay 的 CH-MA* 比。

记收益为小数（131.6% = 1.316），回撤为负数。不等式与 ENTRY-SIGNAL 八格已锁的 `ruler.py` 相同，不另造 0.9× 或 −2pp：

```
Δret     = ret − ret_F0
Δ|MDD|   = |maxDD| − |maxDD_F0|
盖住     = Δret ≥ Δ|MDD|
窗过     = 该窗累计收益 ≥ F0 同窗累计收益
惰性     = (id ≠ F0) 且 (n_ma_off_breadth_on = 0 或 持仓周集合与 F0 相同)
记正     = 盖住 且 2020–22 窗过 且 2023–26 窗过 且 非惰性
证伪     = 其余，含任一字段缺失或 NaN 或惰性
```

相等算盖住。Calmar 只展示，不进这把尺子。2023–26 必须 ≥ F0（用户锁的 no-miss）；自身为正不是额外闸，F0 后段已是 +94.8%。

| 2023–26 | date ≥ `2023-01-01`，直到 2026-10-23 |
