## 这刀回答什么

两道护栏，都打在研究书面上，不升格、不进实盘。

1. **Deflated Sharpe（Bailey & López de Prado, 2014）**。用风格网格的试验次数 N 把面的周频夏普打掉选择偏差，并按收益的偏度、峰度修正。

已有的探索尺子（Δret 盖住 Δ|MDD|，再看 2020–22 与 2023–26）继续有效，本刀不改写它。Walk-forward 刀 `RESEARCH-WF-OOS-B45-FACE`（104/26/26，只在训练窗里挑 TV）是另一条账，数字不并进这里。

## 1. Deflated Sharpe

频率锁死在**周**。周收益是持有周内日净收益的复利：信号周五 `t` 到下一信号周五之间、`(friday_t, friday_{t+1}]` 上的 `∏(1+r_d) − 1`。空仓周保留，周收益为 0 也留在样本里。T 必须等于 348。

夏普用样本标准差（除以 T−1）。不年化之后再送进公式。给人看的年化数是 `SR_week × √52`，只展示。

```
SR = mean(r_w) / std(r_w, ddof=1)
```

偏度、峰度用除数 T 的中心矩（有偏、非超额峰度）。正态峰度 = 3。`pandas.Series.kurtosis()` 默认是超额峰度，禁止直接送进公式。

```
m_k = Σ (r − mean)^k / T          k = 2, 3, 4
γ3  = m3 / m2^(3/2)
γ4  = m4 / m2^2                   Pearson，正态为 3
```

γ3、γ4 只取**面**的周收益。13 本各自的周频 SR 记为 `SR_1 … SR_13`（含面）。

```
V = variance(SR_1 … SR_13, ddof=1)
σ_SR = sqrt(V)
```

零假设是这族的真实夏普均值为 0。所以期望最大夏普的均值项是 0，不把 13 本 SR 的样本均值加回去。

欧拉–马歇罗尼常数 `γ_E = 0.5772156649015329`。`Φ` 为标准正态 cdf，`Φ^{-1}` 为其分位函数。

```
z_max(N) = (1 − γ_E) · Φ^{-1}(1 − 1/N) + γ_E · Φ^{-1}(1 − 1/(N · e))

SR* = σ_SR · z_max(N)

DSR = Φ(  (SR − SR*) · sqrt(T − 1)
        / sqrt( 1 − γ3·SR + ((γ4 − 1)/4) · SR^2 )  )
```

`SR` 是面的周频夏普。N = 13。分母 ≤ 0、T < 4、或任一周频标准差为 0：整包 `BLOCKED`，不把 DSR 写成 1。

这道式子用论文例题锁过：年化 SR = 2.5、年化试验夏普方差 = 0.5、每年 250 个观测、T = 1250、γ3 = −3、γ4 = 10。换算到观测频率（SR 与 σ_SR 都除以 √250）后，N = 100 得 DSR = 0.9004，N = 46 得 0.9505；改成正态（γ3 = 0、γ4 = 3）时 N = 88 得 0.9505。执行方先过这三则夹具，再算面。

披露、不参与判决：

```
ρ̄ = 13 本周收益的两两 Pearson 相关，只取非对角，再平均
N_eff = 1 + (1 − ρ̄) · (13 − 1)
```

边界与论文附录 A.3 一致：ρ̄ → 0 时 N_eff → 13，ρ̄ → 1 时 N_eff → 1。`DSR_eff` 用 N_eff 代入同一公式（N_eff < 2 时不计算，填 null）。`PSR0` 是基准为 0 的概率夏普，即上式里把 `SR*` 换成 0，用来看选择偏差削掉了多少。

日频 T 禁止进入判决。日频会把持有周里的重复观测算成独立样本，DSR 会被抬高。

## 2. CPCV · 6 条路径

周序列就是上面的 348 周，下标 `0 … 347`。分成 G = 7 个连续组，测试组个数 k = 2。

```
splits = C(7, 2) = 21
paths  = C(6, 1) = 6
```

每组被放进测试集的次数是 6，因此能拼出 6 条盖满全样本的路径。`~6` 在这里落成 **6**，因为 k = 2 时路径数 = G − 1，G = 7 得到 6。348 不能被 7 整除，组长度差一周：

| 组 | 周下标（含首不含尾的切片） | 长度 |
|----|----------------------------|------|
| 0 | [0, 50) | 50 |
| 1 | [50, 100) | 50 |
| 2 | [100, 150) | 50 |
| 3 | [150, 200) | 50 |
| 4 | [200, 250) | 50 |
| 5 | [250, 299) | 49 |
| 6 | [299, 348) | 49 |

被否掉的做法：G = 6、k = 2 得到教科书上的 5 条路径，且每组正好 58 周。本刀要 6 条，所以用 G = 7，接受最后两组少一周。持有周数不是 348 就停，不要改组长度去凑。

Split 的顺序是 `itertools.combinations(range(7), 2)` 的字典序。

清洗只作用于**训练段**，测试周不动：

- 清洗（purge）h = 1 周。每个测试组若从周 `a` 开始，训练段里删掉 `a−1`（标签是下一周收益，会伸进测试组）。
- 禁运（embargo）e = 4 周。每个测试组若结束于周 `b`（含），训练段里删掉 `b+1 … b+4`。
- 4 周对上 SHARPE20 的约 4 个交易周，也对上已扫过的最短持有上限 MH4。σ60 不拿来当禁运：TV 是该书自身历史收益上的因果缩放，不是在训练段里重估的特征。
- 先取测试组的补集，再删清洗周，再删禁运周。落在另一个测试组里的周本来就不在训练段。

训练段剩下的日收益按原时间戳拼接，用 `stats_full` 算 Calmar，只用来在邻档里排序。训练 Calmar 与全样本 Calmar 日历跨度不同，禁止拿去和面的 0.70 比大小。训练段短于 52 周：整包 `BLOCKED`。按上面的组长度，训练段约在 230 周以上，这道门是保险丝。

| id | θ | maxN | σ\* | 相对面 |
|----|----|------|-----|--------|
| FACE | 0.45 | 5 | 0.25 | 面 |
| B40 | 0.40 | 5 | 0.25 | θ 下一档 |
| B50 | 0.50 | 5 | 0.25 | θ 上一档 |
| TV22 | 0.45 | 5 | 0.22 | σ\* 下一档 |
| TV28 | 0.45 | 5 | 0.28 | σ\* 上一档 |
| S4 | 0.45 | 4 | 0.25 | 席位 −1 |
| S6 | 0.45 | 6 | 0.25 | 席位 +1 |

B55、TV20、TV30、TV33、S3、S7 留在 DSR 的 13 本里，因为网格跑过它们。它们不进 CPCV 的选择菜单：那是网格尾巴，不是邻档。不做 θ 或 σ\* 的插值，不做 7 本的笛卡尔积。

每个 split：

1. 7 本各自在清洗后的训练段上算 Calmar。
2. 取最大者。并列时先比训练段 `ret`，再按固定顺序 FACE、B40、B50、TV22、TV28、S4、S6，排在前面的赢。Calmar 非有限数的书排在最后。七本都非有限：选 FACE。
3. 该 split 的测试周，使用被选中那本书的日净收益。

路径拼法（位置规则）：对每个组 g，列出包含 g 的 split，顺序就是上面的字典序，共 6 个。第 m 条路径（m = 0…5）在组 g 上，取这张清单的第 m 个 split 所选出的书，用那本书在组 g 里的日净收益。七组按 0→6 接回原时间戳。每条路径都盖住全部 348 周，每个交易日恰好出现一次。再对这条日收益调用 `stats_full`。

冻结的面自己拼路径时，每组都是同一条收益，6 条路径与全样本重合。这是冻结规则的算术结果，不是实现错误。选择一旦在不同 split 里换书，路径就不再重合。所以判决看的是**选择路径**，不是面的六条拷贝。

同时交出 21 个 split 的测试窗 Calmar（只含该 split 的测试周）：一列是面，一列是该 split 选中的书。测试窗短，Calmar 与全样本不同口径，只列表，不进旗标。

## 证伪尺子

先过锚，再算旗标。锚是面相对 `05f0f8a4` 已发表的 `LIVE1430-B45-S20-max5`：

| 量 | 锚 | 允许偏差 |
|----|----|----------|
| ret | 1.316 | 0.005 |
| maxDD | −0.188 | 0.002 |
| Calmar | 0.70 | 0.02 |
| 日历周 | 349 | 0 |
| 持有周 T | 348 | 0 |
| 终点 | 2026-10-23 | 必须相同 |
| AUM≥2 亿只数 | 324 | 0 |

锚不过：`anchor_pass = false`，`family_verdict = BLOCKED`，DSR 与 CPCV 都写 `BLOCKED`。四件套仍写出实数。停止，不去改成本、不去改宽度、不去贴 158.3% 那条引擎。

锚过了之后：

```
FLAG_DSR  = DSR < 0.95
FLAG_CPCV = median(6 条选择路径的 Calmar) < 0.5 × Calmar_FACE
```

路径 Calmar 非有限时，排序当作 −∞。6 个数排序后，中位数是第 3 与第 4 个的算术平均。该中位数非有限，或它小于 `0.5 × Calmar_FACE`，则 `FLAG_CPCV` 为真。

0.95 是论文例题里出资人使用的置信水平（N=46 时 DSR=0.9505 才过线）。0.5 倍沿用本仓库 walk-forward 刀已经写死的 OOS Calmar 红旗（全样本面的一半），用在**等长**的 6 条路径上，不用在 21 个短测试窗上。

| 条件 | family_verdict | 含义 |
|------|----------------|------|
| 锚不过，或公式无定义 | `BLOCKED` | 护栏没有跑成 |
| `FLAG_DSR` 或 `FLAG_CPCV` | `OVERFIT` | 相对面，护栏标过拟合 |
| 两面旗都是假 | `HOLD` | 面穿过这两道护栏 |

`OVERFIT` 与 `HOLD` 都不换冠。`N_eff`、`DSR_eff`、`DSR_max`、`PSR0`、21 个短窗 Calmar，都不翻转上表。

REPORT 的证伪段只写这三句之一：

- 锚点未过。家族结论 BLOCKED。不换冠。
- 护栏标过拟合：点名 DSR、CPCV 或两者。不换冠。
- 两道护栏都未标。不换冠。
