## 2. 文献边界（只约束本卡）

仓库笔记 `research/research-kb/`（分支 `cursor/research-kb-f52d`）：

- **04 Moskowitz–Ooi–Pedersen (2012)**：单工具过去约 12 个月超额收益的符号决定方向，再用事前波动缩放仓位。原文在期货/远期上允许按目标波动加杠杆。验证「跨资产普遍性」需要股、商品、利率，不能只留权益和黄金。
- **06 Kim–Tse–Wald (2016)**：去掉波动缩放后，TSMOM 累计收益与买入持有接近，alpha 差异往往不显著。标准消融是四象限：有/无趋势信号 × 有/无 vol 缩放。笔记标明依据公开摘要，**不编造**原文 t 统计或表格数字。
- **01 Moreira–Muir (2017)**：无趋势、只按滞后已实现方差缩放，是第四象限（本卡邻档 `VS-BH-12`）。证据集中在美股因子，不能写成股债商品普遍规律。
- **08 Clarke / Harvey vol-target**：等权 ≠ 等风险贡献 ≠ 波动率目标。Harvey 等：vol-target 稳住风险、削尾，但夏普改善主要见于股票与信用，债券/外汇/商品上夏普影响可忽略。

本卡因此把**方向**和**缩放**拆开，袖间等权与等风险分开，商品/利率单独出表。L≤1 是本仓库冻结红线：低波动周**不能**加杠杆去够目标波动。这与 Moskowitz 原文可加杠杆的设定不同，报告必须写明「只缩不放」。PR#47 在 B45 持仓上做过 VT12：未缩放 159.7% / −25.7% / 实现 vol 21.7% / Calmar 0.59，VT12 71.1% / −12.0% / 9.6% / 0.69；那是 SPIKE 面层的杠杆叠加，**不是**本卡预测，只说明本仓 `σ* = 12%` 与 `L≤1` 已经用过。

Cederburg (2020) 提醒 spanning 回归正 alpha ≠ 可实施样本外超额。本卡过闸用已实施、扣费、L≤1 的 Sharpe / Calmar，不做 spanning 回归。

### 3.4 方向、缩放、袖间预算（被测机制）

`σ* = 0.12`（PR#47 已用过的目标波动，不是新编数字）。`σ_i`：资格集内该名最近 60 根周简单收益的样本标准差（ddof=1）× √52。`σ_i ≤ 0` 或非有限则该名当周视同不在 `E_s`。

令 `n_s = |E_s|`。`n_s = 0` 时该袖当周全部现金。否则：

| 簿 | 名字权重（乘袖预算之前） |
|---|---|
| `VS-TSMOM-12` | `u_i = (1/n_s) · 1{R52_i > 0} · min(1, σ*/σ_i)` |
| `TSMOM-UNSCALED` | `u_i = (1/n_s) · 1{R52_i > 0}` |
| `EW-BH` | `u_i = 1/n_s` |

`R52_i = P_t / P_{t-52} − 1`，价格取周网格收盘。不要跳月（PR#51 已证伪）。不要改成 max5 / 横截面排序（那是已证伪的全池 TSMOM / CSMOM）。

袖预算（主簿）：设 `n_declared` 为库存后**宣布**的袖数（`OX`+`CMD`，若 `RATES` 未 SKIP 再加 1）。`B_s = 1 / n_declared`。某袖 `n_s = 0` 或全员 `R52 ≤ 0` 时，该袖的 `B_s` **留在现金**，不重新分给其它袖。这与 RP-SLEEVE「缺袖再归一」不同：本卡要保留资产类预算，避免做成袖间 CSMOM。

最终名字权重 `w_i = B_s · u_i`。现金 `= 1 − Σ w_i`，收益 0。因为 `min(1, σ*/σ_i) ≤ 1` 且方向可为 0，主簿经常 `Σ w < 1`。这就是 vol-target，**不要**再把袖内 `u_i` 归一成 1（归一成 1 是席位逆波动，已判卡）。

`R52 = 0` 视为非正，方向 0。
