
### 回看：R² 与 ER

价格与 `sharpe_n_on` 同一条日 qfq 收盘。截止：**信号周五的前一交易日**。`(signal − last_bar).days > 5` → 缺失。函数与 #3 `ER-R2-FLOOR` 的 `ols_r2` / `r2_on` / `kaufman_er` 相同。本刀**不调用** #3 的 `floor_pass`，不比较 0.50 / 0.40。

```
ols_r2(px[0…n−1]):
    根数 < n，或任一收盘 ≤0 或非有限 → None
    y_i = ln(P_i)                         # 最老→最新
    t_i = i                               # 交易日下标，不是日历日
    R² = Sxy² / (Sxx·Syy)
    Sxx≤0 或 Syy≤0 或非有限 → None        # 全平 → 缺失，不是 0
    落在 [0,1] 外超过 1e-12 → None
    否则 clip 到 [0,1]
    # 不算 β，不年化，不乘斜率。β 的符号不进键

r2_on(closes, d, n=90):
    sub = closes[: d − 1 日]
    (d − sub 末根).days > 5 → None
    最后 n 根，不足 n → None
    返回 ols_r2

kaufman_er(closes, d, n=20):
    sub 同上，最后 n+1 根
    ER = |C_n − C_0| / Σ|ΔC|
    分母 ≤0 或非有限 → None               # 全平 → 缺失
    返回 num/denom，不 clip，不设 0.40
```

| 书 | 计算 | 不计算 |
|----|------|--------|
| F0 | 无 | R²、ER、z |
| R290S | `r2_on(n=90)` | ER、z、accel |
| ER20S | `kaufman_er(n=20)` | R²、z、accel |
| COMBOS | 两个都算，再在带内做 z | accel |

R² 高但 β<0（平滑下跌）仍然排得高。方向只来自 `spike_ft` + SHARPE20。ER 没有方向：单边下跌 ER=1，照样排在带首；能不能进带仍看 S20。

### 排序键

先记下带内的 S20 下标 `s20_index`（0 = 带内 S20 最好），再排。元组升序：

```
(0 if 键有限 else 1,  −键 if 有限 else 0,  s20_index,  code)
```

精确同分先回到原来的 S20 序，再按代码升序。不用 accel 断同分。不把 R² 四舍五入成分桶。

单键书：带内该键**全部**缺失 → 回退这条带的 S20 原序，取前 `slots`。有一部分缺失：有限的在前，缺失的在后，仍然取满 `min(slots, |band|)`。

### COMBOS

z 的样本是**当周这条带里 R² 和 ER 都有限**的名字。缺任一腿的名字不进 z 样本，`combo = None`，排在所有有限 combo 之后，仍然可以占带尾的席。

```
n = 样本人数
μ = Σx / n
方差 = Σ(x−μ)² / n          # ddof = 0，总体标准差
若 n < 2，或两条腿的方差都 ≤0：整段带回退 S20 原序
若某一腿方差 ≤0：该腿每个人的 z = 0，另一腿照常
z = (x − μ) / sd
combo = 0.5·z(R²) + 0.5·z(ER)
```

z 每周、每条带重算。不用全市场 z，不用跨周池化 z，不用别的书的 z。样本里的人只来自当周带内、且两腿都有限的名字；一个缺腿的名字不拉动别人的 z。

已持仓不因 R²、ER 或 combo 变差而平，也不因排到带尾而平。换仓只发生在席位空出来之后：空席从当周短名单的重排结果里补。与 F0、AG40S 相同。

## 证伪尺子

比较对象只有本次运行的 **F0**。不与 158.3% / 0.94 比，不与 nob_ref 134.0% 比，不与 KB 135.0% 比，不与 PR#67 的 131.9% 比，不与 #1 的 SR90 72.8% 比，不与 #2 的 AG40S 235.6% 比，不与 #3 的 RF50 102.9% / ER20 90.5% / AND50 56.2% 比。这些数字只许出现在对照段和跳过段。

记收益为小数（131.6% = 1.316），回撤为负数。

```
Δret     = ret − ret_F0
Δ|MDD|   = |maxDD| − |maxDD_F0|
盖住     = Δret ≥ Δ|MDD|
窗过     = 该窗累计收益 ≥ F0 同窗累计收益
惰性     = (id ≠ F0) 且持仓周集合 {(周五, frozenset(codes))} 与 F0 相同
记正     = 盖住 且 2020–22 窗过 且 2023–26 窗过 且 非惰性
证伪     = 其余，含任一字段缺失或 NaN
证伪·惰性 = 惰性
```

相等算盖住，相等算窗过。Calmar 只展示，不进尺子。没有 0.9×，没有 −2pp。

| 窗 | 切片 |
|----|------|
| 2020–22 | `2020-01-01` ≤ date ≤ `2022-12-31` |
| 2023–26 | date ≥ `2023-01-01`，直到 2026-10-23 |

两窗都报 ret / maxDD / Calmar。判定只用窗内 ret。2023–26 必须 ≥ F0 同窗，这是硬条件，不是 0.9 倍。

### 只披露、不翻转旗标

- `n_entries`：新开+换入次数
- `n_rerank`：实际填入、但不在当周纯 S20 头部 `slots` 里的（周五, 代码）次数。F0 为 0
- `n_miss_r2`：过了 spike、有信号价、在 `C_t` 中，但 `r2_on` 为 None 的次数。按 `C_t` 全计。F0 / ER20S 为 0（那两本不计算 R²）
- `n_miss_er`：同上，`kaufman_er` 为 None。F0 / R290S 为 0
- `n_empty_slots`：各周 `max(0, slots − 实际新开数)` 之和。可以与 F0 不同
- `n_short_fills`：`len(take) < min(slots, |band|)` 的周数。四本都应为 0。大于 0 是实现偏离，不是机制证伪
- `n_fallback_weeks`：单键全部缺失，或 COMBOS 不满足 z 条件，从而整段带回退 S20 的周数。F0 为 0
- `mean_r2` / `mean_er` / `mean_combo`：实际新开名字上的均值。该书不算的键写 0；缺失不进均值；样本空写 0
- `mean_abs_D`、`hit_rate`、`win_size`、`jaccard_vs_f0`：定义同 #2 / #3。hit-rate 与 win-size 同时更好只写旁注，不能把证伪改成记正

惰性只看持仓集合，不看 `n_rerank=0` 的旁路。排序书 `n_empty_slots` 接近 F0 是常态（入口不砍席），**不能**据此记惰性。
