# Moreira & Muir (2017)：波动率管理组合

## 结论

核心主张：**在波动率高时降低风险敞口**（用上月已实现方差的倒数缩放当期因子收益），能在市场、价值、动量、盈利、ROE、投资、BAB 以及货币套息等多个因子上产生显著正 alpha、抬高夏普，并对均值–方差投资者给出可观效用增益。机制不是「高波动一定低收益」，而是**预期收益没有随波动同比上升**，因此条件均值–方差权衡 $\mu_t/\sigma_t^2$ 在高波动期变差——理性均值–方差投资者应减仓。边界：证据集中在**美股因子与套息**，不能直接外推为股债商品黄金都能同样奏效；策略在衰退与危机时反而减仓，与「危机加仓」的叙事冲突，但也意味着需要接受阶段性踏空；原论文对交易成本、杠杆上限与严格样本外组合的处理有限，后续被 [[03-Cederburg-2020-Performance-Volatility-Managed]] 与 Barroso–Detzel 等质疑。对实操/回测：可当作**最简风险缩放基准**——先测「仅用滞后已实现方差缩放」是否抬夏普，再与趋势信号、成本、杠杆约束一起做消融。

## 问题与设定

- **研究问题**：若方差在短窗口高度可预测，而预期收益与方差预报的联系很弱，那么按 $\mu_t/\sigma_t^2$ 做波动率择时能否系统性改善投资机会集？这对均衡风险溢价模型意味着什么？
- **资产**：股票市场组合及多个股票因子（HML、MOM、盈利、ROE、投资、BAB 等），外加货币套息（carry）。
- **频率**：月度；用**上月已实现方差**代理条件方差。
- **样本**：与标准因子库一致的长历史（含大萧条、1987、2008 等危机段；具体起止以原文表为准）。

## 方法

### 策略构造

波动率管理因子收益（原文核心构造）：

$$
f_{t+1}^{\sigma} = \frac{c}{\widehat{\sigma}_t^{2}}\, f_{t+1}
$$

其中 $f_{t+1}$ 为原始因子超额收益，$\widehat{\sigma}_t^{2}$ 为**上一月**已实现方差，$c$ 为标定常数（使策略平均暴露或波动与原文可比）。$c$ **不影响夏普**，只影响杠杆水平与绝对收益。

直觉：近期方差高 → 缩放权重小 → 下一期承担更少风险；反之加仓。

### 评价

1. **Spanning 回归**：$f_t^{\sigma} = \alpha + \beta f_t + \varepsilon_t$。正 $\alpha$ 意味着波动率择时扩展了原因子张成的均值–方差前沿。
2. **Appraisal / 超额夏普**：由 $\alpha$ 与 RMSE 构造；新夏普满足近似关系  
   $SR_{\text{new}}^{2} \approx SR_{\text{old}}^{2} + (\alpha/\sigma_{\varepsilon})^{2}$。
3. **效用**：均值–方差投资者的终身效用增益（与 Campbell–Thompson 等收益可预测性文献对比）。
4. **分桶**：按上月已实现波动五分位，画下一月平均收益、波动、$\mu/\sigma^{2}$ 与衰退概率（文中 Figure 1）。

### 对比基准

买入持有原因子；不额外用收益预测变量做择时（刻意分离「波动率择时」与「收益择时」）。

## 主要发现

（依据：**作者站点正式版 PDF** / JoF 2017；数字来自原文叙述。）

- **市场机制**：上月波动与下月**平均收益关系弱**，与下月**波动关系强** → 高波动桶的 $\mu/\sigma^{2}$ 更差。
- **市场因子量化**：年化 alpha 约 **4.9%**（文中亦写 4.86%）、appraisal ratio 约 **0.33**、相对买入持有夏普约 **+25%**。
- **多因子**：价值、动量、盈利、ROE、投资、BAB 及货币套息上普遍出现正 alpha；动量相关策略改善往往最大。
- **效用**：均值–方差投资者从波动率管理获得的终身效用增益约 **65%** 量级，高于文中引用的收益可预测性择时约 35% 的基准。
- **危机行为**：策略在衰退与危机后往往**显著减仓**（如 2008 大幅降暴露），却仍能维持较高平均收益——与「危机必须加仓」的传统叙事相反。
- **理论含义**：对代表性代理人模型构成尖锐挑战——高波动期隐含的「有效风险厌恶」似乎更低，与多数宏观金融设定相反。

## 边界与批评

- **资产边界**：核心证据是股票因子 + 套息，不是跨大类资产配置说明书。
- **可实施性**：正 alpha 来自 spanning 回归；把 scaled 与 unscaled **用事后最优权重组合**才能充分兑现效用——真实投资者拿不到事后权重（见 [[03-Cederburg-2020-Performance-Volatility-Managed]]）。
- **成本与约束**：高波动减仓、低波动加仓隐含**动态杠杆**；Barroso & Detzel 等后续工作强调交易成本可侵蚀收益。
- **样本外/结构稳定**：Cederburg 等指出 spanning 关系结构不稳定，OOS 组合常输给原策略。
- **与「波动率溢价」叙事**：本文不是否定波动风险被定价，而是说**条件**风险–收益权衡并不随已实现波动同比例变好。

## 可学习框架

1. **最简可证伪设定**：只用滞后已实现方差缩放，不加收益预测 → 若夏普不升，则「波动率含独立风险管理信息」假说在该资产上失败。
2. **评价三角**：直接夏普对比 / spanning $\alpha$ / 效用或 CER ——三者回答不同问题，不可混用。
3. **分桶诊断**：滞后波动五分位上画 $\mu$、$\sigma$、$\mu/\sigma^{2}$，一眼看出是否值得做波动率择时。
4. **危机路径审计**：列出策略在已知危机中的暴露路径，避免只看全样本夏普。
5. **与趋势拆开**：本文是**无方向**的风险缩放；要与 [[04-Moskowitz-Ooi-Pedersen-2012-Time-Series-Momentum]] 的方向信号分开检验。
