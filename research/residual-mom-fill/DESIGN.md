## 这刀回答什么

在冻结面上，空席填谁：SHARPE20 换成**去均值后的截面动量**，能不能在同一条 btheta 针上过已经写死的严格尺子，并且 **2023–26 不踏空**。

问的不是「再扫一遍 RET 窗」。RET8 / RET12 已判，KB 写明不插值。问的也不是 MOM121 的 12w/1w 合成 z 分，也不是 Z121 的 z(R12)−z(R1)，也不是 R4W / R8W 的**原始收益**取前 5。那些是已证伪填席族。

## 主口径冻结（只选一种）

候选有两种残差，本卡**只冻结第一种**，第二种不进四件套：

| 候选 | 公式 | 本卡 |
|------|------|------|
| **等权去均值（主）** | `resid = R12w_i − mean_{j∈D_t}(R12w_j)` | **冻结** |
| β×510300 | `resid = R12w_i − β_i · R12w_510300` | **不跑**。β 回看是新自由度；510300 不是合格池；与「截面去均值」不是同一族 |

选等权去均值的理由（设计选择，不是回测结论）：

1. 去均值集合与填席候选是同一合格池，残差是「相对还能进席的名字」而不是相对沪深 300。
2. 不引入 β 窗、不引入第二只代理的缺失规则。
3. 已证伪的 Z121 / MOM121 用的是 **z 分或 12w/1w 加权 z**；本卡**不做 z、不减 R1w、不合成**。只减当周等权均值。
4. 仓库笔记把「动量类替 S20 后段不稳」记在原始 RET / 合成 z / 差分 z 上。本卡先问：去掉截面共同项之后，这个不稳还在不在。

禁止在看到结果之后改成 β×510300，或把两种残差平均。

## 精确规则

### 合格池与去均值集合

每个信号周五 `t`，先看 `risk_on = (b ≥ 0.45)`。`risk_on` 为假：与 FACE 相同，E0 / `breadth_off` 出清，本周不填席。

`D_t`（去均值集合）= 当周同时满足：

1. `in_play` 且 `in_play_kind == spike_ft`；
2. 不是 `box_pending` / `pending_second_week`；
3. 有有限的 `R12w`（主簿）或对应邻档的 `R8w`；
4. 在 AUM≥2 亿研究池内。

`D_t` **包含已持仓**（只要仍是 spike_ft 且收益有限）。残差是名字相对当周冲击池的属性，不因账上已有谁而改均值。

`C_t`（填席集合）= `D_t` 减去当前持仓（与 btheta `build_cands(..., skip=set(positions))` 相同）。

`|D_t| < 2`：残差无定义。已持仓维持到 E0；**空席空着**。禁止回退 SHARPE20，禁止从非 spike 池补。

### 回看收益（R12w / R8w）

价格与 `sharpe_n_on` 同一条日 qfq 收盘。截止：**信号周五的前一交易日**。`(signal − last_bar).days > 5` → 缺失。

```
R_k(closes, d, cal_days, min_bars):
    sub = closes[: d − 1 日]
    若 (d − sub.index[-1]).days > 5 → None
    p1 = sub.iloc[-1]
    t0 = sub.index[-1] − cal_days
    past = sub[: t0]
    若 past 空 → None
    若 (sub.index[-1] − past.index[-1]).days > 5 → None
    p0 = past.iloc[-1]
    n_bars = 从 past.index[-1] 到 sub.index[-1] 的收盘根数
    若 n_bars < min_bars 或 p0≤0 或非有限 → None
    返回 p1 / p0 − 1
```

| 键 | `cal_days` | `min_bars` |
|----|------------|------------|
| R12w（主） | 84 | 40 |
| R8w（仅邻档） | 56 | 28 |

这是日历 12 周 / 8 周，不是 RET8/RET12 那套「原始收益填席」的重开，也不是 PR#43 的日窗 R40/R60/R80 入场闸。

禁止：跳月（12−1）、减 R1w、z 分、与 SHARPE20 加权、用信号日当天收盘。

### 残差与排序

主簿 `RES12-EW`：

```
mu_t = mean({R12w_j : j ∈ D_t})
resid_i = R12w_i − mu_t          # i ∈ D_t
```

邻档 `RES12-MED` 把 `mean` 换成 `median`（同集合 `D_t`）。邻档 `RES8-EW` 把全部 `R12w` 换成 `R8w`，仍用等权均值。

排序键（只用于 `C_t`）：

```
residual_key(c) = (0 if resid 有限 else 1,  −resid,  code)
```

`require_residual = True`：残差缺失的名字不进排序。取 `slots = max_pos − 已持仓` 的头部。过不了的席位空着。

已持仓不因残差变负而平。出场只走 E0（`breadth_off` / `falsify` / `always_in_flip` / `left_structure` / 末日 `eod_eval`）。

腿内等权，总暴露仍 TV25。不改 max5。

### F0

θ / 残差关闭。`rank_fn = sharpe_key`，`sharpe_n=20`，`require_sharpe=True`。不计算残差，`n_miss_residual = 0`。

