## 1. 对照面 FACE（冻结，只作尺子）

FACE 是研究侧账面，不是实盘冠军。规则保持 SPIKE-S20 延窗复核的原文：

- 池：研究池 `universe_replace_only_436.csv`，`aum ≥ 2`（324 只）。与实盘池分开。
- 时钟：信号周五 ≥14:30（pytdx 14:30 替换当周收盘后做因果 classify）；成交同一周五收盘。
- 门：breadth ≥ 45%（face 列 `b` / `risk_on`）。门关则当周空仓，现金收益为 0。
- 选品：`spike_ft`，剔除 `box_pending` 与 `pending_second_week`；席位最多 5。
- 填席：`SHARPE20`。近 20 个日收益的均值/标准差 × √252，窗口严格止于信号日前一交易日。缺 Sharpe 的名字不参与排序。
- 退出 E0：`falsify`（价跌破 `falsify_close`）、`always_in_flip`、`left_structure`。E0 已判为保护项（2026-10-21 `NO-E0` 证伪，去掉后 16.1% / −35.9% / Calmar 0.06）。
- 杠杆：TV25。`L = min(1, 0.25 / max(σ20, σ60))`，σ 为策略自身过去日收益的年化标准差（√252），`L ≤ 1`。
- 成本：0.2% 往返。`cost = (Σ|Δw| ) × 0.002 / 2`，w 为乘上 L 之后的权重。

延窗锚（`SPIKE-S20-EXTEND-REBASE-LIVE1430`，簿 `LIVE1430-B45-S20`，样本 2020-01-03 → 2026-10-23）来自该簿 `metrics.csv`，原样引用：

| maxDD | −18.8% |
| CAGR | 13.1% |
| Calmar | 0.70 |

该次 `metrics.csv` 没有 Sharpe，也没有换手。下面两格是用**同一批已发布产物**复算的锚，不是新回测：

- 日频 Sharpe（rf = 0，√252）= **0.82**。算法：`nav_LIVE1430-B45-S20.csv` 相邻净值的简单收益，样本标准差 ddof=1。净值 2020-01-03 = 0.999，2026-10-23 = 2.31635，与 ret 131.6%（`nav_end − 1`）一致。分段：2020–22 为 0.43，2023–26 为 1.14。周频 √52 为 0.88，只作旁注，过闸用日频。
- 名单等权一手换手 = **0.180 / 再平衡**（年化约 9.4 倍）。算法：`holdings_LIVE1430-B45-S20.csv` 的 348 行，持仓等权、空仓权重为 0，`mean(Σ|Δw| / 2)`。这一格**不含** TV 的 L 漂移。引擎换手（乘 L 之后）由实施时在同一公式下复算；FACE 引擎一手换手落在 **0.10–0.40** 之外则 `BLOCKED`，先核对口径。

TV 网格那张表里的 TV25 行（ret 158.3% / maxDD −15.9%）是另一次绝对水平，**不作 FACE 锚**。

in-run 对照必须重放这条 FACE，并同时满足：`|ret − 131.6%| ≤ 2.0pp` 且 `||MDD| − 18.8%| ≤ 1.0pp`。读已发布净值时，日频 Sharpe 与 0.82 的差不超过 0.03。对不齐就 `BLOCKED`，不许拿漂移后的对照给风险平价记账。

## 2. 精确规则（主簿 RP-IV60）

主簿问的是：在同一研究池、同一周五时钟、同一 TV25 与 0.2% 成本下，**按袖子做逆波动风险预算** 相对 FACE 的集中冲击选品，风险调整后是否更划算。

风险预算的单位是袖子篮子。席位内部把等权改成个股逆波动，是 2026-10-14 已判 `INVVOL-WEIGHT`（实盘口径 IV60 69.5% / −24.6% / Calmar 0.33，邻档 20/120 与 cap 40% 同塌）。那张卡不重开，也不把本主簿做成它的研究池翻版。

### 2.2 袖内篮子（冻结，不是被测旋钮）

每个信号周五、每个袖：

1. 候选是该袖可投名字里，截止日（信号日前一交易日）已有价格、且截止日前至少有 21 个日收盘的名字。上市日以研究缓存 `listing.json` 为准；没有该文件时，用该代码第一根可用价格日代替。
2. 每个 `family` 留一只代表：冻结 CSV 的 `aum` 最大；并列时 `code` 字符串较小者。`aum` 是与 FACE 的 `aum ≥ 2` 同一份静态截面，不另做时点规模。
3. 袖子篮子在历史上的日收益：用**本信号日选出的这组代表**，对有价格的代表等权，缺价的当天在其余代表上重新归一。代表集合沿回看窗不重组。

`CMD` 因此最多 4 个代表（黄金现货两只并成 518880）。`EQ` 的 family 数是 11。

### 2.3 波动与逆波动权重

波动用袖子篮子的周收益，不用日波动直接年化后再混口径。

- 周收益：相邻两个 FACE 日历周五之间、篮子日收益的复合。信号周五 `t` 的最后一根可用周收益，结束于 `t` 之前的上一个日历周五。`t` 当天的收盘不进入 σ。
- 主簿回看 **60** 根已完成周收益。不足 60 根的袖，当周不可投（权重先记 0，不改用更短窗）。
- `σ_s = std(周收益, ddof=1) × √52`。`σ_s ≤ 0` 或非有限，则该袖当周不可投。
- 可投集合 `E` 上，`w_s = (1/σ_s) / Σ_{j∈E}(1/σ_j)`。这是对角逆波动，权重和为 1。
- `E` 为空：当周全部现金，`L = 0`。
- 某袖不可投时，在其余可投袖上重新归一。缺袖的周数写入 `sleeve_missing_week_pct`，不把缺的风险预算改成现金锁死（锁死是未列入本卡的另一刀）。

### 2.4 杠杆、现金、再平衡、成本

袖子权重定完之后，套与 FACE 相同的 TV25，且 `L ≤ 1`：

- 用本策略过去的日收益序列 `rp`（乘 L 之前的满仓袖子组合收益；前序为空的日子不进入波动样本）。
- `σ20`、`σ60`：`rp` 最近 20、60 个收益的标准差 × √252。`L = min(1, 0.25 / max(σ20, σ60))`。有效样本不足 2 天时 `L = 1`。
- 名字权重：袖 `s` 的每个代表 `i` 得到 `L × w_s / n_s`。`n_s` 是该袖当周代表数。主簿上 `Σ w_s = 1`。`RP-IV60-CAP40` 放不下的残差在乘 L 之前就留在现金，因此 `Σ w_s` 可以小于 1。
- 现金权重 `= 1 − L × Σ w_s`，收益 0。现金不是 ETF。主簿此式等于 `1 − L`。
- 每个 FACE 日历周五再平衡到目标权重，无再平衡带。样本与 FACE 相同：2020-01-03 → 2026-10-23。
- 成本与 FACE 同一公式，打在乘 L 之后的名字权重上：`cost_t = Σ|Δw| × 0.002 / 2`。

时钟：决策日是 FACE 的那些周五；成交是当日收盘；信号只用严格早于当日的数据。主簿不做 14:30 classify，14:30 价格不进入袖子权重。FACE 对照继续用它自己的 14:30 路径。两边对齐的是周五决策日、当日收盘成交、0.2%RT、TV25、`L ≤ 1` 和样本窗。

## 3. 邻档（只跑这四本，不升格）

邻档与主簿同时出数。邻档过闸只写旁注，不能把失败的主簿救成 `记正`，也不做窗长插值（不跑 40 周、80 周、120 周）。

| 簿 | 相对主簿的唯一改动 |
|---|---|
| `RP-IV20` | 周波动回看 20 根；最少 12 根，否则当周该袖不可投 |
| `RP-IV60-CAP40` | 逆波动归一之后，单袖权重上限 40%。超出部分按比例分给尚未触顶的可投袖，迭代到稳定。放不下的残差在乘 L 之前留成现金 |
| `RP-ERC60` | 60 周等风险贡献，见下。失败的周退回该周的逆波动，并计 `erc_fallback_weeks` |
| `RP-IV60-EQONLY` | 去掉 `CMD`，只在 `EQ` 与 `SEC` 上做逆波动。用来看结果是否只来自五只商品 |

`RP-ERC60` 的协方差与迭代写死，避免各写各的求解器：

- `Σ`：三袖（或当周可投子集）周收益的样本协方差，ddof=1，不年化。仅一袖可投时权重为 1，再乘 TV。
- 岭：`Σ ← Σ + 1e-8 · I`。
- 初值用当周逆波动。然后最多 500 步：令 `m = Σw`，`w_i ← (1/m_i) / Σ_j(1/m_j)`，负的或非有限的分量当场改为逆波动并跳出，记入 fallback。
- 停止：各分量风险贡献 `w_i · m_i` 与其均值的最大绝对差 `< 1e-8 × 均值`。
- 未在 500 步内停止：该周 fallback。

不跑的邻档：FACE 持仓内部再套逆波动；叠 B50、HYST-M3、TV33、511010、511260；去掉 breadth 或去掉 E0；给红利或固收另开袖。

## 4. 四闸（相对 in-run FACE）

四闸全部用主簿对 **当次重放的 FACE**。百分比差用百分点。`Δ|MDD| = |MDD_book| − |MDD_FACE|`，回撤变深时为正。

| 闸 | 过闸 |
|---|---|
| G1 收益盖住回撤 | `Δret ≥ Δ\|MDD\|` |
| G2 Calmar | `Calmar_book ≥ Calmar_FACE` |
| G3 Sharpe | 日频 Sharpe（rf=0，√252，ddof=1）`≥ FACE` |
| G4 后段不踏空 | 2023–26 的累计收益 `≥ FACE` 的 2023–26 累计收益，且本身为正 |

换手是主表必报列，不是第五闸。口径：再平衡截面上 `mean(Σ|Δ(L·w)| / 2)`，即一手。另报 `×52` 的年化。两边同一公式。

集中度旁注，只作用于「主簿四闸都过」的情形：若任一袖的平均权重 `> 70%`，则必须 `RP-IV60-CAP40` 也过 G1 与 G3，主簿才能 `记正`。否则判词写 **证伪「结果来自单袖低波」**。商品只有五只，这条专门挡住黄金把逆波动做成单袖。

`记正`（不换冠）的句子：

> 记正（不换冠）：RP-IV60 四闸全过。Δret 与 Δ|MDD|、Sharpe、Calmar、2023–26 收益、一手换手各写实测差。邻档只旁注。

`证伪`（不换冠）的句子：

> 证伪（不换冠）：RP-IV60 未过闸 Gx。写上四闸的实测。邻档即使全过也不升格。

2020–22 必须进主表。前段变弱、后段不踏空、且 G1–G3 仍过时，可以 `记正`（与 HYST-M3 的记账方式相同）。前段不单独否决，后段踏空否决。

`BLOCKED` 不叫记正，也不叫证伪。触发条件见第 1 节的锚容忍，以及商品名单核对、FACE 引擎换手落在 0.10–0.40 之外、输入缓存缺失。

## 7. 文献边界（只约束本卡，不另开刀）

仓库笔记 `08-Risk-Parity-Vol-Targeting-Clarke-CFA-Bai` 把等风险贡献和逆波动分开：长多头下风险平价更接近逆波动，等风险贡献才使用相关。所以主簿用对角逆波动，`RP-ERC60` 单列，用来看相关改不改判词。同一笔记里，波动率目标能压 vol-of-vol，夏普改善并不普遍，商品上尤其弱。本卡把 TV25 留在两边，避免把「换了目标波动」记成「袖子风险预算有效」。Kim–Tse–Wald 的消融（趋势收益里很大一块来自波动缩放）是把个股逆波动留在已判卡里的理由：本卡不再把缩放后的曲线记到选品名下。
