## 主口径冻结（只选一种）

候选有两种写法，本卡**只冻结第一种**。第二种不进四件套、不作并列主簿。

| 候选 | 公式（`p_now` = 信号日前一交易日收盘） | 本卡 |
|------|----------------------------------------|------|
| **R11m、截止 t−4w（主）** | `skip_mom = p_skip / p_long − 1`，其中 `p_skip` 为 `p_now − 28` 日历日及之前最近一根有限收盘，`p_long` 为 `p_now − 364` 日历日及之前最近一根有限收盘 | **冻结**。与复利 `(1+R52w)/(1+R4w) − 1` 在同一 `p_now` 上恒等 |
| 简单差 `R52w − R4w` | `p_now/p_long − p_now/p_skip` | **不跑**。不是收益率；排序会与价格比分叉（见 COMPOSER 夹具） |

文献边界（只约束本卡，不编造原文表格数字）：

- Jegadeesh–Titman (1993) 原文在形成期与持有期之间**跳过 1 周**，避开买卖价差 / 价格压力 / 滞后反应；形成期是过去 1–4 个季度。
- 后续月频惯例（Carhart 1997；Asness；Daniel–Moskowitz 等沿用）把「跳过」写成 **最近 1 个月**，排序键为 **t−12 到 t−2**（即 11 个月、截止形成期末）。用户点名的海外方法进研究池，指的是这一条，不是 1993 原文的跳 1 周。
- 本卡主口径因此冻成 **12 个月回看、跳最近 4 周（≈1 个月）**。跳 2 周只作邻档，用来摸「少跳」一侧，**不得升格为主簿**。
- PR#51 用**日历月末**锚（形成期 t−12 月末 → t−2 月末）。FACE 是周五 ≥14:30 周频。本卡**不用月末锚**，避免把 PR#51 的周线书原样搬进填席键。

选价格比 / 复利、不选简单差的理由（设计选择，不是回测结论）：

1. 价格比是真正的形成期收益率，与 Jegadeesh 线「过去 J 个月累计收益排序」同构。
2. 简单差对最近价格水平过敏，两名 `R52−R4` 相同也可以有不同的 11 个月收益。
3. 复利差与价格比恒等，Composer 只需实现一套，夹具锁恒等，禁止再写第三套。

禁止在看到结果之后改成简单差、月末锚、或把两种跳月定义平均。

## 精确规则

### 合格池与填席集合

每个信号周五 `t`，先看 `risk_on = (b ≥ 0.45)`。`risk_on` 为假：与 FACE 相同，E0 / `breadth_off` 出清，本周不填席。

`D_t`（当周冲击池）= 当周同时满足：

1. `in_play` 且 `in_play_kind == spike_ft`；
2. 不是 `box_pending` / `pending_second_week`；
3. 有有限的主簿 / 邻档 `skip_mom`；
4. 在 AUM≥2 亿研究池内。

`D_t` **包含已持仓**（只要仍是 spike_ft 且 `skip_mom` 有限）。跳月键是名字相对自身价格路径的属性，不因账上已有谁而改。跳月**不**减截面均值——那是 residual-mom。

`C_t`（填席集合）= `D_t` 减去当前持仓（与 btheta `build_cands(..., skip=set(positions))` 相同）。

跳月排序不要求 `|D_t| ≥ 2`（没有去均值）。`C_t` 为空：已持仓维持到 E0；**空席空着**。禁止回退 SHARPE20，禁止从非 spike 池补，禁止把缺失 `skip_mom` 回退成 RET52 / R12w。

### 回看价格与跳月键

价格与 `sharpe_n_on` 同一条日 qfq 收盘。截止：**信号周五的前一交易日**。`(signal − last_bar).days > 5` → 缺失。

```
lookback_ret(closes, d, cal_days, min_bars):     # 与 residual-mom 同一函数
    sub = closes[: d − 1 日]
    若 (d − sub.index[-1]).days > 5 → None
    p1 = sub.iloc[-1]
    t0 = sub.index[-1] − cal_days
    past = sub[: t0]
    若 past 空 → None
    若 (sub.index[-1] − past.index[-1]).days > 5 → None
    p0 = past.iloc[-1]
    n_bars = 从 past.index[-1] 到 sub.index[-1] 的收盘根数
    若 n_bars < min_bars 或 p0≤0 或非有限 → None
    返回 p1 / p0 − 1

skip_mom(closes, d, long_cal, skip_cal, min_long, min_skip):
    R_long = lookback_ret(closes, d, long_cal, min_long)
    R_skip = lookback_ret(closes, d, skip_cal, min_skip)
    若任一为 None → None          # 禁止回退成 R_long（那是 RET52）
    若 R_skip ≤ −1 或非有限 → None
    返回 (1 + R_long) / (1 + R_skip) − 1
```

恒等（夹具锁死，不是可选实现）：

```
(1 + R_long) / (1 + R_skip) − 1  ==  p_skip / p_long − 1
```

其中 `p_now` 为 `d−1` 日收盘，`p_skip` / `p_long` 为从 `p_now` 往回 `skip_cal` / `long_cal` 的锚价。

| 键 | `long_cal` | `skip_cal` | `min_long` | `min_skip` |
|----|------------|------------|------------|------------|
| CSM12-S4（主） | 364 | 28 | 160 | 15 |
| CSM12-S2（邻） | 364 | 14 | 160 | 8 |
| CSM12-S8（邻） | 364 | 56 | 160 | 28 |
| CSM26-S4（邻） | 182 | 28 | 80 | 15 |

这是日历 52 周 / 26 周回看、跳过 4 / 2 / 8 周，**不是** RET8 / RET12 / RET52 那套「原始收益填席」的重开，也不是 residual-mom 的 R12**w**（84 日）去均值，也不是 PR#51 的月末 t−12→t−2。

禁止：简单差 `R52−R4`、月末锚、减截面均值、z 分、与 SHARPE20 加权、用信号日当天收盘、缺 `R_skip` 时回退 `R_long`。

### 排序与持仓

主簿 `CSM12-S4`：

```

```
