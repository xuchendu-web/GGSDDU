## 4. 精确规则（主簿 TS-MH8）

唯一改动：在 FACE 的 `simulate` 退出环里，E0 之前加一层单票时停。入场、填席键、TV、成本、周五时钟、E0 原文不动。

### 4.1 计数（与 PR#41 / FACE 引擎同一把尺，避免另造 off-by-one）

对持仓 `p`：

```
入场当周：weeks = 0
当周未触发任何退出：weeks += 1
触发判定：weeks >= N          # 主档 N = 8
```

入场当周不对新开仓做时停（`weeks = 0`）。走满 N 次「未退出则 +1」之后，**下一个信号周五** `weeks >= N`，强制清出。这就是「持有 ≥ N 周，在当周周五再平衡出场」。

不要改成「入场周 weeks=1」或「满 N 周的当周收盘盘中砍」。不要日频触发。不要组合层 overlay。

### 4.2 必须重挣席位

时停把该票从 `positions` 拿掉，`exit_reason = time_stop`。同一周五的 `build_cands` 以**清出后的持仓**为 `skip`。该票若仍是 `spike_ft` 且 SHARPE20 有限，回到候选池，按 SHARPE20 降序和别人抢空席。抢到 → 新开，`weeks = 0`，`entry_date = t`，付 FACE 原文的 0.2% RT。抢不到 → 空着，不从非 spike 池补。

主档 **K=0**：没有多周禁入。同一周五允许再入（「重挣」就在当次填席）。

### 4.3 可选冷静 K（规则写死，四件套不跑）

K 是**单票**再入禁窗，不是 PR#37 的组合亏损冷静。

```
时停发生在信号周五 t：
  first_eligible = t 之后第 K 个信号周五
  K = 0 → first_eligible = t     # 当周可再入
  K = 2 → first_eligible = t 之后第 2 个信号周五

填席：若 code 的 first_eligible 存在且当前周五 < first_eligible，则不进候选
```

四件套锁 K=0。K∈{2,4} 不进四件套、不进 H1、禁止与 N 做笛卡尔。若执行方多跑一本旁注，只许 `TS-MH8-K2`，且必须单独标 `SIDE`，不得写入 `positive_ids`。

### 4.4 退出优先级（写死）

对每个持仓、每个信号周五，按此顺序只留一个 `exit_reason`：

1. `eod_eval`（末日）
2. `breadth_off`（门关）
3. `time_stop`（本族，`weeks >= N`）
4. E0：`falsify` / `always_in_flip` / `left_structure`（原文；与时停共用当周 `px_on`）

E0 与时停同一周五都满足：记 `time_stop`，E0 原因写入旁标 `e0_also`，两条计数都加。breadth / 末日仍优先于时停。

未退出则 `weeks += 1`，与 FACE 相同。

### 4.5 同周五再入保险丝（披露，不改 N）

| 列 | 定义 |
|----|------|
| `n_timestop` | `exit_reason == time_stop` 的次数。F0 必须为 0 |
| `n_timestop_same_fri_reenter` | 时停当周又被 SHARPE20 填回的次数 |
| `n_cool_block` | 因 K 禁窗没进候选的次数。四件套必须为 0 |
| `avg_hold_weeks` | 已结束交易的 `weeks`（出场瞬间、尚未 +1）均值 |
| `n_e0` | `falsify` + `always_in_flip` + `left_structure` |

主簿 `n_timestop = 0`：机制没咬住 → **证伪**（不是 `BLOCKED`）。`n_timestop_same_fri_reenter / n_timestop > 0.8`（分母 >0）：旁注「计数器重置 / 成本泄漏」，**仍按第 6 节两闸判决**，不许事后改成 K=2 来「让它咬住」。

## 6. 证伪尺子（相对 in-run F0）

百分比差用百分点。`Δret = ret_book − ret_F0`。`Δ|MDD| = |MDD_book| − |MDD_F0|`，回撤变深时为正。

与 ENTRY-SIGNAL / 吊灯出场族已锁的口径相同，**不另造 0.9× 或 −2pp**：

| 闸 | 过闸 |
|----|------|
| G1 收益盖住回撤 | `Δret ≥ Δ\|MDD\|` |
| G2 后段不踏空（硬闸） | 2023–26 累计收益 `≥` F0 的 2023–26 累计收益，且本身为正 |

两闸都打在**主簿 `TS-MH8`** 上。2023–26 的「不踏空」是 **≥ F0**，不是旧 PT/COOL/MH 刀用过的「≥ 90% FACE」或「Calmar ≥ 基准」。分段边界与延窗相同：2020-01-01…2022-12-31，以及 ≥2023-01-01 直到 2026-10-23。

Calmar、Sharpe、一手换手、`n_timestop` 是主表必报列，**不是第三闸**。Calmar 劣于 F0 只旁注，不单独否决。2020–22 必须进主表；前段变弱、后段不踏空、且 G1 仍过时，可以 `记正`。前段不单独否决，**后段踏空否决**。

相等算过闸。任一字段缺失或 NaN → 证伪。

`记正`（不换冠）的句子：

> 记正（不换冠）：TS-MH8 两闸全过。Δret 与 Δ|MDD|、2023–26 收益、时停次数、同周五再入、一手换手各写实测差。邻档只旁注。

`证伪`（不换冠）的句子：

> 证伪（不换冠）：TS-MH8 未过闸 Gx。写上两闸的实测。邻档即使全过也不升格。

`BLOCKED` 不叫记正，也不叫证伪。触发：第 1 节锚容忍、输入缓存缺失、F0 落到 158.3% 那条引擎。
