## 面已完全冻结（写死）

面层旋钮在 CLOUD-BATCH 之后没有「自由旋钮」。B45、max5、E0、TV25、SHARPE20、0.2% RT、L≤1、周五 ≥14:30 全部锁死。

因此：

- **训练窗里不允许选型。** 不挑 TV，不挑 θ，不挑 maxN，不挑填席，不挑出场。
- Walk-forward 报的是 **冻结规则本身的 OOS**，对照 **全样本 in-sample 面**（F0 = 同一条路径的全窗 `stats_full`）。
- 所谓 train 只用来切折界、写 IS 前缀披露。它不改变持仓，不改变杠杆。
- 算术后果：本刀 **不是** 四条不同策略。它是 **一条冻结净值被四种窗长切开**。主协议 step = test 时，OOS 拼接就是该路径从首个测试周起的后缀（去掉末尾不足一折的尾巴）。这不是实现错误，必须在 REPORT 里写明。

若执行方在训练窗里重新挑了任何旋钮：`family_verdict = BLOCKED`。那是另一刀，不是本卡。

## 精确协议（主档，冻结一档）

持有周下标 `0 … T−1`，`T = 348`。信号周五日历与 btheta 针对齐；最后一根没有前向收益的哨兵周五不进 T。

```
train_w = 104
test_w  = 26
step_w  = 26          # = test_w：OOS 折互不重叠
```

折生成（滚动、定长训练，不是扩张窗）：

```
folds = []
start = train_w
while start + test_w <= T:
    train = [start - train_w, start)     # 右开
    test  = [start, start + test_w)
    folds.append((train, test))
    start += step_w
leftover = T - folds[-1].test.stop       # 不足 test_w 的尾巴丢掉
```

主档算术（T=348 时必须对上，对不上就 `BLOCKED`，不要改 train_w 去凑）：

| 项 | 值 |
|----|----|
| 折数 | 9 |
| 各折 test 起点（周下标） | 104, 130, 156, 182, 208, 234, 260, 286, 312 |
| 末折 test | [312, 338) |
| leftover | 10 周（下标 338…347），**不评分** |
| OOS 覆盖 | 周 [104, 338)，共 234 周 |

被否掉的做法：

- 扩张窗（train 从 0 一直长到 start）。本刀是滚动定长 104。
- step < test（OOS 重叠，拼接会重复计同一段）。
- 把 leftover 短折硬评分（短窗 Calmar 噪声当证据）。
- 每折在 test 起点清空持仓、重开组合。OOS 必须从**同一条连续冻结路径**切片；仓位跨 train→test 连续。
- 清洗 / 禁运。冻结规则没有训练选型，没有标签泄漏需要 purge。不要把 CPCV 的 h=1 / e=4 搬过来改路径。

### 每折与拼接

日净收益序列 `r_d` 只来自一次 F0 回放（fork btheta 针，参数锁在面上）。

- **折 OOS**：该折 test 周对应的交易日 `r_d`（信号周五 `t` 的持有期为 `(friday_t, friday_{t+1}]`，与 overfit-guards / btheta 周界一致）。对该段独立调用 `stats_full`，NAV 从 1 起。只列表，不进家族旗。
- **OOS 拼接（主评判）**：按时间顺序把各折 test 的日收益接成一条，保留原时间戳，再调用一次 `stats_full`。主档 step=test，这段就是后缀 `[104, 338)`。起点 NAV=1。CAGR 的 `n` 用这段首尾日历天数，**禁止**拿全样本 2020-01-03→2026-10-23 的 `n` 去年化 OOS。
- **IS 前缀（披露）**：周 `[0, train_w)` 上同一条 `r_d` 的 `stats_full`。主档即前 104 周。用来看「OOS 相对这段前缀」而不是用来过闸。
- **F0 全样本**：周 `[0, 348)`（含 leftover 10 周）的 `stats_full`。这是锚，也是「in-sample full-sample」。闸的对照是它，不是 IS 前缀。

OOS 的 ret 与 131.6% **不是同一投资期**。主表必须并排 OOS ret / maxDD / Calmar / Sharpe，闸只用 Calmar 与 |maxDD|，不用「OOS ret 小于 131.6」当证伪。

## 邻档（协议窗长，≤4；冻结一档主协议）

邻档问的是「切开的位置会不会改变塌/不塌」，不是再给面找旋钮。只动 `(train_w, test_w, step_w)`，`step_w = test_w`。规则仍全冻结。

|----|---------------------|------|------------------|----------------|----------|
| F0 | — | 全样本冻结面（锚） | — | — | — |

## 强势段注（必须写进 REPORT，先于家族句）

仓库已发表的面层分段（PR#28 / PR#27 主表，本刀不重算当新锚）：

| 窗 | 切片 | 已发表（只引用） |
|----|------|------------------|

后段 Calmar 约是前段的四倍。主档首个 test 落在周 104 ≈ 2022 年初，OOS 覆盖 2022 弱段 + 2023–26 强段，**时间权重以后段为主**。

因此：

1. OOS 拼接 Calmar **高于** 全样本 0.70，是「把更差的 2020–21 前缀留在 IS」之后的算术预期，**不是稳健性确认**。
2. 家族结论禁止出现 `CONFIRMED` / `PROMOTE` / 「OOS 优于全样本」。未塌只准 `HOLD_CAVEAT`。
3. 折表必须给每折打 `period_tag`：
   - `WEAK_2020_22`：test 日历全在 2020-01-01…2022-12-31
   - `STRONG_2023_26`：test 日历全在 ≥2023-01-01
   - `MIX`：跨 2023-01-01
4. 主档折表里至少要能指认一折带 2022（弱段探针）。缺这列：`BLOCKED`。
5. 探索尺子「2023–26 不踏空」是**别的刀**用来防新机制踏空的。本刀审计的是全样本 X 会不会在 OOS 上塌；禁止用「OOS 后段很强」把塌缩闸翻成记正。

### 主档三闸（只打 WF-P10426 的 OOS 拼接）

```
G1 塌缩   = Calmar_OOS 非有限，或 Calmar_OOS < 0.50 × Calmar_FACE
G2 地板   = Calmar_FACE ≥ 0.30 且（Calmar_OOS 非有限或 Calmar_OOS < 0.15）
G3 回撤   = |maxDD_OOS| > 1.50 × |maxDD_FACE|
塌        = G1 或 G2 或 G3
未塌      = 三闸都假
```

0.50 倍沿用本仓库 walk-forward / CPCV 已经写死的红旗（PR#54 协议、PR#71 DESIGN 的 `FLAG_CPCV`），用在**等协议主档的 OOS 拼接**上，不用在单折短窗上。0.15 地板防止「全样本 0.70、OOS 掉到近零但仍高于 0.35」被漏掉——当且仅当 F0 Calmar ≥ 0.30。1.50 倍回撤闸接住「短窗 CAGR 噪声把 Calmar 撑住、但 OOS 回撤炸穿面层」的情况。

相等不算塌（`<` / `>`，不是 `≤` / `≥`）。单折 Calmar、IS 前缀 Calmar、邻档 Calmar、Sharpe、周胜率，都不进这三闸。

锚过且 F0 Calmar 落在 0.70±0.02 时，G1 阈值约为 0.35，G3 阈值约为 0.282 绝对值。REPORT 必须写出**本次** `0.50 × Calmar_FACE` 与 `1.50 × |maxDD_FACE|` 的实数，不要写死 0.35 / 0.282 当公式。
