## 零、理论哲学基础

### 0.1 理论的两大前提

缠论体系的成立建立在两个基本前提之上（第72课）：

**前提一：价格充分有效市场**
- 市场价格反映所有交易者的行为结果
- 每一笔成交都是当下市场合力的真实记录
- 不存在无法交易的价格区间

**前提二：非完全绝对趋同交易**
- 市场参与者之间存在认知差异
- 不可能所有人同一时刻做出完全相同的买卖决策
- 这种差异性导致了走势的波动性

> 这两个前提是**动力学部分**成立的基础。形态学部分无需任何前提——即使一个庄家全买了天天自交易，也逃不出形态学的几何圈圈。

### 0.3 基本概念定义（第17课）

#### 缠中说禅走势中枢（定义）

> 某级别走势类型中，被**至少三个连续次级别走势类型**所重叠的部分，称为缠中说禅走势中枢。

- 关键词：至少、三个、连续的次级别走势类型、重叠
- 最低级别（不可再分解）：至少三个该级别单位 K 线重叠部分

#### 缠中说禅盘整

> 在任何级别的任何走势中，某完成的走势类型**只包含一个**缠中说禅走势中枢。

#### 缠中说禅趋势

> 在任何级别的任何走势中，某完成的走势类型**至少包含两个以上依次同向**的缠中说禅走势中枢。方向向上为**上涨**，方向向下为**下跌**。

### 0.4 公理与定理体系

#### 基本原理

| 编号 | 内容 | 课号 |
|------|------|------|
| 原理一 | 任何级别的任何走势类型终要完成（**走势终完美**） | 第17课 |
| 原理二 | 任何级别任何完成的走势类型，必然包含一个以上的缠中说禅走势中枢 | 第17课 |

"走势终完美"有两个不可分割的方面：
1. **任何走势在图形上最终都要完成**（趋势终完美，盘整也终完美）
2. **一旦某种类型的走势完成后，就会转化为其他类型的走势**（"不患"而有其位次）

#### 走势分解定理

| 定理 | 内容 |
|------|------|
| 分解定理一 | 任何级别的任何走势，都可以分解成同级别"盘整"、"下跌"与"上涨"三种走势类型的连接 |
| 分解定理二 | 任何级别的任何走势类型，都至少由三段以上次级别走势类型构成 |

#### 买卖点定理

| 定理 | 内容 | 课号 |
|------|------|------|
| 背驰-买卖点定理 | 任一背驰都必然制造某级别的买卖点，任一级别的买卖点都必然源自某级别走势的背驰 | 第24课 |
| 买卖点定律一 | 任何级别的第二类买卖点都由次级别相应走势的第一类买卖点构成 | 第17课 |
| 趋势转折定律 | 任何级别的上涨转折都由某级别的第一类卖点构成；任何级别的下跌转折都由某级别的第一类买点构成 | 第17课 |

### 0.5 核心操作哲学（第3/5/19/41/80课）

1. **你的喜好，你的死亡陷阱**（第3课）：任何对股票的情感都是亏损的根源
2. **市场无须分析，只要看和干**（第5课）：看图作业，不做无意义的预测

## 一、形态学（上）：分型与笔

### 1.1 K 线包含处理 —— 标准算法

#### 1.1.1 包含关系的定义

两根相邻 K 线，如果**一根 K 线的高低点完全在另一根 K 线的高低点范围内**，则这两根 K 线存在包含关系。

判断条件伪代码：
```
def has_contain(prev_K, curr_K):
    # prev_K 完全包含 curr_K
    if prev_K.high >= curr_K.high and prev_K.low <= curr_K.low:
        return True, "prev_contains_curr"
    # curr_K 完全包含 prev_K
    if curr_K.high >= prev_K.high and curr_K.low <= prev_K.low:
        return True, "curr_contains_prev"
    return False, None
```

#### 1.1.2 包含处理的方向判断

包含处理的方向由**前面已经处理过的两根非包含 K 线**的关系决定：

```
处理方向：
- 向上（前一根非包含K线低点 < 当前非包含K线低点）：
  新K线高点 = max(两根包含K线的高点)
  新K线低点 = max(两根包含K线的低点)  ← 取"高高、低高"

- 向下（前一根非包含K线低点 > 当前非包含K线低点）：
  新K线高点 = min(两根包含K线的高点)  ← 取"高低、低低"
  新K线低点 = min(两根包含K线的低点)
```

记忆口诀：
- **向上取高高**（高的高点 + 高的低点）
- **向下取低低**（低的高点 + 低的低点）

#### 1.1.3 完整的包含处理流程

```
算法：K线序列包含处理

输入：原始K线列表 raw_klines[]
输出：无包含关系的K线列表 clean_klines[]

步骤：
1. 将第一根K线加入 clean_klines
2. 从 i=1 到 len(raw_klines)-1：
   a. 将 raw_klines[i] 与 clean_klines[-1]（已处理序列的最后一根）比较
   b. 如果不包含 → 直接加入 clean_klines
   c. 如果包含：
      - 确定方向：看 clean_klines[-2] 与 clean_klines[-1] 的关系
        （如果 clean_klines 只有1根且当前出现包含，参考前一根原始K线方向）
      - 按方向规则合并，替换 clean_klines[-1]
      - 继续用合并后的K线与下一根原始K线比较（连锁包含处理）
3. 返回 clean_klines
```

#### 1.1.4 包含处理的特殊情形

| 情形 | 处理方式 |
|------|---------|
| 连续多根K线包含 | 逐根合并，每次合并后可能产生新的包含关系，继续合并直到无包含 |
| 第一根K线就被包含 | 先保留第一根，以第二根相对于第一根的方向作为处理方向 |
| 完全相同的K线（等高低） | 按向上处理（取max-min=max-min原值）|

### 1.2 分型（Fractal）—— 定义与识别

#### 1.2.1 顶分型的严格定义

三根相邻无包含关系的 K 线，编号 1、2、3，满足：

```
顶分型判定条件（三个条件同时成立）：
（1）K2.high > K1.high  AND  K2.high > K3.high   （第2根高点最高）
（2）K2.low  > K1.low   AND  K2.low  > K3.low    （第2根低点最高）
（3）K1、K2、K3 之间无包含关系（已处理）
```

```
顶分型图示（ASCII侧视图）：

      ┌─┐  ← K2（最高）
      │ │
  ┌─┐ │ │
  │ │ │ │  ┌─┐
  │ │ │ │  │ │
  │ │ │ │  │ │
  └─┘ └─┘  └─┘
  K1   K2    K3

顶分型的顶 = K2.high（顶分型的底即K2.low无独立意义，统称"顶"时指K2.high）
```

#### 1.2.2 底分型的严格定义

三根相邻无包含关系的 K 线，编号 1、2、3，满足：

```
底分型判定条件（三个条件同时成立）：
（1）K2.low  < K1.low   AND  K2.low  < K3.low    （第2根低点最低）
（2）K2.high < K1.high  AND  K2.high < K3.high   （第2根高点最低）
（3）K1、K2、K3 之间无包含关系（已处理）
```

```
底分型图示：

  ┌─┐     ┌─┐
  │ │ ┌─┐ │ │
  │ │ │ │ │ │
  │ │ │ │ │ │
  └─┘ └─┘ └─┘
  K1   K2   K3
       ↑
    最低点

底分型的底 = K2.low
```

#### 1.2.3 分型后的K线分类（第62课完全分类）

经过包含处理后，三相邻 K 线共有四种可能组合：

| 类型 | 特征 | 名称 |
|------|------|------|
| 类型一 | K1.low < K2.low < K3.low 且 K1.high < K2.high < K3.high | 上升 K 线 |
| 类型二 | 顶分型 | 顶分型 |
| 类型三 | K1.low > K2.low > K3.low 且 K1.high > K2.high > K3.high | 下降 K 线 |
| 类型四 | 底分型 | 底分型 |

> 上升的一笔 = 底分型 + 上升K线（若干根）+ 顶分型
> 下降的一笔 = 顶分型 + 下降K线（若干根）+ 底分型

#### 1.2.4 分型的强弱分类

**顶分型强弱判断**：
| 强弱 | 特征 | 含义 |
|------|------|------|
| 最强顶分型 | 第三根K线收盘跌破第一根K线低点 | 反转概率极高 |
| 中等顶分型 | 第三根K线收在第一根低点之上但第二根高点之下 | 需要下一根K线确认 |
| 最弱顶分型 | 第三根K线收盘接近第二根高点 | 多为中继分型 |

**底分型强弱判断**（对称）：
| 强弱 | 特征 | 含义 |
|------|------|------|
| 最强底分型 | 第三根K线收盘升破第一根K线高点 | 反转概率极高 |
| 中等底分型 | 第三根K线收在第一根高点之下但第二根低点之上 | 需要确认 |
| 最弱底分型 | 第三根K线收盘接近第二根低点 | 多为中继分型 |

#### 1.2.5 分型操作法则（第79/82课）

**中继分型 vs 转折分型的判断**：

1. 出现顶分型后：
   - 如果后续走势不能有效跌破该分型的最低点（即分型中三根K线的最低价），则该分型**很可能是中继分型**
   - 如果后续有效跌破，则确认为转折分型

2. 出现底分型后：
   - 如果后续走势不能有效升破该分型的最高点（即分型中三根K线的最高价），则该分型**很可能是中继分型**
   - 如果后续有效升破，则确认为转折分型

3. 分型的心理意义（第82课）：
   - 顶分型 = 预期不能继续上涨的市场合力第一次占优
   - 底分型 = 预期不能继续下跌的市场合力第一次占优
   - 再次跌破/升破分型的关键价位，意味着反向预期的进一步强化或弱化

### 1.3 笔（Stroke）—— 构建规则与修正

#### 1.3.1 笔的标准定义

**笔**：两个相邻的顶分型和底分型之间的连线。

#### 1.3.2 新笔的构成条件（严格版）

```
一笔成立的必要条件（全部满足）：

（1）顶分型和底分型之间至少有一根独立K线
    → 即两个分型之间共享K线不超过1根
    → 换句话说：顶分型的最高那根K线与底分型最低那根K线
       之间至少隔了1根既不属于顶分型也不属于底分型的K线

（2）顶分型和底分型必须是相邻的分型
    → 两个顶分型之间如果没有底分型，取最高的那个
    → 两个底分型之间如果没有顶分型，取最低的那个
    → 这叫"分型的包含处理"——分型也可以合并

（3）顶分型必须比底分型高（对于上升笔）
    底分型必须比顶分型低（对于下降笔）
    → 如果顶分型的顶 ≤ 底分型的底，这笔不成立，取极端的分型继续
```

#### 1.3.3 宽笔 vs 严笔

缠论在不同阶段对笔的要求有微妙差异：

| 标准 | 要求 | 适用场景 |
|------|------|---------|
| **旧笔（严笔）** | 顶底之间必须至少有一根独立K线 | 学术精确分析 |
| **新笔（宽笔）** | 允许顶底之间没有独立K线，但分型不能共用K线 | 实际操作（第71课后） |

> 对于机构操作级别（30分钟以上），建议使用严笔标准，容错率更高。

#### 1.3.4 笔的修正规则

当后续走势出现新高/新低时，需要修正之前的笔划分：

```
笔修正原则：
1. 新的顶分型出现后（高于前一顶），原来不成立的笔可能变为成立
2. 新的底分型出现后（低于前一底），原来不成立的笔可能变为成立
3. 修正原则：后面走出来的优先
4. 一旦一笔被确认，就不能被后续走势改变（确定性原则）
```

#### 1.3.5 特殊笔的处理

| 情形 | 处理方式 |
|------|---------|
| 一字涨停/跌停造成的大量K线无重叠 | 如果这些K线内部没有分型，当作一根处理 |
| 除权除息缺口 | 使用前复权数据，消除除权缺口 |
| 相邻两个顶分型没有底分型 | 保留最高的顶分型，删除较低的 |
| 相邻两个底分型没有顶分型 | 保留最低的底分型，删除较高的 |
| 顶分型高于前顶但两者之间无底分型 | 这不是一笔的结束——等待底分型出现 |

### 1.4 分型与笔的实战意义

操作级别的选择与对应的形态构件：

## 二、形态学（中）：线段

### 2.1 线段的基本定义（第62/65课）

**线段**：至少由**连续三笔**构成，且**前三笔必须有重叠部分**。

线段是比笔高一个级别的形态构件。如果说笔是走势的"砖块"，线段就是"预制板"。

#### 线段三要素

1. **至少三笔**：少于三笔不构成线段
2. **前三笔重叠**：第一笔的终点必须和第二笔的起点有价格重叠
3. **方向由第一笔决定**：
   - 向上线段：从底分型开始，走向上的第一笔
   - 向下线段：从顶分型开始，走向下的第一笔

### 2.2 特征序列 —— 线段划分的核心工具（第67/71课）

#### 2.2.1 特征序列的定义

**特征序列**：以某线段为基准，与该线段方向**相反**的所有笔构成的序列。

```
向上线段的特征序列：该线段中所有的 向下笔
向下线段的特征序列：该线段中所有的 向上笔
```

```
图示（向上线段及其特征序列 S1, S2, S3...）：

       X1    X3    X5    ← 向上笔（确定线段方向）
      /  \  /  \  /  \
     /    \/    \/    \
    /     /\    /\     \
   /     /  \  /  \     \
  S1    S2   S3   S4    S5  ← 向下笔（特征序列元素）
```

#### 2.2.2 特征序列的包含处理

特征序列元素之间也可能存在包含关系，需要进行**特征序列的包含处理**。

规则与 K 线包含处理一致：
- 向上线段中（特征序列为向下笔）：按向下方向处理包含
- 向下线段中（特征序列为向上笔）：按向上方向处理包含

#### 2.2.3 线段被破坏的两种情况

##### 情况一：特征序列存在缺口（第一、二元素间无缺口）

```
判定：特征序列出现顶分型（向上线段）或底分型（向下线段），
       且该分型的第一元素与第二元素之间不存在价格缺口。

结果：原线段结束于该分型的顶点/低点。

这是最简单、最常见的线段破坏方式。
```

**向上线段被破坏（出现特征序列顶分型，无缺口）**：

```
原线段从特征序列顶分型处结束于高点，新向下线段开始。
处于顶分型最高处的转折点就是线段的终点。
```

**向下线段被破坏（出现特征序列底分型，无缺口）**：

```
原线段从特征序列底分型处结束于低点，新向上线段开始。
处于底分型最低处的转折点就是线段的终点。
```

##### 情况二：特征序列存在缺口（第一、二元素间有缺口）

```
判定：特征序列出现分型，但该分型的第一元素与第二元素之间
       存在价格缺口（即第二元素的终点没有回到第一元素的价格区间内）。

处理：不能立即确认线段结束。需要从该分型的顶点开始，
      等待反向走出一笔，看这一笔之后能否形成反向的特征序列分型。

最终判定：
- 如果反向线段走到能形成自己的特征序列底分型（对原向上线段）
  → 原线段结束，新的反向线段确认
- 如果反向线段不能形成特征序列分型就重新被原方向突破
  → 原线段延续，前面的特征序列顶分型被合并
```

### 2.3 线段划分的标准操作流程（SOP）

```
线段划分 SOP（在给定起始方向上）：

Step 1: 确定线段方向（第一笔的方向）
        向上线段：从底分型开始的向上笔
        向下线段：从顶分型开始的向下笔

Step 2: 收集特征序列
        向上线段：收集向下的笔作为特征序列元素
        向下线段：收集向上的笔作为特征序列元素

Step 3: 对特征序列进行包含处理
        按与线段方向相反的规则合并包含的特征序列元素

Step 4: 寻找特征序列分型
        向上线段中找特征序列的顶分型
        向下线段中找特征序列的底分型

Step 5: 判断缺口
        IF 分型的第一、二元素间无缺口：
          → 线段结束于该分型顶点/低点
          → 新线段开始
        ELSE（有缺口）：
          → 暂不确定，进入 Step 6

Step 6: 等待反向确认（仅当有缺口时）
        等待从该分型顶点出发的反向线段
        反向线段能否形成特征序列分型？
          YES → 原线段结束，反向线段确认
          NO  → 原线段延续，特征序列分型作废

Step 7: 继续跟踪
        如果线段延续，回到 Step 2 继续收集特征序列
```

### 2.4 线段划分中的特殊情况

#### 2.4.1 缺口处理

| 缺口类型 | 处理方式 |
|---------|---------|
| 顺着原一笔方向的缺口 | 包含在该笔中，不单独成段 |
| 逆着原一笔方向的强势缺口 | **必须当作独立一段**（如530型缺口） |
| 多缺口连续 | 每个缺口可视为三段（0=0+0+0原则），即至少三笔 |

#### 2.4.2 线段以下级别的类中枢

在线段内部的震荡中，可以形成**类中枢**（严格意义上线段以下没有中枢）：

- 用途：判断线段内部的背驰
- 定位：线段内下-上-下（或上-下-上）三次重叠
- 操作意义：线段级别的操作者可利用类中枢做 T+0

#### 2.4.3 精度预设原则（第64课）

```
1. 预设精度后必须严格统一
2. 数值相差 0.5 点以内可视为相同（或其他预设容差）
3. 不同软件的数值有细微差异不影响判断
4. 关键不是精确到小数点，而是逻辑一致性
```

### 2.5 线段与走势类型的关系

```
线段（最小级别图上）
  ↓ 三段线段有重叠
最小级别中枢（1分钟中枢）
  ↓ 三段1分钟走势类型重叠
5分钟级别中枢
  ↓ 递归...
更高级别中枢
```

> 关键认知：只有在最小级别图上，线段才直接构成中枢。更高级别的中枢由次级别**走势类型**（不是线段）的重叠构成。

## 三、形态学（下）：中枢与走势类型

### 3.1 中枢的完整定义与构建

#### 3.1.1 中枢的两种构建方式

**方式一：最小级别中枢（用线段）**

```
在选定的最小级别图（如1分钟图）上，
三条连续的、有重叠的线段 → 构成1分钟级别中枢

中枢区间：
  ZG = min(三个线段高点的最高值)
  ZD = max(三个线段低点的最低值)

中枢成立条件：ZD < ZG（即三段确实有重叠）
```

**方式二：高级别中枢（用次级别走势类型）**

```
三个连续的次级别走势类型重叠 → 构成高一级别中枢

例如：三个5分钟级别走势类型重叠 → 30分钟级别中枢
```

#### 3.1.2 中枢的精确数学表达

```
设三段走势为 S1, S2, S3

S1 区间：[s1_low, s1_high]
S2 区间：[s2_low, s2_high]
S3 区间：[s3_low, s3_high]

中枢高点 ZG = min(s1_high, s2_high, s3_high)
中枢低点 ZD = max(s1_low, s2_low, s3_low)
中枢区间 = [ZD, ZG]

波动区间：
  波动高点 GG = max(s1_high, s2_high, s3_high)
  波动低点 DD = min(s1_low, s2_low, s3_low)
  波动区间 = [DD, GG]

在中枢构建期间（震荡）：
  触及 ZG 或 ZD 但未有效突破 → 仍在中枢震荡范围内
  有效突破 ZG → 可能离开中枢
  有效跌破 ZD → 可能离开中枢
```

#### 3.1.3 中枢的方向

中枢本身不区分方向，但根据构建中枢的三段方向：

```
- 由"下-上-下"三段构成的中枢 → 属于下跌+盘整中 → 注意向上突破
- 由"上-下-上"三段构成的中枢 → 属于上涨+盘整中 → 注意向下突破
```

中枢的方向由其前后走势决定：
```
前走势向下 + 中枢 → 中枢偏空（反弹中枢）
前走势向上 + 中枢 → 中枢偏多（回调中枢）
```

### 3.2 中枢的三种演化路径（第20/33课）

#### 3.2.1 中枢新生（中枢上移/下移）

```
定义：前后两个同级别中枢的区间完全不重叠。

上涨趋势中的中枢新生：
  [中枢1] → 离开段 → [中枢2]
  中枢1的最高点 < 中枢2的最低点（完全不重叠）

下跌趋势中的中枢新生：
  [中枢1] → 离开段 → [中枢2]
  中枢1的最低点 > 中枢2的最高点（完全不重叠）

操作意义：
  - 两个同向不重叠的中枢 = 趋势成立
  - 中枢新生是趋势延续的最强信号
```

#### 3.2.2 中枢扩展（级别提升）

```
定义：前后两个同级别中枢的区间发生重叠，
      但又不是回到前中枢内部的情况。

具体表现：
  - 第三类买卖点后，次级别回拉的幅度超过了预期
  - 两个中枢的波动区间有重叠但中枢区间不重叠

结果：中枢级别扩大一级
  例如：两个5分钟中枢扩展 → 形成30分钟级别中枢

识别标志：
  原中枢的[ZD, ZG]与新中枢的[ZD', ZG']区间部分重叠
  → 合并为更大级别的中枢
  → 区间 [max(ZD, ZD'), min(ZG, ZG')]
```

#### 3.2.3 中枢扩张（更复杂的形式）

```
定义：走势反复穿越中枢区间，形成更大范围的震荡。

三种表现形式：
  1. 三角形收敛 → 中枢越缩越小
  2. 矩形箱体 → 来回震但不缩
  3. 扩散形 → 中枢越放越大

结果：中枢级别大幅提升
  例如：日线中枢扩张 → 周线中枢
```

#### 3.2.4 演化路径图

```
                    原有的中枢
                        │
          ┌─────────────┼─────────────┐
          │             │             │
       第三类         中枢区间      第三类
       买点确认       内震荡        卖点确认
          │             │             │
     ┌────┴────┐   中枢延伸    ┌────┴────┐
     │         │   (盘整延续)   │         │
  中枢新生   中枢扩展         中枢新生   中枢扩展
  (趋势延续) (级别提升)      (趋势延续) (级别提升)
```

### 3.3 中枢震荡监视器（第92课）

在中枢震荡期间，用以下指标监控震荡的力度与方向：

#### 3.3.1 中枢震荡的买卖点分类

```
中枢震荡中任何离开中枢的次级别走势：

1. 离开后次级别回拉不跌回中枢 → 第三类买点
2. 离开后次级别回拉跌回中枢 → 中枢震荡延续
3. 离开后次级别回拉且创新低/新高 → 需重新评估
```

#### 3.3.2 中枢震荡的操作节奏

```
原则：中枢下沿附近 + 次级别底背驰 → 买入
      中枢上沿附近 + 次级别顶背驰 → 卖出
      或者说：中枢低点买，中枢高点卖

仓位控制：
  - 底仓：保持基本方向仓位不动
  - 浮动仓：在中枢震荡中做差价
  - 浮动仓比例 = f(中枢宽度, 操作级别)
```

### 3.4 走势类型的完备分类

#### 3.4.1 六种基本连接方式

任何级别的任何完成的走势类型，与其他走势类型之间，有且只有六种连接方式：

```
上涨 + 盘整 + 上涨   上涨 + 盘整 + 下跌   上涨 + 下跌
下跌 + 盘整 + 下跌   下跌 + 盘整 + 上涨   下跌 + 上涨
```

#### 3.4.2 走势类型的完成标志

```
盘整完成的标志：出现第三类买卖点
  - 向上突破中枢后回拉不跌回 → 第三类买点 → 上涨
  - 向下突破中枢后回拉不升回 → 第三类卖点 → 下跌

趋势完成的标志：背驰
  - 上涨趋势：最后一个中枢前后两段背驰 → 趋势完成
  - 下跌趋势：最后一个中枢前后两段背驰 → 趋势完成
```

#### 3.4.3 "走势终完美"的操作应用

```
核心逻辑：
1. 任何走势类型终要完成
2. 完成后必然转化为其他类型

操作推导：
  对于下跌走势 → 一旦完成 → 只能转化为盘整或上涨
  → 在第一类买点（下跌完成点）买入
  → 最少获利的空间：盘整的中枢震荡高度
  → 最大获利空间：上涨趋势的全部高度
```

## 四、动力学：背驰与能量

### 4.1 背驰的严格定义

#### 4.1.1 趋势背驰

**定义**：在一个趋势中，**围绕最后一个中枢的前后两段同向走势**之间的力度比较。

```
结构：a + A + b + B + c

其中：
  A, B = 本级别中枢
  a = A之前的走势段（进入段）
  b = A和B之间的走势段（连接段）
  c = B之后的走势段（离开段/背驰段）

背驰判断：比较 b 和 c 的力度
  如果 c 的走势力度 < b 的走势力度 → 趋势背驰成立
```

**力度比较的方法**：
1. 走势斜率比较
2. 成交量比较

#### 4.1.2 盘整背驰

**定义**：在盘整（只有一个中枢）走势中，**中枢前后两段**之间的力度比较。

```
结构：a + A + b

其中：
  A = 本级别中枢
  a = 进入段
  b = 离开段

盘整背驰判断：比较 a 和 b 的力度

三种结果：
  1. b段力度 < a段力度 且 b段不破中枢 → 必回中枢
  2. b段力度 < a段力度 但 b段已破中枢 → 先卖出，等回拉不破中枢再买回（→第三类买点）
  3. b段力度 ≥ a段力度 → 中枢突破有效，趋势可能延续
```

#### 4.1.3 类背驰（中枢震荡中的背驰）

**定义**：在中枢震荡内部，次级别走势之间的力度比较。

用于在中枢震荡中精确操作 T+0 差价。

### 4.3 区间套——精确定位买卖点（第61课）

#### 4.3.1 区间套的数学原理

区间套定理源于数学分析中的区间套定理（闭区间套定理）。在缠论中的应用：

```
大级别背驰段 → 次级别背驰段 → 次次级别背驰段 → ... → 1分钟背驰点
     ↓                ↓                  ↓                     ↓
   潜在转折         确认转折范围      进一步缩小              精确到点
```

#### 4.3.2 区间套的标准操作流程

```
Step 1: 确定大级别背驰段
  在操作级别的图表上，确认是否进入了背驰段
  （如：30分钟图上，c段是否正在运行且力度小于b段）

Step 2: 进入次级别验证
  在背驰段的内部（次级别图），看次级别是否也出现背驰
  例如：30分钟的c段内部，在5分钟图上是否出现背驰

Step 3: 继续向下递归
  在次级别的背驰段内部（次次级别图），继续找背驰
  例如：5分钟的背驰段内部，在1分钟图上是否出现背驰

Step 4: 精确定位
  在最底层的级别上找到精确的背驰转折点

Step 5: 执行操作
  在最底级别背驰点执行买卖
```

#### 4.3.3 区间套实战判断要点

```
要点一：没有创新高/新低就没有背驰
  背驰的前提是价格必须创了新高（对卖点）或新低（对买点）

要点二：每一层都要比较对一段
  确保每一层比较的都是同一中枢的前后两段

要点三：背驰 ≠ 立即大幅反向
  背驰只保证"至少回到该级别的最后一个中枢"
  幅度取决于：①级别大小 ②多级别共振情况

要点四：小转大的识别
  如果小级别背驰后走势不回中枢 → 可能转换为大级别趋势延续
```

### 4.4 力度比较的多种方法

#### 4.4.1 综合力度评估体系

```
力度 = f(走势长度, 走势角度, 成交量结构, 中枢位置)

具体评估维度：
1. 空间维度：走势段的绝对涨跌幅
2. 时间维度：完成该段所用的K线数量（时间越长力度越小）
3. 成交量：量价配合情况（放量上涨→力度强，缩量上涨→力度弱）
```

#### 4.4.2 走势力度的直观判断

```
强势特征：
  - K线实体大、影线短
  - 走势角度陡（>45度）
  - 成交量持续放大
  - 次级别回调浅且短

弱势特征（背驰信号的增强因素）：
  - K线实体小、影线长
  - 走势角度平缓（<30度）
  - 成交量萎缩
  - 次级别回调深且长
```

### 4.5 转折的力度与级别（第29课）

上涨趋势结束后的三种转折力度（以日线上涨为例）：

| 力度级别 | 转折形式 | 技术特征 | 操作意义 |
|---------|---------|---------|---------|
| 最弱 | 最后一个中枢的级别扩展 | 下跌只触及最后一个中枢的DD | 盘整后可能继续上涨 |
| 中等 | 更大级别的盘整 | 下跌回到倒数第二个中枢区间 | 至少走大级别盘整 |
| 最强 | 同级别或更大级别的反向趋势 | 下跌跌破所有中枢 | 趋势反转确认 |

> "背驰后的三种情况"是缠论判断转折力度的核心框架。

## 五、买卖点系统

### 5.1 第一类买卖点

#### 5.1.1 第一类买点（一买）

```
定义：下跌趋势中，最后一个中枢之下，走势力度背驰产生的最低点。

形成条件（全部满足）：
  1. 存在下跌趋势（至少两个依次向下的同级别中枢）
  2. 最后一个中枢之后，走势创了新低
  3. 创新低的这段走势力度小于中枢前一段同向走势的力度（背驰）
  4. 背驰通过区间套在次级别精确确认

位置：最后一个下跌中枢的ZD（中枢低点）之下
安全性：由"走势终完美"和"趋势转折定律"严格保证
风险等级：高（抄底），但理论上最安全
```

#### 5.1.2 第一类卖点（一卖）

```
定义：上涨趋势中，最后一个中枢之上，走势力度背驰产生的最高点。

形成条件（全部满足）：
  1. 存在上涨趋势（至少两个依次向上的同级别中枢）
  2. 最后一个中枢之后，走势创了新高
  3. 创新高的这段走势力度小于中枢前一段同向走势的力度（背驰）
  4. 背驰通过区间套在次级别精确确认

位置：最后一个上涨中枢的ZG（中枢高点）之上
```

#### 5.1.3 第一类买卖点的精确定位公式

```
一买位置 = 下跌趋势最后一个中枢的ZD之下 + 区间套背驰点
一卖位置 = 上涨趋势最后一个中枢的ZG之上 + 区间套背驰点

最小保证幅度（背驰后必回）：
  一买后最少回到最后一个中枢的DD之上
  一卖后最少回到最后一个中枢的GG之下
```

### 5.2 第二类买卖点

#### 5.2.1 第二类买点（二买）

```
定义：第一类买点出现后，第一次次级别回调不创新低的低点。

形成逻辑：
  1. 一买出现后，走势开始上涨（或盘整）
  2. 第一次次级别回调出现
  3. 回调的低点高于一买的最低点
  4. 如果此处出现次级别的底背驰 → 二买确认

位置：第一个上涨中枢的下沿附近（不一定精确在中枢内）

安全性：比一买高（趋势已经转折确认）
操作优先级：机构重仓点（二次确认 + 流动性更好）
```

#### 5.2.2 第二类卖点（二卖）

```
定义：第一类卖点出现后，第一次次级别反弹不创新高的高点。
位置：第一个下跌中枢的上沿附近
安全性：比一卖更可靠
```

#### 5.2.3 二买与一买的关系

```
时间维度：二买在一买之后出现（必然的先后顺序）
价格维度：二买可以高于、等于、或低于一买（三种情况）

二买高于一买：最强情况（标准回调）
二买等于一买：中等（双底结构）
二买低于一买：最弱（可能一买判断有误或级别不对）

注意：二买绝对不能低于一买的最低点——否则一买不成立，
      需要重新评估走势。
```

> 缠中说禅买卖点定律一：任何级别的第二类买卖点都由次级别相应走势的第一类买卖点构成。

### 5.3 第三类买卖点

#### 5.3.1 第三类买点（三买）—— 最有效率的买点

```
定义：离开中枢后，第一次次级别回拉不跌回中枢的次级别低点。

形成条件（全部满足）：
  1. 走势离开中枢（次级别走势突破中枢的ZG）
  2. 次级别回拉出现
  3. 回拉的最低点 > 中枢的ZG（即不跌回中枢）
  4. 回拉在次级别出现背驰（确认回拉完成）

位置：中枢的ZG（高点）之上

操作价值：
  - 三买确认中枢向上突破有效 → 可能开启新趋势
  - 三买是最有效率的介入点（亏时间最少）
  - 尽量只介入第一个中枢的第三类买点
```

#### 5.3.2 第三类卖点（三卖）

```
定义：离开中枢后，第一次次级别回拉不升回中枢的次级别高点。
位置：中枢的ZD（低点）之下
操作价值：确认下跌趋势延续
```

#### 5.3.3 第三类买卖点的特殊组合

```
情况一：二买和三买重合
  二买的回调低点同时不跌回中枢 → 二买=三买
  这是最强信号，后续上涨力度通常很大

情况二：二卖和三卖重合
  二卖的反弹高点同时不升回中枢 → 二卖=三卖
  这是最弱信号，后续下跌力度通常很大

情况三：中枢的三买后立即出现三卖 = 中枢扩展
  先出现三买（向上假突破），然后出现三卖（向下真跌破）
  → 中枢扩展为更大级别
```

### 5.4 三类买卖点的级别对应关系

月线级别           数年一遇           年度级别            少有
周线级别           年度              季度                月级
日线级别           月度              周级                1-2周
30分钟级别         周内              1-3天              日内
5分钟级别          日内              小时级              分钟级
1分钟级别          分钟级            秒级                无意义
```

## 六、走势分解与多义性

### 6.1 走势的多义性（第33课）

#### 6.1.1 多义性的本质

走势的多义性**不是模糊性**，而是多角度分析的必然结果。不同的分解方式对应不同的操作策略，每一种都是有意义的。

> 多样性不是模糊性，而是多角度去让市场本身自己去画地为牢，由此使得市场的走势万变不离本ID理论的控制之中。

#### 6.1.2 多义性的三个来源

1. **中枢连接方式的多样性**：同一个中枢可以由不同的次级别走势类型组合而成
2. **中枢区间的选择**：不同级别的图上看到的中枢区间可能略有不同
3. **结合律的应用**：走势段的组合方式可以不同

#### 6.1.3 如何处理多义性

```
原则一：选择最有利于当前操作级别的分解方式
原则二：结合律必须严格遵守（不能随意跳级组合）
原则三：在同一分析中保持分解标准的一致性
原则四：不同分解方式的结论应该相互印证
```

### 6.2 结合律——走势分解的宪法（第36课）

#### 6.2.1 结合律的基本规则

```
规则一：走势段的组合只能按顺序进行（不能跳跃K线）
规则二：组合的最小单位由操作级别决定
规则三：组合的结果必须符合走势类型的定义

允许的组合：
  (a + b) + c = a + (b + c)  ← 三段可以不同组合方式

不允许的组合：
  a + c（跳过了b）             ← 违反顺序原则
  (a + c) + b（乱序组合）       ← 违反序列原则
```

#### 6.2.2 结合律的实际应用

```
同一段走势，不同组合方式的实战意义：

方式一（大级别分解）：(a+b) + (c+d) + (e+f)
  → 看作三段大级别走势类型 → 适合长线

方式二（中级别分解）：a + b + c + d + e + f
  → 看作六段中级别走势类型 → 适合波段

方式三（小级别分解）：a1+a2+...+an 逐段分解
  → 适合短线操作

三种都不违反结合律，选择取决于操作级别。
```

### 6.3 同级别分解（第38-40课）

#### 6.3.1 同级别分解的核心思想

> 将任何级别的任何走势，分解为同级别的上涨、下跌、盘整三种走势类型的连接。

**操作最简单化**：在该级别上涨完成时卖出，下跌完成时买入。

#### 6.3.2 同级别分解的操作模型

```
以5分钟级别为操作级别：

1. 将走势分解为连续的5分钟走势类型：
   上涨1 → 盘整1 → 上涨2 → 下跌1 → 盘整2 → 上涨3 → ...

2. 操作策略：
   - 在上涨完成点（5分钟一卖）卖出
   - 在下跌完成点（5分钟一买）买入
   - 盘整期间不参与或做差价

3. 换档机制（当出现大级别走势时）：
   5分钟走势类型连续不重叠 → 形成30分钟走势类型
   此时可选择换档到30分钟级别操作
```

#### 6.3.3 多重赋格操作模型（第40课，机构核心）

```
级别层        操作模型                 资金分配
────────────────────────────────────────────
年线级别      只决定多空大方向          不参与具体操作
月线级别      大趋势中的仓位方向        20% 战略底仓
周线级别      中级趋势的波段操作        30% 核心仓位
日线级别      日常操作的主要级别        30% 主要操作仓
30分钟级别    精确买卖点定位            15% 浮动仓位
5分钟级别     盘中T+0差价操作            5% 短线仓
```

> 每一层次的操作都独立又在一个整体的操作中。如果对古典音乐有点了解的就知道，如同赋格曲——简单的动机、旋律在N个层次上根据不同的转位、移位、对位等原则运动着，合成统一的乐曲。（第40课）

### 6.4 走势的多级别生长模型

```
走势生长的阶段模型（以牛市中的大级别上涨为例）：

阶段一：小级别底背驰 → 1分钟一买
阶段二：1分钟上涨 → 形成1分钟中枢
阶段三：1分钟中枢三买 → 1分钟趋势上涨
阶段四：1分钟趋势背驰 → 形成5分钟中枢
阶段五：5分钟中枢三买 → 5分钟趋势上涨（1分钟走势类型不重叠）
阶段六：5分钟趋势背驰 → 形成30分钟中枢
阶段七：...继续递归生长...

每一级都是"走势终完美"的体现：
  该级别走势完成后 → 要么转化为同级别盘整
                    → 要么转化为更高级别的走势的一部分
```

### 7.2 各级别的角色与关注点

#### 7.2.1 年线级别（超长线）

```
关注点：
  - 年线级别中枢的位置和规模
  - 年线级别的走势类型（盘整还是趋势）

操作意义：
  - 决定是否参与市场（年线趋势向上 → 始终有仓位）
  - 决定战略性板块选择
```

#### 7.2.2 季线/月线级别（长线）

```
关注点：
  - 月线中枢的构成和第三类买卖点
  - 5月均线的支撑是否有效

操作意义：
  - 决定总体仓位水平
  - 牛市第一轮调整不破5月线 → 行情延续
```

#### 7.2.3 周线级别（中长线）

```
关注点：
  - 周线中枢的ZG/ZD位置
  - 5周均线的方向

操作意义：
  - 决定核心仓位的持有/减仓
  - 周线三买/三卖是中长线操作的核心信号
```

#### 7.2.4 日线级别（中线/主要操作级别）

```
关注点：
  - 日线中枢的精确位置
  - 日线笔和线段的构成
  - 日线的背驰和盘整背驰

操作意义：
  - 机构日常操作的核心级别
  - 日线三买是最重要的中线上车点
  - 日线一卖是中线清仓信号
```

#### 7.2.5 30分钟级别（短线精确定位）

```
关注点：
  - 30分钟中枢的第三类买卖点
  - 30分钟走势类型的背驰
  - 30分钟与日线的共振

操作意义：
  - 精确日线级别买卖点的定位工具
  - 30分钟级别本身的交易（3-10天持仓）
```

#### 7.2.6 5分钟/1分钟级别（超短线/盘中）

```
关注点：
  - 区间套的最底层确认
  - 盘中T+0差价机会
  - 中枢震荡的精确买卖点

操作意义：
  - 主要用于：①大级别买卖点的精确定位
             ②中枢震荡中的差价操作
  - 不建议作为主要操作级别
```

### 7.3 多级别共振——最强信号

#### 7.3.1 共振的定义与类型

```
买点共振（最强买入信号）：
  月线底背驰 + 周线底背驰 + 日线底背驰 + 30分钟底背驰
  → 四级别共振买入，安全系数最高

  → 四级别共振卖出，必须清仓

#### 7.3.2 共振强度评级

| 共振级别数 | 信号强度 | 操作 |
|-----------|---------|------|
| 4级共振 | 极强 | 满仓/清仓 |
| 3级共振 | 强 | 重仓操作 |
| 2级共振 | 中等 | 正常操作 |
| 1级单独 | 弱 | 轻仓试探或不参与 |

## 八、操作策略与资金管理体系

### 8.1 五类投资者的操作策略（第79课）

#### 类别一：没时间看盘的投资者

```
策略：定投 + 指数基金 + 成长股基金
  - 60% 指数基金（不会跑输指数）
  - 40% 高成长股基金（获取超额收益）
  - 每月定投，不择时
  - 股票不是这类人应该碰的
```

#### 类别二：有时间的散户（< 1000万）

```
策略：第三类买点买卖法
  1. 选定一个操作级别（30分钟或日线）
  2. 只介入在该级别出现第三类买点的股票
  3. 买入后新次级别向上不创新高或盘整背驰 → 坚决卖掉
  4. 如果没有背驰 → 持有到中枢上移背驰
  5. 尽量只介入第一个中枢的第三类买点
  6. 禁止对任何股票有感情

资金管理：
  - 每次全仓一只 → 卖出后再换下一只
  - 止损不设 → 买点错了就是卖点
  - 年化目标：50%-200%（取决于市场环境）
```

#### 类别三：大散户（1000万-1亿）

```
策略：基本面长期价值股 + 中枢震荡操作
  1. 选择基本面上有长期价值的标的
  2. 建立底仓（不轻易动）
  3. 在中枢震荡中用浮动仓位做差价降低成本
  4. 分级别的中枢震荡对应不同规模的浮动仓

资金管理：
  - 底仓 50-60%（长持不动）
  - 波段仓 20-30%（日线级别买卖）
  - 差价仓 10-20%（30分钟级别高抛低吸）
```

#### 类别四：专门猎手（1亿-10亿）

```
策略：猎杀式攻击
  对选定目标进行精准的大规模攻击
  不吃小鱼只吃大鱼（资金效率要求）

特点：
  - 能在多个级别上同时操作
  - 能承受较大的持仓波动
  - 有足够的流动性管理能力
```

#### 类别五：超大规模资金（>10亿）

```
策略：全局战争
  不仅仅是市场操作，涉及：
  - 板块的统筹攻击
  - 对产业链上下游的布局
  - 与政策的博弈
  - 全球资本的联动

技术面的作用递减，综合能力的要求递增。
```

### 8.2 仓位管理的精确规则

#### 8.2.1 仓位与买卖点级别的对应

```
买卖点级别          仓位比例        止损/纠错条件
────────────────────────────────────────────
年线一买            80-100%         跌破年线中枢
月线一买            60-80%          跌破月线中枢DD
周线一买            40-60%          跌破周线中枢DD
日线一买            30-50%          跌破日线中枢ZD
30分钟一买          20-30%          跌破30分钟中枢
5分钟一买           10-20%          跌破5分钟中枢
```

#### 8.2.2 三段式建仓法

```
以日线级别一买为例：

第一阶段（从一买到二买）：
  在一买确认时建仓 30%
  理由：一买虽然最安全但可能反复

第二阶段（二买确认）：
  加仓至 60%
  理由：二买确认了趋势转折

第三阶段（三买确认）：
  加仓至 100%
  理由：三买确认了上涨趋势的延续

如果期间出现逆转信号 → 不再加仓 → 逐步减仓 → 退出
```

#### 8.2.3 动态仓位管理

```
根据走势强度的仓位调节：

强势走势（中枢上移、回拉浅）：
  → 维持高仓位，每一次回调都是加仓机会

中性走势（中枢震荡）：
  → 保持底仓，用浮动仓做差价

弱势走势（中枢下移、回拉深）：
  → 逐步减仓，反弹减仓，等待下一个买点
```

### 8.3 风险控制体系

#### 8.3.1 缠论的风险控制哲学

缠论不是不控制风险，而是**通过买点的精确定位，将风险控制在买点本身**。

> 买点买入，卖点卖出。不需要止损——因为买点本身就是判断对错的唯一标准。买点买错了？那这个位置就不是买点，直接卖就是。

#### 8.3.2 风险事件的级别分类

```
黑天鹅级别（破坏年级别中枢）：
  → 系统性风险，无条件清仓
  → 参考2008年级别

重大利空（破坏月/周级别走势）：
  → 清掉同方向的仓位，等待新买点
  → 不抄底、不接飞刀

一般利空（日线级别波动）：
  → 正常应对，按买卖点操作
  → 甚至可能是加仓机会（利用恐慌）

盘中波动（操作级别以下的波动）：
  → 忽略
  → 操作级别越大，容忍的波动越大
```

#### 8.3.3 不可参与的情形（红线）

```
1. 没有本级别买点的任何股票（绝对红线）
2. 大级别下跌趋势中的小级别买点（刀口舔血）
3. 中枢震荡没有方向且没有买卖信号时（等待）
4. 对股票有感情或听消息买卖（致命错误）
5. 没有明确的级别概念时进行交易（赌博）
6. 追涨杀跌（即使三买也是在回调中形成的）
```

系统三：基本面（权重：15%）

## 十、走势类型实战形态库

### 10.1 标准底部形态

#### 形态一：标准一买底部

```
走势特征：
  下跌趋势：a + A + b + B + c
  c段背驰于b段 → 一买出现
  随后回到B中枢的区间

确认信号：
  1. c段走势力度 < b段走势力度
  2. 一买后放量上涨
```

#### 形态二：二买确认底部（双底/W底）

```
走势特征：
  一买后上涨 → 次级别回调不创新低 → 二买
  两个底点构成W底

确认信号：
  1. 二买处出现次级别底背驰
  2. 二买高于一买（最佳）
  3. 二买处成交量萎缩（空头衰竭）
```

#### 形态三：盘整背驰底部

```
走势特征：
  下跌 + 盘整（中枢）+ 下跌（破中枢但不背驰）
  或：下跌 + 盘整（中枢）+ 盘整背驰

确认信号：
  盘整中枢前后的下跌力度对比
  适用于无趋势的市场底部
```

### 10.2 标准顶部形态

#### 形态一：标准一卖顶部

```
走势特征：
  上涨趋势：a + A + b + B + c
  c段背驰于b段 → 一卖
  随后回到B中枢

确认信号：
  1. c段走势力度 < b段走势力度
  2. 一卖后放量下跌
```

#### 形态二：二卖确认顶部（双顶/M头）

```
走势特征：
  一卖后下跌 → 次级别反弹不创新高 → 二卖
  两个顶点构成M头

确认信号：
  1. 二卖处出现次级别顶背驰
  2. 二卖低于一卖（最佳）
  3. 二卖处成交量萎缩（多头衰竭）
```

### 10.3 中继形态

#### 中枢延伸（箱体震荡）

```
识别特征：
  □ 走势在固定的区间内来回
  □ ZG和ZD被反复触及但不有效突破

操作策略：
  □ 在ZD附近 + 次级别底背驰 → 买入
  □ 在ZG附近 + 次级别顶背驰 → 卖出
  □ 等待第三类买卖点确认方向
```

#### 三角形收敛

```
识别特征：
  □ 中枢的每一次波动幅度都在缩小
  □ 走势呈三角形收敛形态
  □ 成交量逐步萎缩

操作策略：
  □ 等待三角形末端的突破方向
  □ 不提前押注方向
  □ 突破后如果有三买/三卖 → 按趋势操作
```

### 10.4 强势/弱势形态识别

#### 强势上涨的特征

```
□ 每次次级别回拉都不跌破前中枢的ZG → 三买不断涌现
□ 中枢上移迅速，中枢区间短
□ 回拉幅度小、时间短
□ 5日线始终不破
→ 操作：持有为主，只做大级别卖点
```

#### 弱势上涨的特征

```
□ 次级别回拉经常跌回中枢 → 没有三买或三买虚假
□ 中枢区间在扩大
□ 回拉深、时间长
□ 5日线频繁被跌破
→ 操作：高抛低吸，警惕转势
```

### 11.2 K线包含处理

```python
def containment(kl):
    kls = [{'idx':i,'t':str(r['时间']),'o':float(r['open']),
            'h':float(r['high']),'l':float(r['low']),'c':float(r['close'])}
           for i,r in kl.iterrows()]
    if len(kls)<2: return kls
    res=[kls[0]]; d=None
    for i in range(1,len(kls)):
        c,p=kls[i],res[-1]
        pc=p['h']>=c['h'] and p['l']<=c['l']
        cc=c['h']>=p['h'] and c['l']<=p['l']
        if not pc and not cc:
            if len(res)>=2:
                d=1 if res[-1]['l']>res[-2]['l'] else (-1 if res[-1]['l']<res[-2]['l'] else d)
            res.append(c)
        else:
            if d is None: d=1 if c['l']>=p['l'] else -1
            m={'idx':p['idx'],'t':p['t'],'o':p['o']}
            if d==1: m['h']=max(p['h'],c['h']); m['l']=max(p['l'],c['l'])
            else: m['h']=min(p['h'],c['h']); m['l']=min(p['l'],c['l'])
            m['c']=m['l'] if d==-1 else m['h']
            res[-1]=m
    return res
```

## 使用指引

当用户使用本 Skill 提出分析请求时，遵循以下响应规范：

### 响应格式要求

1. **每次分析必须先声明分析级别**
   - 例如："以下分析基于日线级别（操作级别：日线，定位级别：30分钟）"

2. **分析顺序：从上到下，从大到小**
   - 月线/周线定方向 → 日线找结构 → 30分钟/5分钟定买卖点

3. **明确标注结论类型**
   - 形态学结论（分型/笔/线段/中枢/走势类型的几何判断）
   - 动力学结论（背驰/力度比较）
   - 策略结论（买卖点/仓位/操作建议）

4. **不预测，看图作业**
   - 只分析已经形成的结构和正在进行中的走势
   - 用"如果...则..."条件句式代替"会...到..."

5. **始终标注来源**
   - 涉及具体规则时标注课号（如"参见第62课"）

### 常见用户请求的处理模板

```
请求："用缠论分析 XX 股票"
→ 执行 9.1 盘前准备流程 + 输出完整的级别联立分析

请求："XX 股票现在能买吗？"
→ 先问操作级别 → 按对应级别找买卖点 → 给条件判断

请求："XX 股票该卖了吗？"
→ 检查当前级别是否出现卖点信号 → 按区间套确认

请求："帮我复盘今天的操作"
→ 按 9.3 复盘模板 → 重点对比买卖点判断与实际操作

请求："帮我筛选三买标的"
→ 用 cjpy 拉数据 → 日线级别搜中枢突破 → 等次级别回拉确认
```
