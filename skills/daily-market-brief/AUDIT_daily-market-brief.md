## 三、SKILL 文档与实际的偏离（7 项实锤）

| # | 严重度 | 问题 | 证据 |

| 5 | **P1** | `日收益率` 因子返回**小数**（0.0442），文档 JSON 示例是**百分数**（0.25），未标注换算 | 漏乘 100 → 报告全线失真 100 倍 |
| 6 | **P1** | `成交额` 因子返回**元**（1.166e12），JSON 示例是**亿**，未标注 | 漏除 1e8 |

**CJPY 接口自身的两个坑（文档未提示）**
- `上市板` 因子遇到北交所代码（BJ 开头）直接 **HTTP 500**，同批次其他股票一起失败。须用代码前缀推断板块。
- 单次请求超过约 **500 个交易日 × 因子** 会触发 **30 秒 ReadTimeout**。5 年分位必须按 120 天分块 + 重试。

## 四、脚本健壮性压测（27 场景 / 7 崩溃 / 崩溃率 26%）

| 场景 | 结果 | 异常 |
|------|------|------|
| 北向净流入写成字符串 `"-243.3亿"` | **CRASH** | `TypeError: '>' not supported between str and int` |
| 行业 TOP 缺 `amount` 键 | **CRASH** | `KeyError: 'amount'` |
| 换手率写成 `"1.22%"` | **CRASH** | `ValueError: Unknown format code 'f'` |
| 日收益率写成 `"+0.57%"` | **CRASH** | `TypeError: unsupported operand int + str` |
| sectors `change` 写成字符串 | **CRASH** | `TypeError` |

| `pe_timeline` 缺 `pb` 键 | **CRASH** | `KeyError: 'pb'` |

| 日收益率忘记 ×100 | **PASS（最危险）** | 报告正常生成、数据全错 |
| 成交额忘记 ÷1e8 | **PASS（最危险）** | 同上 |

**其他脚本缺陷**
- `format_num(v, unit="", digits=2)` 的 `digits` 参数失效 → 量比 1.0 渲染成 `"1.0"`、1.234567 渲染成 `"1.234567"`。
- 指数卡片只渲染 6 个，中证 500 / 中证 1000 取了数但**从不显示**（SKILL.md 承诺 8 个）。
- `render_index_card()` 接收 `pe`/`pb` 参数但函数体内**完全没用**。
- 机构专属小结用了 `.section` / `.section-title` 两个 CSS 类，**样式表里没有定义** → 白卡片背景、内边距全丢。
- 「估值水位近 5 年分位数」在 SKILL.md 和 data_reference 都承诺了，**脚本里根本没有渲染逻辑**。
- 资金面点评用**绝对 PE 阈值**判断（<12 低 / >18 高）→ 实测沪深300 PE 14.33（历史 92.7% 分位，明显偏高）被判为「历史中位附近」，结论相反。
- 新闻 `title` 与 `url` **未做 HTML 转义**：`<img src=x onerror=alert(1)>` 和 `javascript:` URL 原样进入页面。
- SKILL.md 第 15 行编码损坏：`## 一、输入��据全景`。

## 五、稳定性评估：不同人 / 不同 agent / 不同模型的偏差范围

| 层级 | 数据 | 偏差范围 | 可控性 |
|------|------|---------|-------|
| **L1 确定性** | 指数收盘价/涨跌幅/估值、申万行业涨跌、涨跌家数、龙虎榜 | **0%**（同一交易日结果完全一致） | 完全可控 |
| **L2 口径分歧** | 两市成交额、量比、涨停家数、炸板率 | **±5% ~ ±22%** | 可控——写死算法即可 |
| **L3 单位陷阱** | 日收益率、成交额 | **0% 或 100 倍 / 1e8 倍**（二值化灾难） | 可控——文档标注 + 断言 |
| **L4 时点歧义** | 外围市场「前一日收盘」 | 实测同一次检索里道指同时出现 **+0.49%（8/5）与 +1.71%（8/4）**；恒生 **+0.24%（8/5）vs -1.49%（8/6）** | 部分可控 |
| **L5 主观生成** | 8 条新闻选取、利好/利空/层级/持续性三标签、机构小结 4 段 | **重合度约 30~60%**，措辞 100% 不同 | 不可控 |

**综合判断：当前流程不是高度稳定的。**
- 量化骨架（L1）稳定，但它只占报告约 40% 的信息量。
- L2/L3 是当前最大风险：**同一天、同样数据、两个 agent 可以合法地产出成交额 1.97 万亿和 2.53 万亿两个版本**，且都不报错。
- L5 本质是 LLM 生成，只能约束格式不能约束内容。
- 崩溃维度：26% 的输入变体会让脚本抛异常。换一个模型（对 JSON schema 遵守度差一些）失败率会显著上升。

## 六、优化建议（按投入产出排序）

### P0 — 必须改，否则数据是错的
1. **修正两市成交额算法**：`data_reference.md` 改为「全 A `成交额` 因子加总（排除 BJ）」，并注明指数成交额 ≠ 市场成交额。
2. **两融改用 `融资融券明细`**，并说明 T+1 滞后（取 `end=今日` 时实际返回昨日）。
3. **去掉硬编码 `C:\Python314\python.exe`**：改为在 SKILL.md 里写一段解释器探测逻辑——依次尝试 `python`、`py -3`、常见安装路径，用 `python -c "import cjpy"` 验证后再用；脚本本身只依赖标准库，任意 Python 3.8+ 都能跑。
4. **在 data_reference.md 顶部加「单位与量纲约定」硬性条款**：日收益率 ×100、成交额 ÷1e8、换手率已是百分数、金额统一亿元。

### P1 — 大幅提升稳定性
5. **把取数固化成脚本**，而不是让 agent 自由发挥。新增 `scripts/fetch_data.py`，把第一节 14 类调用全部写死，输出标准 `data.json`。**这是把 L2/L3 偏差从 ±22% 压到 0 的唯一办法**——agent 只负责跑脚本 + 填 WebSearch 部分。
6. **给 `generate_report.py` 加防御层**：统一 `safe_float(v)` 解析（能吃 `"1.22%"`、`"24792亿"`、`None`），所有 `dict[key]` 换成 `.get(key)`，`None` 一律渲染为 `—`。仅此一项就能把 26% 崩溃率降到 0。
7. **加 `validate_data.py` 前置校验**：量纲合理性断言（指数涨跌幅绝对值 <20、两市成交额 3000~50000 亿、PE 5~60），越界直接报错而不是生成错误报告。这能拦住「忘记 ×100」这类静默错误。
8. **把行业/涨跌停/炸板率从 WebSearch 改回 CJPY**，减少 4 次外部检索，同时消除这部分的模型间差异。

### P2 — 质量与体验
9. 补 `.section` / `.section-title` 的 CSS 定义；补渲染中证 500 / 中证 1000（凑够 8 卡）。
10. 估值点评改用**分位数**而非绝对 PE 阈值（数据已经算出来了，只是没传进去）；同时把 5 年分位真正渲染到「估值水位」模块。
11. 新闻 `title` 走 `html.escape()`，`url` 白名单只放行 `http(s)://`。
12. 修 `format_num` 的 `digits` 失效；修 SKILL.md 第 15 行乱码。
13. Chart.js 加 `onerror` 本地降级或直接内联 SVG，避免断网/内网空白图。
14. WebSearch 部分在 SKILL.md 里**写死日期锚点规则**（外围市场一律取「A股上一交易日的海外收盘」并在页面标注日期），消除 L4 时点歧义。
15. 新闻条目在 HTML 上标注来源与检索时间，让不可控的 L5 部分至少可追溯。

### 兼容性（不同 Windows 设备）
16. 所有脚本统一 `# -*- coding: utf-8 -*-` + `sys.stdout` 强制 UTF-8 包装（GBK 控制台下 print 中文会 `UnicodeEncodeError`）。
17. 路径全部走 `pathlib.Path` + `__file__` 相对定位，不假设当前工作目录。
18. CJPY 请求统一加**分块 + 3 次重试 + 指数退避**（实测 1211 天单次请求必超时），并把批大小设为可配置（建议代码 ≤1200 / 日期 ≤120）。
19. 显式跳过 `上市板` 因子对北交所的调用，或改用代码前缀推断板块。
