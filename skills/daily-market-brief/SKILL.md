# 每日市场快报（机构版）

> 行情 + 资金 + 情绪 + 新闻 → 三栏结构化日报 + 机构专属小结

---

## 一、输入��据全景

### 1.1 行情数据（cjpy）

| 数据层 | 内容 | cjpy 来源 | 频率 |
|--------|------|----------|------|
| **宽基指数** | 上证/深证/创业板/沪深300/上证50/科创50/中证500/中证1000 收盘价、涨跌幅、成交额、换手率 | `get_factor_data` | 当日+近5日对比 |
| **行业指数** | 申万一级行业涨跌幅、中信三级行业涨跌幅（涨幅TOP5/跌幅TOP5） | WebSearch + 行业因子 | 当日 |
| **概念板块** | 当日领涨/领跌概念板块 | WebSearch | 当日 |
| **涨跌停与异动** | 涨停/跌停家数、炸板率、涨幅>7%异动个股、跌幅>7%个股 | WebSearch | 当日 |
| **外围行情** | 美股三大指数、恒生/恒生科技、日经225、商品（黄金/原油）涨跌 | WebSearch | 前一日收盘 |
| **量价波动** | 两市成交额、量比（vs 5日均）、日内振幅 | `get_factor_data` 计算 | 当日 |

### 1.2 新闻事件流（WebSearch）

| 新闻层 | 搜索方向 | 提取目标 |
|--------|---------|---------|
| **宏观政策** | 国务院/央行/证监会/发改委/财政部/工信部 | 政策标题 + 核心内容 + 影响层级(一级全局/二级行业/三级个股) |
| **产业政策** | 行业监管/补贴/关税/规划 | 受益/受损行业 + 持续性判断(长期/阶段/一次性) |
| **上市公司公告** | 重大合同/重组/增减持/业绩大幅变动 | 个股影响 + 行业映射 |
| **海外宏观** | 美联储/欧央行/地缘政治/关税/大宗商品 | 对A股的传导路径 |

### 1.3 资金与情绪数据（cjpy + WebSearch）

| 数据层 | 内容 | cjpy/WebSearch |
|--------|------|---------------|
| **北向资金** | 当日净流入/流出额、沪股通/深股通分拆 | WebSearch |
| **两融数据** | 融资余额、融券余额、融资买入占比 | cjpy `融资融券汇总` |
| **龙虎榜** | 机构席位净买入/卖出TOP5、游资活跃度 | cjpy `交易公开信息` |
| **涨跌家数** | 上涨/下跌/平盘家数、涨跌比 | WebSearch |
| **炸板率** | 涨停炸板率 = 炸板数/触及涨停数 | WebSearch |
| **估值分位** | 沪深300 PE/PB 近5年分位数 | cjpy 因子+手动计算 |
| **连板情绪** | 最高连板数、连板晋级率 | WebSearch |

## 二、输出日报详解

### 2.1 左栏：市场情绪

| 模块 | 内容 | 呈现 |
|------|------|------|
| **宽基指数卡片** | 8大指数 2×4网格：代码/收盘价/涨跌幅/成交额 | 涨红跌绿 |
| **情绪温度计** | 0-100° 综合指标（涨跌比×0.3 + 量比×0.3 + 指数均值×0.4） | 红/灰/绿分段进度条 |
| **赚钱效应** | 涨跌家数比、涨幅中位数、涨停家数、炸板率 | 4格统计卡片 |
| **行情定性** | 自动判定：普涨(涨>70%) / 普跌(跌>70%) / 结构性分化(30-70%) | emoji标签 |

### 2.2 中栏：资金面

| 模块 | 内容 | 呈现 |
|------|------|------|
| **银行间流动性** | Shibor/DR007（如有）、央行公开市场操作 | 文本行 |
| **北向资金** | 当日净流入/流出、连续净流入天数 | 红绿色数字+箭头 |
| **行业资金TOP** | 申万一级行业资金净流入TOP5 / 净流出TOP5 | 双列表格 |
| **两融与龙虎榜** | 融资余额变化、机构席位净买卖TOP3 | 文本+表格 |
| **估值水位** | 沪深300 PETTM + PBMRQ + 近5年分位数 | 双行数值+档位标签 |
| **量能趋势** | 两市成交额 + 量比 + 近半年成交额柱状图 | 数字+Chart.js bar |

### 2.3 右栏：事件面

| 模块 | 内容 | 呈现 |
|------|------|------|
| **宏观政策** | 部委级政策发布，标注影响层级 | 底色标签+可点击标题 |
| **产业动态** | 行业政策/供需/价格变化，标注受益受损板块 | 同上 |
| **上市公司** | 重大公告摘要（业绩超预期/减持/重组） | 同上 |
| **海外事件** | 美股/港股/商品/地缘，标注对A股传导 | 同上 |
| **事件分类** | 每条标注：利好/利空/中性 + 影响层级(全局/行业/个股) + 持续性(长期/阶段/一次性) | 三标签体系 |

### 2.4 机构专属小结（三栏下方）

| 模块 | 内容 |
|------|------|
| **当日行情核心逻辑** | 150字总结：驱动因素 × 市场反应 × 主线判断 |
| **次日走势判断** | 偏多/偏空/震荡 + 核心变量（如：关注XX数据/XX事件） |
| **配置参考** | 建议超配/低配行业 + 一句话理由 |
| **关键风险提示** | 2-3条需警惕的尾部风险或潜在催化剂 |
