# 事件驱动型个股复盘（Event-Driven Stock Review）

> 股票代码 + 时间段 + 触发事件 → 涨跌归因拆解 + 量能异动 + 新闻匹配

---

## 一、总览

本 skill 对单只股票在指定事件窗口内的表现做完整复盘，回答三个核心问题：

1. **涨跌是谁贡献的？** → 大盘 Beta / 行业联动 / 个股 Alpha 三元拆解
2. **资金怎么走的？** → 成交量异动检测 + 龙虎榜/主力流向
3. **为什么发生？** → cjpy 公告 + WebSearch 新闻事件匹配

---

## 二、三元归因模型

```
个股涨跌幅 = 大盘贡献(Beta) + 行业贡献(Sector) + 个股Alpha

┌─────────────────────────────────────────────────────────────┐
│  个股涨跌幅 = α + β×大盘涨跌幅 + γ×行业涨跌幅                │
│                                                             │
│  大盘贡献 = 沪深300 涨跌幅 × 个股Beta（近60日滚动）            │
│  行业贡献 = 申万一级行业指数涨跌幅（个股所属行业）               │
│  个股Alpha = 实际涨跌幅 - 大盘贡献 - 行业贡献                  │
│                                                             │
│  Alpha > 0：个股跑赢大盘+行业，有独立正面驱动                  │
│  Alpha < 0：个股跑输大盘+行业，存在独立负面因素                 │
└─────────────────────────────────────────────────────────────┘
```

### 2.1 Beta 计算

```python
# 用事件窗口前60个交易日数据，计算个股相对沪深300的Beta
Beta = Cov(个股日收益率, 沪深300日收益率) / Var(沪深300日收益率)
```

### 2.2 行业联动

- 通过 cjpy `一级行业` 因子确定个股所属申万行业
- 行业涨跌幅 = 同行业成分股在窗口内的市值加权平均涨跌幅
- 如果个股是该行业唯一或主要成分股，则行业联动 = 申万行业指数涨跌幅

## 三、数据提取工作流

### Step 1: 确定复盘窗口

```
输入参数：
  --code SZ300750           # 股票代码
  --event "Q2财报发布"       # 触发事件描述
  --window 前3后5            # 事件窗口：事件日前3天 + 事件日 + 后5天 = 共9天
  --event_date 20260723     # 事件日
```

窗口定义：
- **事件前窗口**（pre-N）：用于对比基准
- **事件日**（T0）：触发事件当天
- **事件后窗口**（post-N）：观察市场反应
- **对照窗口**（pre-20）：事件前20个交易日，用于计算正常量能区间

### Step 2: 提取行情数据（cjpy）

```python
# 个股K线（覆盖窗口+基准期）
get_market_data(code="SZ300750", start="基准开始日", end="窗口结束日", cycle="day", rate="前复权")

# 大盘指数
get_market_data(code="SH000300", start="基准开始日", end="窗口结束日", cycle="day")
```

提取字段：开盘价、最高价、最低价、收盘价、成交量、成交额

### Step 3: 确定行业 + 行业指数

```python
# 获取个股所属申万一级行业
get_factor_data(code=["SZ300750"], date=["事件日"], factors=["一级行业"])

# 获取该行业代表性成分股 + 行业指数行情
get_factor_data(code=["行业龙头们"], date=["窗口日期列表"], factors=["收盘价","日收益率"])
```

### Step 4: 提取事件数据（cjpy）

| cjpy 表 | 用途 |
|---------|------|
| 股票公告 | 窗口期内所有公告，匹配触发事件 |
| 交易公开信息 | 龙虎榜数据（涨跌幅异动/换手率异动） |
| 股东增减持 | 窗口期内增减持变动 |
| 业绩预告/快报 | 如果触发事件是业绩相关 |
| 融资融券明细 | 融资余额变化 |

### Step 5: 搜索新闻（WebSearch）

```
"股票名称 事件关键词 日期"
```

### Step 6: 计算归因 + 生成报告

调用 `scripts/stock_review.py`：

```bash
C:\Python314\python.exe scripts/stock_review.py \
  --code SZ300750 \
  --event "2026年中报发布" \
  --event_date 20260723 \
  --pre 3 --post 5 \
  --output outputs/review_SZ300750_20260723.html
```

## 六、注意事项

1. **Beta 时效**：Beta 使用事件前60个交易日滚动计算，不跨年
2. **行业联动**：若个股在行业中权重过大（如宁德在电力设备），行业贡献可能包含自身效应
3. **事件重叠**：如果窗口内有多个事件，优先按重要性排序展示
4. **停牌处理**：窗口内若有停牌日期，标注并跳过计算
5. **数据精度**：涨跌幅以百分比表示，保留2位小数
