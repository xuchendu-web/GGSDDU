# 基金筛选与互补匹配器（Fund Matcher）

> 目标特征 / 组合缺口 → 候选基金列表 → 维度打分 → 互补性评估

---

## 一、总览

当你想替换一只基金，或补充组合短板时，本 skill 帮你从全市场找到最匹配的候选，并量化评估它们的互补性。

**输入：**
- **方式A**：描述目标特征（如「半导体主题、规模<20亿、近1年收益>50%」）
- **方式B**：描述组合缺口（如「我现有组合全是半导体，需要一只消费或医药基金做对冲」）
- **方式C**：给一只要替换的参考基金（如「有没有比013840更好的半导体基金」）

**输出：**
- 候选基金列表（Top 5-10），每只综合评分，**同经理仅保留最优一只**
- **两阶段筛选结果**：仅保留收益率曲线与参考基金 Pearson r ≥ 0.70 的候选进入持仓对比
- 六维度打分：风格 / 行业 / 业绩 / 规模 / 持仓重叠 / 相似度（权重根据筛选方向自适应，见下表）
- **全基金 × 全个股重仓矩阵图**（重叠单元格标红，权重深浅色阶）
- **前十大重仓个股与权重表**（与现有组合重叠个股标红）
- **实际收益率相关性矩阵图**（基于 cjpy 净值序列计算的真实 Pearson r）
- 最终推荐排序 + 一句话理由

## 二、六维度匹配模型（按筛选方向自适应）

评分方向由用户意图决定，权重自动切换：

| 维度 | 相似替代 权重 | 互补分散 权重 | 指标 | cjpy 数据源 |
|------|:---:|:---:|------|-----------|
| **风格匹配** | 20% | 20% | 成长/价值/均衡判定，PE/ROE | `基金持股明细` → 个股 → `PETTM`/`净资产收益率` |
| **行业匹配** | 25% | 20% | 行业暴露度 vs 需求（使用统一行业分类映射） | `基金持股明细` → 个股 → `板块名称` |
| **业绩优越度** | 20% | 10% | 近1年/3年收益 vs 参考基准 | `基金净值收益率`（年/季） |
| **规模匹配** | 10% | 10% | 规模（10-50亿最优） | `基金持股明细` 聚合 |
| **持仓重叠度** | **15% ↑** | **10% ↓** | 相似模式: 重叠多=高分; 互补模式: 重叠少=高分 | 同 portfolio-overlap 算法 |
| **收益曲线相似度** | **10% ↑** | **30% ↓** | 相似模式: Pearson r 高=高分; 互补模式: Pearson r 低=高分 | `基金净值收益率` → 实际周度序列 |

> **关键原则**：收益曲线相似度是前置硬筛选条件，不是软打分项。进入六维打分前已淘汰 r < 0.70 的候选。

### 基金经理去重规则

在初筛完成后、深度画像前执行。去重逻辑：

```
1. cjpy 查询每只候选基金的「在任基金经理」字段
2. 按基金经理分组：
   - 同一位经理管理多只候选基金 → 仅保留近1年收益率最高的一只
   - 被筛掉的基金不进入后续打分流程
3. 去重结果记录在报告底部「基金经理去重备注」中：
   - 列出被筛掉的基金名称和代码
   - 说明筛除原因（与 xx基金 同经理，业绩次优）
```

**为什么这样做？** 同一基金经理管理的多只产品往往持仓高度雷同，把它们都放进候选列表会给用户造成"有多个选择"的假象，实际风险分散效果极差。

**特别处理：经理变更** 如参考基金的基金经理近期发生变更（如 011128 王斌 -> 高钥群），还需额外排除：
- 前任经理管理的其他同类产品（它们仍反映前任策略，但不再是持有人当前选择）
- 新任经理管理的其他产品（新人接手时间短，风格有待观察）

### 前十大重仓个股与权重表格

每只候选基金独立渲染一张前十大持仓表。规则：

- **头两列**：股票代码 + 股票名称
- **权重列**：以颜色渐变的柱状条显示（深色=高权重），右侧标注百分比
- **标红逻辑**：遍历现有组合中所有基金的持仓股票集合，若某只重仓股出现在现有组合中 → 整行底色 `#FFE0E0`（浅红），文字加粗，并在备注列标注「重叠」
- **底部汇总行**：
  - 重叠仓位合计占比（所有标红个股的权重之和）
  - 重叠个股数量 / 重仓个股总数

### 收益率相关性矩阵（基于实际净值数据）

**数据来源**：cjpy `基金净值收益率` 表，拉取每只基金近 2 年的周度净值收益率序列。

**关键要求**：矩阵数据必须来自**实际 cjpy 查询结果**，不是估算值。如果 cjpy 数据不可得，报告中明确标注「数据不足，未计算」。

**计算流程**：
1. 对参考基金和通过阶段一的所有候选基金，各拉一条周度净值收益率时间序列
2. 对齐到共同交易日历（取交集），每列一只基金，每行一个周度收益
3. 使用 `numpy.corrcoef()` 计算两两 Pearson r

**可视化规范**：同之前（红-白-蓝色阶，每个格标注两位小数，层次聚类排序）。

**在阶段一的作用**：这个矩阵呈现的是**通过筛选后**基金的收益率相关性全貌。参考基金与每只候选的相关系数已在阶段一计算（用于 r >= 0.70 的通过/淘汰判断），此处完整展开所有通过基金间的两两关系。

```
┌──────────────────────────────────────────────┐
│  收益率相关性矩阵 (近2年周度)                    │
│          ┌──────┬──────┬──────┬──────┐        │
│          │ 基金A │ 基金B │ 基金C │ 现有  │        │
│   ┌──────┼──────┼──────┼──────┼──────┤        │
│   │ 基金A │ 1.00 │ 0.85 │ 0.32 │ 0.78 │        │
│   │ 基金B │ 0.85 │ 1.00 │ 0.41 │ 0.82 │        │
│   │ 基金C │ 0.32 │ 0.41 │ 1.00 │ 0.15 │        │
│   │ 现有  │ 0.78 │ 0.82 │ 0.15 │ 1.00 │        │
│   └──────┴──────┴──────┴──────┴──────┘        │
│   🟥 高相关(>0.7)  ⬜ 低相关(<0.3)  🟦 负相关   │
└──────────────────────────────────────────────┘
```

当相关性矩阵中某只候选与现有组合的相关性 >0.85，在推荐详情中加一条风险提示

### 两阶段筛选流程（核心升级）

本 skill 采用**先粗筛、再细比**的两阶段策略：

```
阶段一: 收益曲线相似度硬筛选
┌──────────────────────────────────────────────┐
│  输入: 候选池 (10-20只, 经经理去重)            │
│  操作: cjpy 拉取参考+候选的周度净值收益率序列   │
│  计算: 每只候选 vs 参考基金的 Pearson r        │
│  阈值: 相似替代 -> r >= 0.70 保留               │
│        互补分散 -> r <= 0.30 保留               │
│  输出: 通过筛选的精简池 (通常 3-5只)            │
└──────────────────┬───────────────────────────┘
                   │ 仅通过筛选的基金进入 ↓
阶段��: 重仓个股深度对比
┌──────────────────────────────────────────────┐
│  输入: 通过阶段一的基金列表                    │
│  操作: 拉取每只基金的持股明细 -> 前十大重仓      │
│  对比: 构建全基金x全个股矩阵图                  │
│        计算重叠率、行业分布、集中度             │
│  打分: 六维度 0-5 分，权重根据方向自适应       │
│  输出: 排序推荐 + 重仓矩阵图 + 相关系数表       │
└──────────────────────────────────────────────┘
```

**为什么先筛收益率曲线？** 净值走势高度一致（r >= 0.70）说明基金在相似时点做相似决策，才是真正「替代品」。持仓数据有季报滞后，净值每日更新更反映实际运作。

**行业分类统一映射**：cjpy 板块名称粒度不统一，评分时使用以下规则：

| 原始关键词 | 统一归类 | 原始关键词 | 统一归类 |
|:---|:---|:---|:---|
| 制造/材料/设备/军工/半导体/汽车/机械 | **制造** | 医药/医疗/生物/药 | **医药** |
| 电子/芯片 | **电子** | 电力/新能源/光伏/锂电 | **电力设备** |
| 交通/运输/物流/航运/铁路/航空 | **交通运输** | 化工/化学/石化 | **化工** |
| 通信/5G/光通信 | **通信** | 公用/燃气/水务 | **公用事业** |
| 采矿/矿产/石油/煤炭/黄金/有色/稀土 | 归入**制造** | 信息技术/软件/计算机 | 归入**电子** |
| 食品/饮料/消费/家电/零售/白酒/金融/银行 | 不匹配011128主线 | | |

## 五、使用示例

### 示例 1：找赛道基金（相似替代）

> 用户：「推荐几只纯半导体主题基金，规模不要太大」

执行：搜索半导体ETF/主题基金 -> 行业纯度筛选 -> 规模过滤 -> 基金经理去重 -> **Step 2.6: 收益曲线硬筛选(r>=0.70)** -> 阶段二持仓对比 -> 重仓矩阵图 -> 打分推荐

### 示例 2：组合补缺（互补分散）

> 用户：「我持仓全是半导体，需要一只消费基金对冲」

执行：搜索消费基金 -> 经理去重 -> **Step 2.6: 收益曲线筛选(r<=0.30，低相关的才保留)** -> 计算重叠率 -> 低重叠+低相关排前面

## 八、实战注意事项

### cjpy 数据拉取

`get_table_data` 的 `limit` 参数返回的是**时间正序的前 N 行**（最早的数据），不是最近 N 行。要获取近期数据：

```
方案: 设置一个足够大的 limit (如 2000) 拉取全量数据
      在 Python 端用 json.load() 解析
      按「截止日」字段排序
      取尾部 ~500 行即为近 2 年数据
```

- OF011128: ~1258 行（2021-03 起）
- OF519133: ~2467 行（2016-05 起）
- 起步晚的基金行数更少（如 OF010965 仅 ~1147 行）

如果数据量过大导致 MCP 输出超出 token 限制，数据会自动存到本地文件。用 `json.load()` 读取文件即可。

### Pearson r 计算

对齐所有基金的共同交易日，取近 500 个交易日（约 2 年），用 `numpy.corrcoef()` 计算：

```python
import numpy as np
ref_returns = np.array([returns_ref.get(d, 0) for d in common_dates[-500:]])
cand_returns = np.array([returns_cand.get(d, 0) for d in common_dates[-500:]])
r = np.corrcoef(ref_returns, cand_returns)[0, 1]
```

A股偏股型基金之间的 r 通常在 0.6-0.95 区间。替代基金筛选阈值 r ≥ 0.70，优质替代应达到 0.80 以上。

#### 完整 Python 生成流程

```python
import numpy as np

W, H = 900, 450
LM, RM, TM, BM = 80, 30, 30, 50  # 边距
PW, PH = W - LM - RM, H - TM - BM

# 1. 下采样到 ~100 点
step = max(1, len(dates) // 100)
pts = list(range(0, len(dates), step))
if pts[-1] != len(dates) - 1:
    pts.append(len(dates) - 1)

# 2. 坐标映射
def xp(i): return LM + (i / (len(pts) - 1)) * PW
def yp(v): return TM + (1 - (v - ymin) / yrange) * PH

# 3. Y 轴刻度 + 水平网格线
for v in np.linspace(ymin, ymax, 6):
    y = yp(v)
    svg += f'<line x1="{LM-5}" y1="{y}" x2="{LM}" y2="{y}" stroke="#94a3b8"/>'
    svg += f'<text x="{LM-8}" y="{y+4}" fill="#64748b" font-size="11" text-anchor="end">{v:.0f}%</text>'
    svg += f'<line x1="{LM}" y1="{y}" x2="{W-RM}" y2="{y}" stroke="#f1f5f9"/>'

# 4. X 轴刻度（~12 个标签）
for i in range(0, len(pts), len(pts) // 12):
    svg += f'<text x="{xp(i)}" y="{H-BM+18}" fill="#64748b" font-size="10" text-anchor="middle">{label}</text>'

# 5. 零线
if ymin < 0: svg += f'<line x1="{LM}" y1="{yp(0)}" x2="{W-RM}" y2="{yp(0)}" stroke="#94a3b8" stroke-dasharray="4,4"/>'

# 6. 五条曲线
colors = {"011128":"#1e40af","519133":"#dc2626","004475":"#16a34a","004138":"#f59e0b","010965":"#8b5cf6"}
for code, color in colors.items():
    path = " ".join([f"{'M' if j==0 else 'L'}{xp(j):.1f},{yp(cum[code][pts[j]]):.1f}" for j in range(len(pts))])
    lw = 3 if code == "011128" else 2
    svg += f'<path d="{path}" fill="none" stroke="{color}" stroke-width="{lw}" stroke-linejoin="round"/>'
    # 末端标签
    svg += f'<text x="{xp(len(pts)-1)+6}" y="{yp(cum[code][pts[-1]])+4}" fill="{color}" font-size="11" font-weight="bold">{name}</text>'

# 7. 外层包装
full_svg = f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 {W} {H}" style="width:100%;max-width:900px;">{svg}</svg>'
```

**渲染要点**：
- 基准基金（011128）用粗线（stroke-width=3），其他用细线（2）
- 颜色与全报告一致：011128=蓝、519133=红、004475=绿、004138=橙、010965=紫
- 图例用独立 HTML 元素放在 SVG 下方，不嵌入 SVG
- 曲线末端标注基金名称
