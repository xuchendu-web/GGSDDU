# 行业景气度追踪（Industry Prosperity Tracker）

> 财务数据 + 行情数据 + 宏观数据 → 申万一级行业景气评分矩阵 + 边际变化信号

---

## 一、总览

本 skill 构建一套申万一级行业景气度量化评分体系，综合利用 cjpy 的财务报表、行情因子、宏观数据，输出：
- **景气评分矩阵**（0-100 分，31 个申万一级行业）
- **边际变化信号**（景气上行/改善/持平/恶化/下行）

---

## 二、景气度评分框架

### 2.1 五维评分体系

```
行业景气度 = Σ(维度得分 × 维度权重)

┌──────────┬──────┬──────────────────────────────────┬─────────────────────┐
│   维度   │ 权重 │            核心指标               │     cjpy 数据源      │
├──────────┼──────┼──────────────────────────────────┼─────────────────────┤
│ 盈利质量 │ 30%  │ ROE、毛利率、净利率（同比变化）    │ 主要财务指标         │
│          │      │                                  │ 主营收入及成本_分行业 │
├──────────┼──────┼──────────────────────────────────┼─────────────────────┤
│ 增长动能 │ 25%  │ 营收增速、净利润增速（YoY）        │ 合并利润表           │
│          │      │                                  │ 业绩预告             │
├──────────┼──────┼──────────────────────────────────┼─────────────────────┤
│ 库存效率 │ 20%  │ 存货周转率、存货/总资产变化        │ 存货、合并资产负债表  │
│          │      │ 应收帐款周转率变化                 │ 应收帐款帐龄分析     │
├──────────┼──────┼──────────────────────────────────┼─────────────────────┤
│ 市场定价 │ 15%  │ PE分位数、近1月/3月价格动量         │ get_factor_data      │
│          │      │ 行业指数涨跌幅                     │ (PETTM, 日收益率)    │
├──────────┼──────┼──────────────────────────────────┼─────────────────────┤
│ 资金关注 │ 10%  │ 换手率变化、成交额变化              │ get_factor_data      │
│          │      │ 机构持仓变化                       │ (换手率, 成交额)     │
└──────────┴──────┴──────────────────────────────────┴─────────────────────┘
```

### 2.2 评分标准化

每个指标标准化到 0-100 分：

- **正向指标**（ROE提升、增速加快）：排名前20% → 90-100分，排名20-40% → 70-89分...
- **负向指标**（库存积压、估值过高）：反向计分
- **环比变化**：除绝对值排名外，变化方向额外加分/扣分

## 三、数据提取工作流

### Step 1: 行业分类锚定

获取申万一级行业列表（31个行业）：

```
因子调用: get_factor_data
  code: 选各行业代表性龙头（约31只）
  factors: ["一级行业", "二级行业"]
```

标准申万一级行业代码映射表见 `references/industry_map.md`。

### Step 2: 财务数据聚合

采用 Python 脚本批量提取各行业成分股财务数据，以 `中位数` + `加权平均` 两种方式聚合。

**关键表及字段：**

| cjpy 表名 | 关键字段 | 用途 |
|-----------|---------|------|
| 主要财务指标 | 净资产收益率(%), 每股收益 | 盈利质量 |
| 合并利润表 | 营业收入, 归母净利润 | 增长动能 |
| 合并资产负债表 | 资产总计, 存货, 应收帐款 | 库存效率 |
| 主营收入及成本_分行业 | 主营毛利率(%), 主营收入增长率(%) | 盈利质量+增长 |
| 存货 | 存货合计, 原材料, 产成品 | 库存结构 |

> **数据时间窗口**：优先最新季报（最近4个季度滚动），与去年同期对比。

### Step 3: 行情动量提取

```python
# 获取行业代表股票的估值和动量
get_factor_data(
    code=["行业龙头代码列表"],
    date=["最近交易日"],
    factors=["收盘价","PETTM","PBMRQ","换手率","日收益率"]
)
```

### Step 4: 宏观数据补充

```python
# PPI 数据（工业生产者价格）
get_table_data(code="M0001389", table_name="宏观_工业生产者价格简表")

# 工业增加值
get_table_data(code="M0001390", table_name="宏观_工业增加值简表")
```

### Step 5: 评分计算与矩阵输出

调用 `scripts/industry_prosperity.py` 执行核心计算，生成：
1. **景气评分矩阵**：31行业 × 5维度 得分表
2. **边际变化热力图**：与上一期对比的变化方向
3. **HTML 可视化报告**

---

## 四、边际变化信号定义

| 信号 | 图标 | 定义 | 操作含义 |
|------|------|------|---------|
| 景气上行 | 🔥 | 得分连续2期上升 + 最新得分>60 | 强烈关注，重点配置 |
| 边际改善 | ✅ | 最新一期得分上升 5%+ | 关注拐点，适度参与 |
| 持平 | ➡️ | 得分变化在 ±5% 以内 | 维持现有配置 |
| 边际恶化 | ⚠️ | 最新一期得分下降 5%+ | 警惕风险，考虑减仓 |
| 景气下行 | ❄️ | 得分连续2期下降 + 最新得分<40 | 规避 |

## 五、输出格式

### 5.1 景气评分矩阵（HTML 热力图）

- **行**：31 个申万一级行业
- **列**：总得分 + 5 维度得分
- **颜色**：高分（>70）绿色 → 中分（40-70）黄色 → 低分（<40）红色
- **信号列**：边际变化箭头
- **排序**：默认按总得分降序

### 5.2 报告命名

`industry_prosperity_YYYYMMDD.html`

### 5.3 报告存放

当前工作区 `outputs/` 目录

## 八、注意事项

1. **财报滞后性**：财务数据按季度更新，最新完整数据可能滞后1-2个月，报告中会标注数据截止期
2. **行业映射**：申万行业分类定期调整，使用 cjpy 的 `一级行业` 因子获取实时分类
3. **中位数 vs 加权**：行业聚合优先使用成分股**中位数**（避免极端值影响），市值加权作为参考
4. **数据缺失**：如某行业成分股均未披露最新财报，标注「数据待更新」
5. **宏观匹配**：PPI/工业增加值按大类行业映射到申万行业，匹配表见 references/industry_map.md
