### 0.2 核心概念：平台形态

> 股价在一段区间里多次试探同一价位而未能突破，最终放量脱离，即构成平台突破形态。

**三大判别要素**：
1. 相近的局部高点连成一条水平阻力线
2. 阻力位的形成与锚定效应有关 — 前期高点成为投资者定价参照
3. 试探越充分的有效突破，趋势延续性往往更好

## 一、高低点识别：布林带趋势分段

### 1.1 算法原理

用布林带做维度缩减：最高价上破上轨确认上升段，最低价下破下轨确认下降段，方向反转时正式确认前一段的高点或低点。

### 1.2 核心参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| N | 20 | 布林带回溯窗口长度（日均线周期） |
| K | 1 | 布林带宽度倍数（上/下轨 = MA ± K×σ） |
| P | 4 | 清洗间隔：低于 P 日的相邻转折点事后清除 |

### 1.3 识别逻辑

```
每日判断:
  IF 最高价 > 上轨(MA20 + 1σ):
    → 标记当前方向为"上升"
  IF 最低价 < 下轨(MA20 - 1σ):
    → 标记当前方向为"下降"

方向反转时:
  上升→下降 反转点 → 确认前一段的"局部高点"
  下降→上升 反转点 → 确认前一段的"局部低点"

数据清洗:
  - 相邻转折点间隔 < P(4)日 → 剔除
  - 连续同类型 → 只保留更极端者
```

### 1.4 布林带计算公式

```
MA20 = SMA(close, 20)
STD20 = STD(close, 20)
上轨 UB = MA20 + K × STD20   (K=1)
下轨 LB = MA20 - K × STD20   (K=1)
```

### 1.5 三步优势

1. **去噪**：过滤日内随机波动，聚焦趋势性转折
2. **降维**：从逐日 K 线转为少数转折点，大幅压缩数据量
3. **动态分段**：自然划分趋势段，便于后续分箱

## 二、阻力位定位：HSAR 分箱算法

### 2.1 算法原理

HSAR（Horizontal Support and Resistance）在转折点得到的局部高点上做价格分箱与密度聚集，把"相近的高点"定量的凝成一条水平阻力线。

### 2.2 核心参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| M | 10 | 价格分箱的箱体个数 |
| Q | 2 | 高点聚集次数达 Q 方可识别为阻力位 |
| 回溯窗口 | 252日(约1年) | 取过去一年日线高低点作为价格范围 |

### 2.3 分箱与阻力位判定

```
Step 1: 划定价格范围
  price_min = min(过去252日所有日线低点)
  price_max = max(过去252日所有日线高点)
  bin_width = (price_max - price_min) / M

Step 2: 将局部高点分入各箱
  每个局部高点归入第 k 箱，其中:
    k = floor((high_price - price_min) / bin_width)
    k = min(k, M-1)  # 边界处理

Step 3: 阻力位判定 — 同时满足两个条件:
  条件① "高点聚集":
    该箱及其下方相邻一箱(共2个箱宽)内高点数量 ≥ Q
  条件② "位置偏高":
    该箱上方一个箱宽内无更高高点

Step 4: 阻力价位输出
  阻力位 = 满足条件的最上方箱体的上边界价格
  即: resistance = price_min + (k+1) × bin_width
```

### 2.4 更新频率

- **每周末回溯重算**：用过去 252 日数据重新计算阻力位
- **次周逐日验证**：用新阻力位检验每日收盘价是否突破
- 新高点出现时阻力位自动滚动上移

## 三、突破触发：3% 缓冲确认

### 3.1 突破判定

```
IF 当日收盘价 > 阻力位 × (1 + 3%):
  → 触发突破信号
ELSE:
  → 未突破
```

### 3.2 缓冲设计意图

- 3% 缓冲用于**滤掉贴着阻力位的无效穿越**
- 避免假突破（盘中短暂穿越但收盘回落）
- 以收盘价为准，排除盘中噪声

### 3.3 信号去重与可交易性过滤

```
信号去重:
  - 同一阻力位连续触发多次 → 只保留首次
  - 阻力位更新后旧信号自动失效

可交易性过滤:
  - 剔除上市不满 60 日的股票
  - 剔除当日涨幅超 9% 的股票（追高风险）
  - 剔除 ST 股票
```

## 五、动量赋权优化

### 5.1 赋权方案

在价量筛选后的样本池内，用正向动量因子对持仓赋权：

| 赋权因子 | 公式 | 年化收益 | 说明 |
|---------|------|---------|------|
| 等权(基准) | w_i = 1/n | 22.17% | 所有入选样本等权 |
| Ret5d | w_i ∝ Ret5d | 26.00% | 近期涨幅越大权重越高 |
| PriceMA20Dev | w_i ∝ PriceMA20Dev | **26.48%** | 相对均线偏离越大权重越高 |

### 5.2 赋权逻辑

```
PriceMA20Dev = (close - MA20) / MA20 × 100

w_i = PriceMA20Dev_i / Σ(PriceMA20Dev_j)   (仅对正值样本赋权)
```

### 8.2 参数灵敏度指引

| 参数调整方向 | 效果 |
|-------------|------|
| N ↑ (如20→30) | 转折点更稀疏，信号更少但更可靠 |
| K ↑ (如1→1.5) | 更宽的布林带，减少假转折但可能延迟 |
| M ↑ (如10→15) | 更精细的分箱，阻力位更精确但可能分散 |
| Q ↑ (如2→3) | 更严格的阻力位确认，减少信号但提高质量 |
| 缓冲 ↑ (如3%→5%) | 更保守的突破判定，滤掉边缘突破 |

## 使用指引

当用户发出平台突破相关请求时：

### 请求 → 响应映射

| 用户请求 | 执行动作 |
|---------|---------|
| "分析 XX 的平台突破" | → 个股分析模式，输出完整五段报告 |
| "筛选今天平台突破的股票" | → 批量筛选模式（默认全市场或根据上下文选择池） |
| "沪深300里哪些股票突破了" | → 指定池批量筛选 |
| "XX 和 YY 对比分析" | → 多股票横向对比表 |
| "最近一周有哪些突破信号" | → 时间范围 + 批量筛选 |
| "展示图形"、"画个图"、"图表" | → 生成 HTML 交互图表（ECharts） |

### 输出规范

1. **先声明分析日期和数据范围**
2. **按五段式结构输出个股分析**
3. **批量筛选按拟合收益率降序排列**
4. **始终标注阻力位的有效期限**（每周更新）
5. **信号强度用 ⭐ 表示（1-5星）**
6. **行业分布用 Top 5 展示**

### 注意事项

- 阻力位**每周更新**，历史阻力位可能已失效
- 拟合收益率是基于历史回归的**预测值**，非实际收益
- 策略在**中小市值**股票中效果更显著，大盘股信号偏少
- 熊市中信号数量减少但筛选增益依然有效
- 突破信号需要结合大盘环境综合判断
