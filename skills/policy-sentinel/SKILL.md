# 政策与舆情雷达（Policy Sentinel）

> 政策舆情 / 产业舆情 / 个股负面预警 → 分级标签 + 原文摘要

---

## 一、总览

本 skill 构建一套三级舆情监控体系，实时追踪影响 A 股的信号事件：

| 监控层级 | 目标 | 数据源 | 输出频率 |
|---------|------|--------|---------|
| 政策舆情 | 宏观政策/监管信号 | WebSearch + cjpy 宏观 | 每日 |
| 产业舆情 | 行业政策/供需/价格 | WebSearch + cjpy 行情 | 每日 |
| 个股负面预警 | 减持/违规/业绩变脸 | cjpy 公告+增减持+业绩 | 实时 |

每条信号输出：**分级预警标签 + 原文摘要（≤80字）**

---

## 二、预警分级体系

| 级别 | 标签 | 定义 | 示例事件 |
|------|------|------|---------|
| 🔴 红色 | 重大利空 | 对公司/行业有重大负面影响 | 被立案调查、业绩暴雷>50%、控股股东减持>5%、ST风险 |
| 🟠 橙色 | 显著负面 | 有较大负面影响，需高度关注 | 业绩下滑>20%、重要股东减持、被监管问询、行业政策收紧 |
| 🟡 黄色 | 一般关注 | 有一定负面信号，保持观察 | 业绩小幅不及预期、小股东减持、行业政策微调 |
| 🔵 蓝色 | 信息提示 | 中性信息，知悉即可 | 例行公告、人事变动、股东大会通知 |
| 🟢 绿色 | 正面催化 | 对公司/行业有积极影响 | 业绩超预期、回购增持、政策利好 |

## 三、三级监控详解

### 3.1 政策舆情（宏观层）

**数据源：**
- WebSearch：国务院、发改委、财政部、央行、证监会、工信部、商务部等部委政策发布
- cjpy 宏观表：`宏观_央行货币政策工具`、`宏观_人民币存贷款利率`、`宏观_人民币汇率中间价` 等验证政策效果

**搜索主题词：**
- `"国务院 政策 发布 {date}"`
- `"证监会 监管 新规 {date}"`
- `"央行 货币政策 {date}"`
- `"发改委 产业政策 {date}"`
- `"财政部 税收 政策 {date}"`

**输出格式：**
```
🔴/🟠/🟡/🔵/🟢 [政策类型] 标题摘要
  来源 | 时间 | 影响行业
```

### 3.2 产业舆情（行业层）

**数据源：**
- WebSearch：行业供需、价格波动、技术突破、海外政策
- cjpy 因子验证：`指数PETTM`、`日收益率`、`换手率`、`成交额`

**搜索主题词：**
- `"{行业名} 政策 供需 {date}"`
- `"{行业名} 价格 涨跌 {date}"`
- `"{行业名} 产能 去化 {date}"`

**输出格式：**
```
🔴/🟠/🟡/🔵/🟢 [行业名] 事件标题摘要
  来源 | 时间 | 市场表现验证（cjpy）
```

### 3.3 个股负面预警（公司层）

**核心数据源：cjpy**

| cjpy 表 | 预警信号 | 等级 |
|---------|---------|------|
| 股东增减持 | 变动方向="减持" + 变动数量（占总股本比例） | 🔴>5% 🟠1-5% 🟡<1% |
| 股东增减持 | 大股东/实际控制人 减持 | 🔴 |
| 业绩预告 | 净利润变动幅度 < -50% | 🔴 |
| 业绩预告 | 净利润变动幅度 -20%~-50% | 🟠 |
| 业绩预告 | 净利润变动幅度 0~-20% | 🟡 |
| 股票公告 | 公告类型含"风险警示/立案调查/处罚/诉讼" | 🔴 |
| 股票公告 | 公告类型含"问询函/关注函" | 🟠 |
| 股票公告 | 公告类型含"澄清/说明" | 🟡 |
| 融资融券明细 | 融资余额连续下降 | 🟡 |

**搜索补充：**
- WebSearch：`"{股票名} 负面 风险 违规 {date}"`

## 四、工作流程

```
┌───────────────────────────────────────────────────────────┐
│  Step 1: 确定监控范围                                       │
│  ├─ 政策：全量监控（无需指定标的）                             │
│  ├─ 产业：用户指定行业 or 全行业扫描                          │
│  └─ 个股：用户指定股票 or 自选池 / 按条件筛选                 │
└──────────────────────────┬────────────────────────────────┘
                           │
┌──────────────────────────▼────────────────────────────────┐
│  Step 2: cjpy 数据提取（个股层）                              │
│  ├─ 股票公告：最近1周公告，按类型过滤                          │
│  ├─ 股东增减持：最近1个月变动，过滤减持方向                    │
│  ├─ 业绩预告：最新一期，过滤大幅变动                           │
│  └─ 融资融券明细：近5日融资余额趋势                           │
└──────────────────────────┬────────────────────────────────┘
                           │
┌──────────────────────────▼────────────────────────────────┐
│  Step 3: WebSearch 舆情搜索（政策+产业+个股补充）              │
│  ├─ 政策舆情：3-5个关键词搜索                                │
│  ├─ 产业舆情：按行业分别搜索                                 │
│  └─ 个股补充：负面新闻搜索 ⚠️ 仅对 cjpy 已触发预警的个股      │
└──────────────────────────┬────────────────────────────────┘
                           │
┌──────────────────────────▼────────────────────────────────┐
│  Step 4: 分级标记 + 摘要生成                                 │
│  ├─ 每条信号打上 🔴🟠🟡🔵🟢 标签                             │
│  ├─ 生成 ≤80字 中文摘要                                    │
│  ├─ 标注来源和时间                                          │
│  └─ 关联影响标的（个股/行业）                                │
└──────────────────────────┬────────────────────────────────┘
                           │
┌──────────────────────────▼────────────────────────────────┐
│  Step 5: 输出舆情日报（HTML）                                │
│  ├─ 顶部：🔴 红色预警汇总（重点关注）                         │
│  ├─ 中部：三级信号分类列表                                    │
│  └─ 底部：统计概览 + 免责声明                                │
└───────────────────────────────────────────────────────────┘
```

## 六、输出格式

### HTML 舆情日报

- **顶部横幅**：🔴 红色预警数量 | 🟠 橙色预警数量 | 🟡 黄色关注数量
- **政策舆情区**：最近政策信号摘要卡片
- **产业舆情区**：按行业分组的舆情信号
- **个股预警区**：按预警等级排序的个股信号列表
- 每行：标签 + 摘要 + 来源 + 时间 + 关联标的

### 报告命名

`policy_sentinel_YYYYMMDD.html`

## 七、使用示例

### 示例 1：全面舆情扫描

> 用户：「今天有哪些政策舆情和风险事件？」

执行：WebSearch 政策新闻 + cjpy 公告/增减持扫描 → 分级报告

### 示例 2：自选股负面预警

> 用户：「帮我扫一下自选池有没有负面信号」

执行：cjpy 提取自选股近期公告 + 增减持 + 业绩预告 + 负面新闻搜索

### 示例 3：行业政策追踪

> 用户：「最近半导体行业有什么政策变化？」

执行：WebSearch 行业政策 + cjpy 行情数据验证市场反应

## 八、注意事项

1. **公告表历史长**：`股票公告` 数据量大，务必加日期过滤（最近7天）
2. **增减持关注变动方向**：`变动方向` 字段区分"增持"/"减持"
3. **业绩预告时效**：业绩预告有预测属性，最终以正式财报为准
4. **新闻摘要长度**：严格控制在 80 字内，保持简洁
5. **信号不重复**：同一事件多个来源取最高等级标记
6. **非交易日处理**：如当天非交易日，使用最近交易日数据
