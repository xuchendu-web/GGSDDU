# 政策与舆情雷达 — 数据参考

## cjpy 关键数据表

### 股票公告

| 字段 | 说明 | 预警用途 |
|------|------|---------|
| CODE / NAME | 证券代码/名称 | 关联标的 |
| 公布日 | 公告发布日期 | 时间过滤 |
| 公告类型(一级) | 大类：风险警示/处罚/补充更正... | 快速筛选 |
| 公告类型(二级) | 细类：立案调查/诉讼/问询... | 精确分类 |
| 公告标题 | 公告全文标题 | 提取关键信息 |

**典型预警查询：**
```python
# 获取最近7天公告
get_table_data(code="SH600519", table_name="股票公告", limit=50)
# 按公布日过滤最近一周
```

### 股东增减持

| 字段 | 说明 | 预警用途 |
|------|------|---------|
| 变动方向 | 增持/减持 | 方向判断 |
| 变动数量 | 股数 | 计算占总股本比例 |
| 股东名称 | 股东身份 | 大股东/实控人 减持 = 🔴 |
| 变动原因 | 减持原因 | 判断主动性 |

**预警规则：**
- 控股股东/实控人减持 + 比例 >5% → 🔴
- 重要股东（持股>5%）减持 + 比例 1-5% → 🟠
- 其他股东小幅减持 → 🟡

### 业绩预告

| 字段 | 预警规则 |
|------|---------|
| 预告净利润变动幅度(%) | <-50% → 🔴, -20%~-50% → 🟠, 0~-20% → 🟡 |

### 融资融券明细

| 指标 | 预警规则 |
|------|---------|
| 融资余额连续5日下降 | 🟡 融资客离场信号 |
| 融券余额大幅上升 | 🟠 做空力量增强 |
