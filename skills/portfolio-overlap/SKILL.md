# 持仓重叠分析（Portfolio Overlap Analyzer）

> 基金列表 → 两两重叠度矩阵 + 组合实质集中度 + 重叠个股曝光

---

## 一、总览

FOF（Fund of Funds）配置中，如果底层基金持仓高度重叠，表面上分散了 N 只基金，实质却集中在少数几只股票上，形成「虚假分散」。本 skill 解决这个核心问题：

**输入：** 2-N 只基金代码
**输出：**
- 两两重叠度矩阵（热力图）
- 组合层面实质集中度（有效持仓数 / HHI）
- 重叠程度最高的个股曝光名单

---

## 二、核心指标

### 2.1 两两重叠度

```
Step 1: 归一化 — 个股在前十大中的权重 = 个股占净值比例 / 前十大权重之和
Step 2: 重叠度(A, B) = min( Σ max(w_i^A', w_i^B') , 100% )

其中 w_i^A' = 股票 i 在基金 A 前十大中的归一化权重

取值范围：0%（完全不重叠）~ 100%（前十大持仓完全一致）
```

**预警阈值：**
| 重叠度 | 信号 | 说明 |
|--------|------|------|
| >80% | 🔴 高度重叠 | 两只基金几乎买同一批股票，分散效果极差 |
| 60-80% | 🟠 显著重叠 | 存在明显集中风险，需要关注 |
| 30-60% | 🟡 中度重叠 | 有一定分散效果，但需注意重叠个股 |
| <30% | 🟢 低度重叠 | 持仓差异较大，分散效果良好 |

### 2.2 组合实质集中度

将 N 只基金持仓合并为一个虚拟组合，计算：

```
有效持仓数 = 1 / Σ(w_i^2)

其中 w_i = 合并后股票 i 的总权重

示例：50只股票等权 → 有效持仓数 = 50
      1只股票占50% → 有效持仓数 ≈ 2（集中风险极高）
```

**HHI（赫芬达尔指数）：**
```
HHI = Σ(w_i²) × 10000
HHI > 2500 → 高度集中
1000-2500 → 中度集中
<1000 → 分散
```

### 2.3 重叠个股曝光

列出在所有/多数基金中共同持有的股票，标注：
- 出现在几只基金中
- 合并总权重
- 单个基金最大权重

## 三、工作流程

```
┌───────────────────────────────────────────────────────────┐
│  Step 1: 输入基金列表                                       │
│  用户提供 2-N 只基金代码（OF前缀，如 OF160706）               │
└──────────────────────────┬────────────────────────────────┘
                           │
┌──────────────────────────▼────────────────────────────────┐
│  Step 2: 提取持仓数据（cjpy）                                │
│  对每只基金调用 get_table_data(code, "基金持股明细")          │
│  提取：股票代码、名称、占净值比例(%）、市值                    │
│  注意：只取最新一期报告（按截止日过滤）                        │
└──────────────────────────┬────────────────────────────────┘
                           │
┌──────────────────────────▼────────────────────────────────┐
│  Step 3: 计算两两重叠度矩阵                                  │
│  N×N 矩阵，对角线 = 100%                                    │
│  公式：① 归一化 → 个股权重' = 占净值比例 / 前十大权重之和     │
│       ② 重叠度(A,B) = Σ_{共同持仓} max(w_i^A', w_i^B')      │
│       ③ 上限 100%                                           │
│  对每对基金计算共同持有股票的归一化权重交集                    │
└──────────────────────────┬────────────────────────────────┘
                           │
┌──────────────────────────▼────────────────────────────────┐
│  Step 4: 计算组合集中度                                     │
│  合并所有基金持仓 → 计算有效持仓数 / HHI                     │
│  对比：单只基金平均有效持仓数 vs 组合有效持仓数               │
│  计算「分散效率」 = 组合有效持仓 / (N × 单基金均值)            │
└──────────────────────────┬────────────────────────────────┘
                           │
┌──────────────────────────▼────────────────────────────────┐
│  Step 5: 生成 HTML 报告                                     │
│  ├─ 摘要卡片（基金数/有效持仓/HHI/分散效率/平均重叠度）        │
│  ├─ 前十大持仓对比表（标红重复持仓）                           │
│  ├─ 重叠度热力图矩阵 + 逐对文字解读                           │
│  ├─ 收益率相关性矩阵（Pearson ρ 热力图 + 分级解读）            │
│  ├─ 赛道聚类自动识别                                         │
│  ├─ 组合集中度面板（各基金 vs 合并 + 文字解读）                │
│  ├─ 重叠个股 Top 10 曝光 + 风险分析                           │
│  └─ 机构级综合配置建议（A~E 五板块）                           │
└───────────────────────────────────────────────────────────┘
```

## 四、输出报告

### HTML 报告结构（共 9 大模块）

- **顶部摘要卡片**：基金数量 | 合并有效持仓数 | HHI | 分散效率 | 平均两两重叠度
- **各基金前十大持仓对比表**：N 列表格逐行对齐排列，跨基金重复持仓红色高亮 + 🔁 标记
- **重叠度矩阵**：N×N 归一化+max 热力图，颜色越深重叠度越高
- **逐对重叠度解读**：每对基金的详细文字分析（高度/中度/低度）
- **收益率相关性矩阵**：基于近 2 年周收益率的 Pearson ρ 热力图 + 强/中/弱相关分级解读
- **赛道聚类分析**：基于重叠度矩阵自动识别基金小团体 + 行业风格推断
- **组合集中度面板**：各基金有效持仓数对比 + 合并组合统计 + HHI/分散效率文字解读
- **重叠个股 Top 10**：出现次数、合并权重、最大单基金权重 + 跨基金集中风险文字分析
- **机构级综合配置建议（A~E）**：
  - A. 总体评估（双维度风险定级）
  - B. 持仓维度核心发现（逐对量化 + 集中度结论）
  - C. 业绩相关性维度（ρ>0.9 极高正相关对识别）
  - D. 配置优化方案（去重/核心-卫星/风格补缺）
  - E. 风险监控框架（五指标预警阈值表）

### 报告命名

`portfolio_overlap_YYYYMMDD.html`

### 报告存放

当前工作区 `outputs/` 目录

## 七、注意事项

1. **数据时效**：基金持仓按季报/中报/年报披露，最新数据可能滞后1-2个月
2. **ETF 联接基金**：联接基金持仓是目标 ETF，实际穿透需二次查询
3. **基金代码格式**：cjpy 使用 `OF` 前缀，如 `OF160706`
4. **权重基准**：使用「占净值比例(%)」作为持仓权重
5. **规模限制**：MCP 每批最多5只基金，超过5只需分批提取

## 八、指标详解

### 重叠度图示

```
基金A 前十大:  {X:10%, Y:8%, Z:7%, ...}  → 归一化 → {X:14%, Y:11%, Z:10%, ...}
基金B 前十大:  {X:6%,  Y:9%, W:8%, ...}  → 归一化 → {X:8%,  Y:12%, W:11%, ...}
                                    共同持仓 X, Y 取 max
重叠度 = max(14%,8%) + max(11%,12%) = 14% + 12% = 26%
```

> 如果只有一方持有的股票（如 Z、W），不参与求和。两只基金持仓完全相同且权重一致 → 100%。

### HHI 直观类比

| 场景 | 权重分布 | HHI | 含义 |
|------|---------|-----|------|
| 极端集中 | 1只股票100% | 10000 | 全部押注一只 |
| 高度集中 | 10只各10% | 1000 | 仅前十大 |
| 中度集中 | 30只各~3.3% | 333 | 有分散但不充分 |
| 充分分散 | 50只各~2% | 200 | 均匀分布 |
| >2500 高度集中 | 1000-2500 中度 | <1000 充分分散 | — |

### 持仓重叠 vs 收益率相关性（双矩阵互补）

| 维度 | 回答的问题 | 局限 |
|------|-----------|------|
| 持仓重叠度 | "买了相同的股票吗？" | 只看到前十大，看不到隐藏仓位；不同股票可能同属一个板块 |
| 收益率相关性 | "涨跌同步吗？" | 无法区分是选股一致还是板块共振；受市场风格切换影响 |

> 典型案例：吴昊（存储芯片）和金梓才（光通信）前十大零重叠，但收益率相关性 0.69——同在 AI 赛道，持仓不同但走势趋同。双矩阵并用才能完整评估组合分散度。
