## 核心公式

### 两两重叠度

```
Step 1: 归一化 weight' = weight / Σ(top10_weights)
Step 2: Overlap(A,B) = min( Σ max(w_i^A', w_i^B'), 100% )

其中 w_i' 为股票 i 在基金前十大中的归一化权重
取值范围：0-100%，100% 表示前十大持仓完全一致
```

### 有效持仓数

```
Effective_N = 1 / Σ(w_i^2)

w_i = 股票 i 在合并组合中的权重
```

### HHI

```
HHI = Σ(w_i^2) × 10000

HHI < 1000: 分散
1000-2500: 中度集中
>2500: 高度集中
```

### 分散效率

```
分散效率 = 组合有效持仓数 / (N × 单基金平均有效持仓数) × 100%

>80%: 分散良好
50-80%: 有重叠但可接受
<50%: 严重重叠，虚假分散
```

## 预警规则

| 指标 | 阈值 | 信号 |
|------|------|------|
| 平均两两重叠度 | >70% | 🔴 严重重叠 |
| 平均两两重叠度 | 40-70% | 🟡 中度重叠 |
| 分散效率 | <50% | 🔴 虚假分散 |
| 分散效率 | 50-80% | 🟡 效率不足 |
| 有效持仓数 | <20 | 🔴 过度集中 |
